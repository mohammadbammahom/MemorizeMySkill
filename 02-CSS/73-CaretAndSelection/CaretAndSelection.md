# CSS Caret And Selection
---
## این مبحث چیست؟
CSS Caret And Selection شامل ویژگی‌هایی است که ظاهر مکان‌نمای متنی و ناحیه انتخاب‌شده را کنترل می‌کند. این تنظیمات به بهبود تجربه کاربری در فرم‌ها و متون قابل انتخاب کمک می‌کنند.
---
## چرا از آن استفاده می‌کنیم؟
- برای هماهنگی طراحی فرم با رنگ‌بندی سایت.
- برای افزایش خوانایی متن انتخاب‌شده.
- برای نمایش واضح‌تر مکان‌نمای ورودی‌ها.
- برای بهبود تجربه کاربر در انتخاب و ویرایش متن.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم رنگ caret در input را تغییر دهیم:
```css
input {
  caret-color: red;
}
```
- وقتی می‌خواهیم رنگ انتخاب متن را مطابق با طراحی سایت تنظیم کنیم:
```css
::selection {
  background: #ffcc00;
  color: #000;
}
```
- وقتی می‌خواهیم انتخاب متن در عناصر خاص متفاوت باشد:
```css
.article ::selection {
  background: rgba(0, 123, 255, 0.2);
  color: #111;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی انتخاب متن باید کاربر را بیشتر از متن اصلی منحرف کند.
```css
::selection {
  background: red;
  color: white;
}
```
- وقتی رنگ caret با رنگ پس‌زمینه همخوانی ندارد.
```css
input { caret-color: yellow; }
```
- وقتی طراحی فرم باید ساده و استاندارد بماند.
```css
input { caret-color: auto; }
```
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `caret-color` | رنگ مکان‌نما | روی مکان‌نما در input/textarea اثر می‌کند |
| `::selection` | رنگ ناحیه انتخاب | روی متن انتخاب‌شده اثر می‌گذارد |
| `color` | رنگ متن | روی متن عادی تاثیر می‌گذارد |
---
## بهترین روش‌های استفاده
- از رنگ‌های واضح و متضاد برای `::selection` استفاده کنید.
- برای فرم‌ها از `caret-color` هماهنگ با رنگ برند استفاده کنید.
- انتخاب متن را در بخش‌های مهم محتوا تست کنید.
- برای کنترل ظاهر selection هم در دسکتاپ و هم موبایل بررسی کنید.
---
## اشتباهات رایج
- ❌ انتخاب متن با رنگ کم‌کنتراست:
```css
::selection { background: #efefef; color: #fff; }
```
- ❌ caret روی پس‌زمینه‌ی روشن:
```css
input { caret-color: white; }
```
- ❌ سبک کردن selection بدون توجه به خوانایی:
```css
::selection { background: rgba(0,0,0,0.1); }
```
---
## نکات بازار کار
- در طراحی فرم‌های حرفه‌ای، ظاهر caret و selection اهمیت UX را افزایش می‌دهد.
- در مصاحبه باید بدانید چگونه `::selection` را برای بخش‌های مختلف اعمال کنید.
- در بازبینی کد، توجه به خوانایی و رنگ متن انتخاب‌شده مهم است.
- انتخاب متن باید با رنگ‌بندی کلی سایت همخوانی داشته باشد.
- برای فرم‌های برندینگ شده، caret هم باید هماهنگ باشد.

## تمرین

در این تمرین یک فرم ساده بسازید که ظاهر caret و انتخاب متن را بهبود دهد.

مراحل انجام تمرین:

1. در HTML یک فرم با موارد زیر ایجاد کنید:
   - یک فیلد ورودی متن (`input type="text"`).
   - یک پاراگراف توضیحی.
   - یک دکمه ارسال ساده.

2. در CSS برای ورودی متن از `caret-color: #ff4500;` استفاده کنید.

3. برای متن داخل صفحه یک استایل `::selection` بنویسید:
   - `background` با رنگ روشن و نیمه‌شفاف.
   - `color` تیره و قابل خواندن.

4. برای فرم و پاراگراف از یک پس‌زمینه روشن و رنگ متن مناسب استفاده کنید تا selection قابل مشاهده باشد.

5. سازگاری موبایل را بررسی کنید:
   - اندازه ورودی و فاصله‌ها روی موبایل مناسب باشند.
   - انتخاب متن در موبایل هنوز خوانا باشد.

نتیجه نهایی:
یک بخش فرم بسازید که caret نارنجی داشته باشد و هنگام انتخاب متن، رنگ پس‌زمینه و متن به شکلی باشد که در موبایل و دسکتاپ خوانایی حفظ شود.
