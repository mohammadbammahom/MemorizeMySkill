# عنوان درس

## این مبحث چیست؟

- CSSMathFunctions به توابع ریاضیاتی اشاره دارد که امکان محاسبات پیچیده‌تر را در سند CSS می‌دهند؛ فعلا `calc()`, `min()`, `max()`, `clamp()` رایجند و مشخصات آینده توابع ریاضیاتی پیشرفته‌تر را مطرح می‌کند.
- هدف این درس آشنایی عملی با به‌کارگیری محاسبات برای layout و spacing است.

## چرا در بازار کار مهم است؟

- توانایی انجام محاسبات در CSS باعث کاهش نیاز به JavaScript برای محاسبات ساده می‌شود و سرعت توسعه را افزایش می‌دهد.
- در تیم‌های مدرن، developers انتظار دارند که layoutهای پیچیده را با CSS و توابع ریاضی به‌سادگی پیاده کنند.

## نکات مهم

- `calc()` هنوز مهم‌ترین ابزار است؛ ترکیب با viewport units و درصد نتایج انعطاف‌پذیری می‌دهد.
- برای محاسبات پیچیده‌تر، گاهی ترکیب چند تابع (مثل `calc(min(...), ...)`) مفید است.
- همیشه نتیجه را در مرورگرهای هدف تست کن.

## مثال واقعی

- استفادهٔ `calc()` برای تعیین ارتفاع hero بر اساس header height: `height: calc(100vh - var(--header-height));` تا hero همیشه درست اندازه‌گیری شود حتی اگر header داینامیک باشد.

## اشتباهات رایج

- انجام محاسبات سنگین و پیچیده در CSS که خوانایی را کاهش می‌دهد.
- عدم تست در مرورگرهای قدیمی یا محیط‌هایی که unitهای viewport متفاوتند.

## چک لیست یادگیری

- [ ] می‌توانم `calc()` را برای layoutهای متداول استفاده کنم.
- [ ] تاثیر واحدهای viewport را در محاسبات می‌فهمم.
- [ ] توانایی ترکیب توابع و `var()` را دارم.
