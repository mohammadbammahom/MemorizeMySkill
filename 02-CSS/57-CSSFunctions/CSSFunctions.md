# عنوان درس

## این مبحث چیست؟

- توابع CSS ابزارهای کوچکی هستند که به شما اجازه می‌دهند محاسبات و انتخاب‌های دینامیک در استایل‌ها انجام دهید؛ نمونه‌های رایج: `calc()`, `min()`, `max()`, `clamp()`, `var()`, `attr()` و توابع رنگ مانند `color-mix()`.
- این توابع باعث انعطاف‌پذیری در اندازه‌گذاری، تایپوگرافی و رنگ‌بندی می‌شوند و به جای ثابت‌نویسی مقدارها می‌توانند مقادیر را بر اساس context محاسبه کنند.

## چرا در بازار کار مهم است؟

- استفادهٔ هوشمندانه از توابع باعث می‌شود که components در اندازه‌ها و شرایط مختلف قابل استفاده باشند و نیاز به media queryهای متعدد کم می‌شود.
- در شرکت‌های حرفه‌ای، teamها انتظار دارند که developers از `clamp()` و `calc()` برای responsive typography و layout استفاده کنند.

## نکات مهم

- `calc()` می‌تواند واحدهای مختلف را ترکیب کند، اما عملکرد آن ساده و قابل فهم نگه داشته شود.
- `clamp(min, preferred, max)` بهترین گزینه برای اندازه‌دهی انعطاف‌پذیر است؛ به خصوص برای فونت‌ها و عرض باکس‌ها.
- `min()` و `max()` برای fallbackهای ترتیبی مفیدند.
- از `var()` همراه توابع دیگر استفاده کن تا design tokens انعطاف‌پذیر شوند.

## مثال واقعی

- در یک پروجکت وب خبری برای اندازه فونت تیتر از `clamp(1.2rem, 3vw, 2rem)` استفاده کن تا تیتر در موبایل و دسکتاپ خوانایی داشته باشد بدون نیاز به media queries متعدد.

## اشتباهات رایج

- استفادهٔ بی‌جهت از `calc()` برای مقادیری که می‌توانند ساده باشند.
- قرار دادن logic پیچیده در `calc()` که خوانایی را خراب کند.
- عدم تست cross-browser برای توابع جدیدتر در مرورگرهای قدیمی.

## چک لیست یادگیری

- [ ] می‌توانم `calc()` را با واحدهای مختلف ترکیب کنم.
- [ ] از `clamp()` برای typography و width استفاده کرده‌ام.
- [ ] `min()`/`max()` را برای fallbackهای منطقی به‌کار برده‌ام.
- [ ] توابع را در design system خود تست کرده‌ام.
