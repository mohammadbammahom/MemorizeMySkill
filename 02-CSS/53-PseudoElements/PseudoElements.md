# عنوان درس

## این مبحث چیست؟

- Pseudo-elements ایندکس‌هایی هستند که به بخشی از یک عنصر (مثل ابتدای محتوا یا بعد از آن) استایل می‌دهند بدون اینکه markup اضافی لازم باشد.
- نمونه‌های رایج: `::before`, `::after`, `::first-letter`, `::first-line`, `::placeholder` و `::marker`.

## چرا از آن استفاده می‌کنیم؟

- برای افزودن محتوای تزیینی یا ساختار ظاهری بدون تغییر HTML.
- برای بهبود دسترسی و جداسازی محتوای نمایشی از محتوای معنایی.

## چه زمانی استفاده می‌کنیم؟

- وقتی نیاز به تزئینات ظاهری داریم که نباید در DOM واقعی ظاهر شوند.
- برای اضافه کردن آیکون‌های تزئینی، نقل قول‌های بزرگ، نشان‌ها و badgeهای ظاهری.

## چه زمانی نباید استفاده کنیم؟

- وقتی محتوای اضافه‌شده از نظر معنایی مهم است یا باید توسط screen reader خوانده شود؛ در این موارد باید از HTML واقعی استفاده کرد.

## تفاوت با روش‌های مشابه

- Pseudo-classes (مثل `:hover`) وضعیت یا ویژگی یک عنصر را هدف می‌گیرند؛ اما pseudo-elements بخش‌های مجازی از خود عنصر را استایل می‌دهند.

## بهترین روش‌های استفاده

- از `content` فقط برای محتوای تزئینی استفاده کن؛ محتوای قابل‌فهم و مهم را داخل HTML قرار بده.
- از pseudo-elements برای بهبود طراحی (ornaments) و نه برای نگهداری داده.
- برای آیکون‌های تزئینی از فونت آیکون یا glyphs در `content` با احتیاط استفاده کن و تست دسترسی انجام بده.

## اشتباهات رایج

- قرار دادن متن مهم یا لینک داخل `::before/::after` که توسط خواننده‌های صفحه قابل‌دسترس نباشد.
- استفاده از pseudo-elements برای layout پیچیده به جای HTML مناسب.

## نکات بازار کار

- توانایی استفادهٔ هوشمندانه از pseudo-elements به شما امکان می‌دهد تا DOM را سبک نگه دارید و UI قابل‌خواناتر بسازید.
- در طراحی componentها، pseudo-elements برای تزئینات کوچک یا نشان‌های وضعیت مفیدند.

## چک‌لیست یادگیری

- [ ] تفاوت `::before` و `::after` را می‌فهمم.
- [ ] می‌توانم از `::first-letter` و `::first-line` برای typography استفاده کنم.
- [ ] می‌دانم چه زمانی نباید از pseudo-elements برای محتوای معنایی استفاده کنم.

## تمرین

فایل

PseudoElements.Exercises.html

را خودت بساز و تمرین‌ها را در آن انجام بده.

1. یک نقل‌قول طراحی کن که از `::before` برای علامت‌گذاری استفاده کند.
2. دکمه‌ای بساز که با `::after` آیکون تزئینی اضافه کند.
3. از `::first-letter` برای استایل‌دهی رأس پاراگراف استفاده کن.
4. مثال‌هایی از `::placeholder` برای فرم‌ها ایجاد کن و تفاوت مرورگرها را بررسی کن.
5. یک badge با استفاده از `::before` و `position: absolute` بساز.
6. تست دسترسی کن که آیا pseudo-content توسط screen reader قابل‌دسترسی نیست.
7. مقایسه‌ای بین استفاده از SVG inline و `content` glyph انجام بده.
8. حداقل یک نمونه که `::marker` را برای لیست‌های سفارشی استفاده کند بساز.
9. نمونه‌ای از pseudo-element که با media query تغییر می‌کند بساز.
10. یک component card بساز که از `::after` برای افکت تزیینی استفاده کند.
