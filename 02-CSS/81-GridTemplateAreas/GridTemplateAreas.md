# CSS Grid Template Areas
---
## این مبحث چیست؟
Grid Template Areas یکی از روش‌های تعریف طرح‌بندی شبکه‌ای با نام‌های معنایی برای هر قسمت است. این ویژگی نوشتن و خواندن layoutهای Grid را ساده‌تر می‌کند.
---
## چرا از آن استفاده می‌کنیم؟
- برای تعریف ساختار layout با خوانایی بهتر.
- برای اختصاص دادن نام به ردیف‌ها و ستون‌ها.
- برای ساده‌تر کردن تطابق بین HTML و CSS.
- برای تغییر سریع چینش بدون اصلاح HTML.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم layout ثابت و قابل فهم بسازیم:
```css
.grid {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "header header"
    "sidebar main";
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
```
- وقتی نیاز داریم اجزا را روی شبکه مرتب کنیم:
```css
.grid {
  grid-template-areas:
    "nav nav"
    "aside content"
    "footer footer";
}
```
- وقتی می‌خواهیم طرح را در responsive بازچینش دهیم:
```css
@media (max-width: 768px) {
  .grid {
    grid-template-areas:
      "header"
      "nav"
      "content"
      "aside"
      "footer";
  }
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی layout بسیار ساده است و نوشتن نام اضافی است.
- وقتی طرح کاملاً پویا و نامشخص است.
- وقتی تنها از یک یا دو سلول grid استفاده می‌کنید.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `grid-template-areas` | نام‌گذاری layout | طرح شبکه را با رشته‌هایی مشخص می‌کند |
| `grid-template-columns` | تعیین ستون‌ها | فقط اندازه ستون‌ها را مشخص می‌کند |
| `grid-column`/`grid-row` | قرار دادن آیتم | روی هر عنصر به صورت جداگانه کار می‌کند |
---
## بهترین روش‌های استفاده
- نام‌گذاری معنادار و ساده برای نواحی استفاده کنید.
- برای layoutهای پیچیده، ساختار را مرحله‌به‌مرحله بنویسید.
- در responsive، طرح را با media query باززدهی کنید.
- از `.header`, `.main`, `.sidebar` و نام‌های مشابه برای خوانایی استفاده کنید.
---
## اشتباهات رایج
- ❌ نام‌گذاری ناحیه‌ها به صورت مبهم:
```css
grid-template-areas: "a a" "b c";
```
- ❌ استفاده از نام‌های تکراری به شکل ناهمسان.
- ❌ فراموش کردن `grid-area` روی آیتم‌ها.
---
## نکات بازار کار
- `grid-template-areas` در پروژه‌های dashboard و پنل‌ها بسیار کاربردی است.
- در مصاحبه نشان دهید که می‌دانید چطور نام‌گذاری بخش‌ها را واضح نگه دارید.
- در بازبینی کد بررسی کنید آیا ساختار grid واضح و قابل اصلاح است.

## تمرین
یک صفحه داشبورد ساده بسازید که با استفاده از `grid-template-areas` بخش‌های آن نام‌گذاری شوند.

مراحل انجام تمرین:

1. در HTML چهار بخش تعریف کنید:
   - `header`
   - `aside` برای نوار کناری
   - `main`
   - `footer`

2. در CSS برای کانتینر اصلی `display: grid;` قرار دهید.
   - `grid-template-columns` و `grid-template-rows` مناسب انتخاب کنید.
   - `grid-template-areas` را با نام‌های `header`, `sidebar`, `main`, `footer` تعریف کنید.

3. برای هر بخش `grid-area` مشخص کنید:
   - `.header { grid-area: header; }`
   - `.sidebar { grid-area: sidebar; }`
   - `.main { grid-area: main; }`
   - `.footer { grid-area: footer; }`

4. برای حالت موبایل با `@media` طرح را بازچینش دهید:
   - بخش‌ها را به صورت ستونی قرار دهید.
   - ترتیب نمایش باید `header`, `sidebar`, `main`, `footer` باشد.

5. هر بخش باید دارای حاشیه داخلی، پس‌زمینه و فاصله باشد تا نمای داشبورد واضح شود.

نتیجه نهایی:
یک داشبورد شبکه‌ای بسازید که بخش‌های آن قابل خواندن و نام‌گذاری شده باشند و در حالت موبایل به ترتیب عمودی نمایش داده شوند.
