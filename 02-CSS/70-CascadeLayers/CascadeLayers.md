# CSS Cascade Layers
---
## این مبحث چیست؟
CSS Cascade Layers به شما امکان می‌دهد تعریف کنید که کدام فایل‌ها یا بلوک‌های CSS در اولویت قرار دارند. این ویژگی ترتیب cascade را کنترل می‌کند و کمک می‌کند از جنگ specificity جلوگیری شود.
---
## چرا از آن استفاده می‌کنیم؟
- برای مدیریت بهتر ترتیب استایل‌ها در پروژه‌های بزرگ.
- برای کاهش استفاده از `!important`.
- برای ایجاد سلسله‌مراتب واضح بین reset، base، theme و utilities.
- برای جلوگیری از overriding ناخواسته استایل‌ها.
---
## چه زمانی استفاده می‌کنیم
- وقتی یک framework یا design system دارید:
```css
@layer reset, base, components, utilities;
```
- وقتی می‌خواهیم استایل‌های عمومی قبل از استایل‌های خاص اعمال شود:
```css
@layer base {
  button { padding: 1rem; }
}
@layer components {
  .btn { padding: 1.25rem; }
}
```
- وقتی می‌خواهیم استایل‌های utility بعد از استایل‌های theme اجرا شوند:
```css
@layer utilities {
  .text-center { text-align: center; }
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی پروژه کوچک است و cascade ساده است.
```css
.button { color: blue; }
```
- وقتی هدف فقط یک استایل محلی ساده است.
```css
.header { background: red; }
```
- وقتی از CSS inline یا style attribute استفاده می‌کنید.
```css
<div style="color: red"></div>
```
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `@layer` | تعیین ترتیب cascade | اولویت قوانین را مشخص می‌کند |
| specificity | اولویت قوانین مشابه | بر اساس انتخاب‌کننده‌ها تعیین می‌شود |
| `!important` | لغو cascade معمول | گزینه‌ای قوی و غالب است |
---
## بهترین روش‌های استفاده
- ترتیب لایه‌ها را روشن و منطقی تعریف کنید.
- از `@layer` در ابتدای فایل‌های CSS استفاده کنید.
- لایه‌های عمومی مثل `reset` و `base` را قبل از `utilities` قرار دهید.
- وقتی لازم است با `@layer` جدا کنید، اما از لایه زیاد پرهیز کنید.
- استایل‌های مشتق و utility را در لایه‌های بعدی قرار دهید.
---
## اشتباهات رایج
- ❌ تعریف لایه‌ها با ترتیب نامناسب:
```css
@layer utilities, base;
```
- ❌ استفاده از `!important` به جای لایه‌بندی مناسب:
```css
.btn { color: blue !important; }
```
- ❌ فرض اینکه لایه‌ها فقط برای فایل‌های جداگانه است:
```css
@layer theme { ... }
```
- ❌ عدم استفاده از لایه برای مدیریت استایل‌های global:
```css
body { margin: 0; }
```
---
## نکات بازار کار
- لایه‌ها در پروژه‌های بزرگ و تیمی بسیار مفید هستند.
- در مصاحبه باید ساختار لایه‌ها را توضیح دهید.
- در بازبینی کد، ترتیب `@layer` و تاثیر آن بر cascade را بررسی کنید.
- لایه‌بندی صحیح می‌تواند کد را خواناتر کند.
- برای استایل‌های utility و theme از لایه‌های جدا استفاده کنید.

## تمرین

در این تمرین یک ساختار CSS با لایه‌های cascade بسازید تا ترتیب و اولویت استایل‌ها مشخص و منطقی باشد.

مراحل انجام تمرین:

1. در HTML یک صفحه ساده ایجاد کنید که شامل موارد زیر باشد:
   - `header` با یک عنوان.
   - یک `section` کارت محتوا.
   - یک بخش متنی.

2. در CSS در بالا فایل `@layer reset, base, theme, utilities;` تعریف کنید.

3. در `@layer reset` قواعد پایه را بنویسید:
   - `html, body { margin: 0; padding: 0; box-sizing: border-box; }`
   - فونت پایه و پس‌زمینه بدنه را تنظیم کنید.

4. در `@layer base` قوانین تایپوگرافی و ساختار کلی را تعریف کنید:
   - `body { font-family, line-height, color }`
   - استایل‌های `h1`, `p`, `a`.

5. در `@layer theme` استایل کارت را بنویسید:
   - کارت با `background`, `border-radius`, `box-shadow` و `padding`.
   - دکمه‌ای با رنگ منطقی و hover.

6. در `@layer utilities` کلاس‌های کمکی را اضافه کنید:
   - `.text-center { text-align: center; }`
   - `.mt-4 { margin-top: 1rem; }`
   - `.px-4 { padding-left: 1rem; padding-right: 1rem; }`

نتیجه نهایی:
یک ساختار CSS بسازید که لایه‌ها ترتیب منطقی داشته باشند؛ reset، base، theme و utilities باید به‌گونه‌ای تعریف شوند که override کردن و خواندن استایل آسان باشد.
