CSS Blend Modes

مثال ساده: Multiply

multiply رنگ‌ها را تاریک می‌کند.

مثال ساده: Screen

screen رنگ‌ها را روشن می‌کند.

مثال متوسط: Overlay

overlay ترکیبی از multiply و screen است.

مثال متوسط: Lighten

lighten روشن‌ترین رنگ را انتخاب می‌کند.

مثال متوسط: Darken

darken تاریک‌ترین رنگ را انتخاب می‌کند.

مثال: Color-Dodge

color-dodge روشن کردن شدید است.

مثال: Color-Burn

color-burn تاریک کردن شدید است.

مثال: Hard-Light

hard-light مشابه overlay است.

مثال: Soft-Light

soft-light نرم‌تر از hard-light است.

مثال: Difference

difference تفاوت رنگ‌ها را نشان می‌دهد.

مثال: Exclusion

exclusion مشابه difference است.

مثال: Hue

hue جنبه رنگ را تغییر می‌دهد.

مثال: Saturation

saturation اشباع رنگ را تغییر می‌دهد.

مثال: Color

color رنگ را حفظ می‌کند.

مثال: Luminosity

luminosity روشنایی را حفظ می‌کند.
