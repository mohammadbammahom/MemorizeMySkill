# CSS User Select
---
## این مبحث چیست؟
ویژگی `user-select` کنترل می‌کند که آیا کاربر می‌تواند متن یک عنصر را انتخاب کند یا خیر. با این ویژگی می‌توانید تجربه انتخاب متن را محدود یا فعال کنید.
---
## چرا از آن استفاده می‌کنیم؟
- برای جلوگیری از انتخاب متن در عناصر UI که انتخاب متن نامناسب است.
- برای محافظت ظاهری از متن یا محتوای غیر قابل کپی.
- برای بهبود تجربه کاربری در دکمه‌ها و منوها.
- برای جلوگیری از انتخاب ناخواسته متن در عناصر منو.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم متن داخل دکمه انتخاب نشود:
```css
button { user-select: none; }
```
- وقتی می‌خواهیم فقط متن در یک بخش قابل انتخاب باشد:
```css
.article { user-select: text; }
```
- وقتی می‌خواهیم انتخاب متن به کلی غیرفعال شود:
```css
.no-select { user-select: none; }
```
---
## چه زمانی نباید استفاده کنیم
- وقتی کاربران باید بتوانند متن را کپی کنند.
```css
.article { user-select: auto; }
```
- وقتی محتوا دارای متن قابل انتخاب مفید است.
- وقتی فقط برای کاهش پشتیبانی دسترسی استفاده می‌شود.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `user-select` | کنترل انتخاب متن | تعیین می‌کند آیا متن انتخاب می‌شود |
| `pointer-events` | کنترل تعامل اشاره‌گر | روی انتخاب تأثیر مستقیم ندارد |
| `user-drag` | کنترل درگ عناصر | فقط برای عناصر dragable مفید است |
---
## بهترین روش‌های استفاده
- برای دکمه‌های تعاملی `user-select: none` بگذارید.
- متن قابل انتخاب را در بخش‌های محتوا فعال نگه دارید.
- روی موبایل تست کنید تا رفتار انتخاب متن مناسب باشد.
- برای عناصر با قابلیت copy لازم است انتخاب را فعال کنید.
---
## اشتباهات رایج
- ❌ غیرفعال کردن انتخاب متن در کل صفحه:
```css
body { user-select: none; }
```
- ❌ استفاده از `user-select: none` روی متن قابل کپی.
- ❌ فراموش کردن تست در مرورگرهای مختلف.
---
## نکات بازار کار
- در پروژه‌های UI، `user-select` می‌تواند جلوی انتخاب ناخواسته متن را بگیرد.
- در مصاحبه باید موارد مناسب استفاده و استثناها را توضیح دهید.
- در بازبینی کد بررسی کنید آیا انتخاب متن مطابق با دسترس‌پذیری است.

## تمرین
یک نوار ابزار بسازید که متن عنوان قابل انتخاب باشد اما دکمه‌ها و آیکون‌ها قابل انتخاب نباشند.

مراحل انجام تمرین:

1. در HTML یک نوار ابزار شامل این عناصر بسازید:
   - چند دکمه یا آیکون (`button` یا `span`).
   - یک پاراگراف توضیحی یا متن کوتاه داخل نوار ابزار.

2. در CSS نوار ابزار را استایل دهید:
   - `display: flex;` یا `display: inline-flex;` برای چینش افقی.
   - `align-items: center;` و `gap` مناسب بین آیتم‌ها.
   - یک `border` واضح و `padding` کافی.

3. برای دکمه‌ها و آیکون‌ها از `user-select: none;` استفاده کنید.

4. برای متن توضیحی یا پاراگراف داخل نوار ابزار از `user-select: text;` استفاده کنید تا کاربر بتواند آن را انتخاب کند.

5. اطمینان حاصل کنید که حالت hover روی دکمه‌ها هنوز قابل مشاهده و قابل کلیک باقی می‌ماند.

نتیجه نهایی:
یک نوار ابزار حرفه‌ای بسازید که ظاهر مرتب و قابل فهم دارد، در آن آیتم‌های تعاملی انتخاب‌پذیر نیستند اما متن توضیحی قابل انتخاب باقی می‌ماند.
