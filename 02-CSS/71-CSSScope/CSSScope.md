# CSS Scope
---
## این مبحث چیست؟
CSS Scope ویژگی‌ای است که به شما اجازه می‌دهد قوانین CSS را در محدوده یک بخش یا کامپوننت خاص محدود کنید. این یعنی استایل‌ها فقط روی بخش تعریف‌شده اعمال شده و از نشت به سایر قسمت‌های صفحه جلوگیری می‌شود.
---
## چرا از آن استفاده می‌کنیم؟
- برای جلوگیری از تداخل CSS در پروژه‌های بزرگ.
- برای ایجاد encapsulation مشابه با کامپوننت‌های UI.
- برای نوشتن استایل‌های مخصوص بخشی از صفحه بدون تاثیر روی بقیه.
- برای ساده‌تر کردن نگهداری استایل‌ها.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم استایل‌های یک کامپوننت تنها داخل همان بخش اعمال شود:
```css
@scope (.card) {
  h2 {
    color: #1a1a1a;
  }
}
```
- وقتی یک صفحه دارای چند کامپوننت مستقل است:
```css
@scope (.sidebar) {
  a {
    color: blue;
  }
}
```
- وقتی می‌خواهیم استایل‌های یک بخش را بدون کلاس‌های اضافی محدود کنیم:
```css
@scope (.modal) {
  button {
    background: #0077ff;
  }
}
```
---
## چه زمانی نباید استفاده کنیم
- زمانی که استایل‌ها باید در کل صفحه اعمال شوند.
```css
@scope (html) {
  body { margin: 0; }
}
```
- زمانی که پروژه خیلی کوچک است و تداخل وجود ندارد.
```css
p { font-size: 16px; }
```
- زمانی که فقط یک کلاس یا ID ساده کافی است.
```css
.header { color: red; }
```
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `@scope` | محدود کردن استایل به یک بخش | جلوگیری از نشت استایل |
| کلاس‌های اختصاصی | هدف‌گذاری بخش‌ها | نیاز به نام‌گذاری صریح دارد |
| کامپوننت‌های CSS-in-JS | encapsulation در JavaScript | وابسته به فرم ورک است |
---
## بهترین روش‌های استفاده
- از `@scope` برای بخش‌هایی استفاده کنید که ممکن است با بخش‌های دیگر تداخل داشته باشند.
- فقط استایل‌هایی را داخل scope قرار دهید که واقعاً باید محدود شوند.
- اسامی scope را واضح و معنادار انتخاب کنید.
- در پروژه‌های تیمی قوانین scope را مستند کنید.
---
## اشتباهات رایج
- ❌ قرار دادن همه قوانین در یک scope بزرگ:
```css
@scope (.app) {
  * { box-sizing: border-box; }
}
```
- ❌ استفاده از scope برای استایل‌های عمومی:
```css
@scope (.container) {
  body { background: white; }
}
```
- ❌ اعتماد به scope به جای نام‌گذاری صحیح کلاس‌ها:
```css
@scope (.card) {
  .title { color: red; }
}
```
---
## نکات بازار کار
- برای تولید، درک scope به معنای کنترل بهتر روی CSS پروژه است.
- در مصاحبه باید تفاوت آن با کلاس‌های معمولی را توضیح دهید.
- در review کد باید ببینید آیا scope کاربردی و محدود است یا باعث پیچیدگی اضافی شده.
- scope می‌تواند به تیم‌ها کمک کند استایل‌های محلی را بهتر مدیریت کنند.
- در پروژه‌های بزرگ، این ویژگی می‌تواند نگهداری را راحت‌تر کند.

## تمرین

در این تمرین یک بخش کارت بسازید که تنها استایل‌های خود را داشته باشد و به بخش‌های دیگر صفحه منتقل نشود.

مراحل انجام تمرین:

1. در HTML یک کارت (`div`) با عنوان، پاراگراف و دکمه ایجاد کنید.

2. در CSS از `@scope (.card)` برای محدود کردن استایل‌ها استفاده کنید.

3. داخل `@scope (.card)` این موارد را بنویسید:
   - عنوان با اندازه و وزن مناسب.
   - پاراگراف با خط فاصله و رنگ خوانا.
   - دکمه با رنگ زمینه، شعاع گوشه و padding.
   - حاشیه (`border`) و فاصله داخلی (`padding`) برای کارت.

4. خارج از `@scope` استایل‌های دیگری برای صفحه بنویسید تا مطمئن شوید استایل‌های کارت به آن‌ها سرایت نمی‌کنند.

نتیجه نهایی:
یک کارت مستقل بسازید که استایل‌های آن داخل `@scope` تعریف شده و روی سایر عناصر صفحه تاثیری نداشته باشد.
