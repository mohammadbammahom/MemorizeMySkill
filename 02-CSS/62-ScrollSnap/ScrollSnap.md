# عنوان درس

## این مبحث چیست؟

- `scroll-snap` مجموعه‌ای از properties است که رفتار ثابت و قابل‌پیش‌بینی اسکرول در محورها را کنترل می‌کند و برای carousels و galleryها بسیار مناسب است.
- عناصر container باید `scroll-snap-type` داشته باشند و آیتم‌ها `scroll-snap-align`.

## این مبحث در بازار کار چرا مهم است؟

- بسیاری از UIs مدرن موبایل نیاز به پیمایش snap دارند؛ استفاده صحیح از این ویژگی تجربه کاربری را بهبود می‌بخشد و جایگزین JavaScript سنگین می‌شود.

## نکات مهم

- `scroll-snap-type` می‌تواند `mandatory` یا `proximity` باشد؛ در proximity مرورگر اجازه می‌دهد که کاربر با کمی لغزش به آیتم بعدی نرود.
- از `scroll-padding` و `scroll-snap-stop` برای کنترل بیشتر استفاده کن.

## مثال واقعی

- پیاده‌سازی carousel محصولات در صفحهٔ محصول که بدون JS و با `scroll-snap` واقعی رفتار swipe را ارائه می‌دهد.

## اشتباهات رایج

- عدم توجه به accessibility مانند کیبورد ناوبری و focus order.
- فرض اینکه scroll-snap همیشه جایگزین کامل JS است؛ در برخی تعامل‌های پیچیده نیاز به ترکیب است.

## چک لیست یادگیری

- [ ] `scroll-snap-type` را پیاده‌سازی کرده‌ام.
- [ ] `scroll-snap-align` را برای آیتم‌ها تعیین کردم.
- [ ] رفتار در موبایل و دسکتاپ را تست کرده‌ام.
