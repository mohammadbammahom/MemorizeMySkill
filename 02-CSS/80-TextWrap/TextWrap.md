# CSS Text Wrap
---
## این مبحث چیست؟
ویژگی `text-wrap` نحوه‌ی پیچش و برش متن را کنترل می‌کند. این ویژگی برای خواناتر کردن متن‌های طولانی و تنظیم نحوه‌ی نمایش خطوط در داخل کانتینرهای محدود مفید است.
---
## چرا از آن استفاده می‌کنیم؟
- برای بهبود خوانایی متن در ستون‌های باریک.
- برای کنترل نحوه‌ی تقسیم خطوط در متن‌های قابل پیچش.
- برای جلوگیری از خطوط نامتعادل در بلوک‌های متنی.
- برای انتخاب نحوه‌ی مدیریت فضای خالی دور متن.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم متن به صورت متعادل‌تر در چند خط نمایش داده شود:
```css
.article { text-wrap: balance; }
```
- وقتی می‌خواهیم متن در صورت نیاز حتماً پیچش پیدا کند:
```css
.article { text-wrap: wrap; }
```
- وقتی می‌خواهیم به متن اجازه دهیم خطوط بلند را بشکند:
```css
.article { text-wrap: normal; }
```
```
---
## چه زمانی نباید استفاده کنیم
- وقتی متن باید بدون شکستن نمایش داده شود.
```css
.title { text-wrap: none; }
```
- وقتی مرورگر یا محیط مورد نظر از آن پشتیبانی نمی‌کند.
- وقتی تنظیمات خط‌شکن پیش‌فرض کافی هستند.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `text-wrap` | کنترل پیچش متن | تعیین می‌کند متن چگونه لاین‌بریک شود |
| `white-space` | کنترل فاصله و شکست خط | بیشتر روی سفیدپوشی و شکستن کلمات اثر دارد |
| `word-break` | کنترل شکستن کلمات | مناسب خطوط طولانی و کلمات بزرگ است |
---
## بهترین روش‌های استفاده
- برای تیترها و پاراگراف‌های متنی از `text-wrap: balance` استفاده کنید.
- ترکیب `text-wrap` با `max-width` را تست کنید.
- در نمونه‌های responsive مطمئن شوید متن خوانا باقی می‌ماند.
- روی مرورگرهای مختلف پشتیبانی و رفتار را بررسی کنید.
---
## اشتباهات رایج
- ❌ استفاده از `text-wrap: none` در متن‌های طولانی.
- ❌ اعمال `text-wrap` بدون سنجش خوانایی.
- ❌ عدم توجه به رفتار موبایل و تبلت.
---
## نکات بازار کار
- `text-wrap` می‌تواند خوانایی محتوا را در طراحی‌های مدرن افزایش دهد.
- در مصاحبه باید بدانید چگونه متن بلند را با این ویژگی بهبود دهید.
- در بازبینی کد، بررسی کنید آیا متن روی عرض‌های کوچک به درستی نمایش داده می‌شود.
---

## تمرین
یک بلوک کارت متنی بسازید که با استفاده از `text-wrap` خطوط خوانا و متعادل داشته باشد.

مراحل انجام تمرین:

1. در HTML یک کارت شامل عنوان و یک پاراگراف طولانی تعریف کنید.
   - کارت را داخل `div` با کلاس مشخص قرار دهید.

2. در CSS این موارد را اعمال کنید:
   - برای کارت `max-width: 320px;` یا مقدار مشابه تعریف کنید.
   - برای پاراگراف از `text-wrap: balance;` استفاده کنید.
   - `padding` مناسب و `background-color` ملایم برای کارت انتخاب کنید.

3. رفتار responsive را بررسی کنید:
   - کارت باید در صفحه‌های کوچک نیز به صورت کامل نمایش داده شود.
   - اگر عرض صفحه کمتر شد، متن همچنان به خوبی شکسته شود.

4. ظاهر کلی کارت باید ساده و خوانا باشد:
   - فاصله خطوط (`line-height`) مناسب باشد.
   - عنوان و پاراگراف به خوبی جدا شوند.

نتیجه نهایی:
یک کارت متنی تولید کنید که در آن پاراگراف به کمک `text-wrap: balance` به صورت متعادل روی چند خط تقسیم می‌شود و کارت در صفحه‌های موبایل و دسکتاپ خوانا باقی می‌ماند.
