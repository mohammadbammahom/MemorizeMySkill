# عنوان درس

## این مبحث چیست؟

- CSS Masks (ماسک‌ها) به شما امکان می‌دهند که قسمت‌هایی از یک المان را با استفاده از تصویر یا گرادینت مخفی یا نمایش دهید. معمولاً با `mask-image`, `mask-size`, `mask-position` و معادل‌های WebKit استفاده می‌شود.

## این مبحث در بازار کار چرا مهم است؟

- ماسک‌ها ابزار قدرتمندی برای ایجاد افکت‌های تصویری و برش‌های خلاقانه بدون نیاز به ویرایش تصویر در سمت سرور یا ابزارهای گرافیکی هستند.
- در دیزاین‌های مدرن و landing pageها، ماسک‌ها جایگاه ویژه‌ای دارند.

## نکات مهم

- برای پشتیبانی بهتر از مرورگرها از prefixed properties (`-webkit-mask-image`) نیز استفاده کن.
- از گرادینت‌ها به‌عنوان mask-image برای افکت‌های نرم استفاده کن.
- همیشه نسخهٔ fallback ساده (مثلاً overlay یا clipped border-radius) در نظر بگیر.

## مثال واقعی

- در کارت‌های نمایش پروژه از mask برای fade-out کنارهٔ تصویر یا ایجاد شکل های غیرمستطیلی استفاده کن.

## اشتباهات رایج

- استفاده از ماسک برای محتوای مهم که باید قابل دسترسی باشد؛ ماسک فقط یک افکت بصری است و نباید ساختار اطلاعات را پنهان کند.
- اعتماد کامل به پشتیبانی همه مرورگرها بدون fallback.

## چک لیست یادگیری

- [ ] نحوهٔ استفاده از `mask-image` و `mask-size` را می‌دانم.
- [ ] fallback مناسب برای مرورگرهای قدیمی طراحی کرده‌ام.
- [ ] تست rendering در مرورگرهای مختلف انجام داده‌ام.
