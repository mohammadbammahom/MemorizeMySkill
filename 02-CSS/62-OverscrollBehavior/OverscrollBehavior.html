توضیحات

overscroll-behavior: auto - رفتار پیش‌فرض (اسکرول می‌تواند parent را تأثیر دهد)

overscroll-behavior: contain - اسکرول محدود است (تأثیر روی parent نمی‌گذارد)

overscroll-behavior: none - تمام overscroll behavior غیرفعال است
