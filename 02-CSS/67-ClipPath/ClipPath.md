# CSS Clip Path
---
## این مبحث چیست؟
CSS Clip Path به شما اجازه می‌دهد که یک عنصر را به شکل‌های هندسی یا مسیرهای دلخواه ببرید. این یعنی فقط بخش مشخصی از عنصر نشان داده می‌شود و باقی قسمت‌ها مخفی می‌ماند.
---
## چرا از آن استفاده می‌کنیم؟
- برای ایجاد اشکال کارت، تصویر و بنر بدون نیاز به تصاویر اختصاصی.
- برای ساختن عناصر تزئینی با خطوط واضح و هندسی.
- برای نمایش بخش‌های خاص از تصاویر یا محتوای عناصر.
- برای طراحی رابط کاربری مدرن و غیرمستطیلی.
---
## چه زمانی استفاده می‌کنیم
- وقتی بخواهیم تصویر پروفایل را دایره‌ای نمایش دهیم:
```css
.avatar {
  clip-path: circle(50% at 50% 50%);
}
```
- وقتی کارت باید لبه‌های مورب یا موجی داشته باشد:
```css
.card {
  clip-path: polygon(0 0, 100% 0, 100% 85%, 50% 100%, 0 85%);
}
```
- وقتی از یک SVG path برای شکل دقیق استفاده می‌کنیم:
```css
.banner {
  clip-path: path('M0,0 H100 V80 Q50 100 0 80 Z');
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی نیاز به نمایش کامل محتوای عنصر داریم.
```css
.text-box {
  clip-path: circle(40%);
}
```
- وقتی قصد داریم متن طولانی را داخل شکل قرار دهیم.
```css
.article {
  clip-path: polygon(0 0, 100% 0, 100% 60%, 0 60%);
}
```
- وقتی فقط می‌خواهیم گوشه‌ها را گرد کنیم.
```css
.card {
  clip-path: inset(0);
}
```
در این حالت `border-radius` مناسب‌تر است.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `clip-path` | بریدن عنصر به شکل مشخص | بخش خارج شکل پنهان می‌شود |
| `border-radius` | گرد کردن گوشه‌ها | فقط گوشه‌ها روان می‌شوند |
| `mask-image` | ایجاد ماسک با تصویر | میتواند قسمت‌های نیمه‌شفاف داشته باشد |
---
## بهترین روش‌های استفاده
- برای شکل‌های responsive از درصد استفاده کنید.
- اگر می‌خواهید انیمیت کنید، از `transition: clip-path` استفاده کنید.
- برای تصویرها از `clip-path: circle()` یا `polygon()` با درصد بهره ببرید.
- هنگامی که `pointer-events` مهم است، تداخل پنهان را بررسی کنید.
- برای سازگاری بهتر، در مرورگرهایی که پشتیبانی ناقص دارند fallback ساده داشته باشید.
---
## اشتباهات رایج
- ❌ استفاده از مسیر ناقص:
```css
.element {
  clip-path: polygon(50% 0%, 100% 100%);
}
```
- ❌ استفاده از `circle()` با اندازه ثابت در responsive:
```css
.avatar {
  clip-path: circle(40px at 50% 50%);
}
```
- ❌ اعمال روی متنی که باید انتخاب شود:
```css
.paragraph {
  clip-path: circle(50%);
}
```

## نکات بازار کار
- در پروژه‌های حرفه‌ای، `clip-path` برای کارت‌ها و بخش‌های معرفی استفاده می‌شود.
- در مصاحبه باید تفاوت آن با `mask-image` را توضیح دهید.
- در بازبینی کد، اثر روی دسترسی و تعامل را چک کنید.
- از `clip-path` روی محتوای حیاتی کمتر استفاده کنید.
- بهترین نتیجه با اشکال ساده و خوانا حاصل می‌شود.

## تمرین

در این تمرین یک کارت پروفایل طراحی کنید که از `clip-path` برای ایجاد شکل‌های مدرن استفاده کند.

مراحل انجام تمرین:

1. در HTML یک کارت بسازید که شامل موارد زیر باشد:
   - یک تصویر avatar.
   - عنوان پروفایل (`h2`).
   - یک زیرعنوان یا نقش کوتاه.
   - یک دکمه.

2. در CSS برای تصویر avatar موارد زیر را اعمال کنید:
   - `clip-path: circle(50% at 50% 50%);`
   - یک `width` و `height` مشخص برای تصویر.

3. پس‌زمینه کارت را با `clip-path: polygon(...)` شکل دهید:
   - لبه پایین کارت به صورت مورب یا زاویه‌دار باشد.
   - کارت دارای `border-radius` یا `overflow: hidden` باشد تا شکل تمیز بماند.

4. کارت باید واکنش‌گرا باشد:
   - روی موبایل محتوا به صورت ستونی قرار گیرد.
   - اندازه متن و تصویر با صفحه سازگار شود.

5. یک افکت hover ساده اضافه کنید:
   - کارت کمی بزرگ‌تر شود یا سایه آن قوی‌تر شود.

نتیجه نهایی:
یک کارت پروفایل مدرن بسازید که شامل تصویر گرد، بدنه کارت با لبه مورب و یک دکمه است؛ کارت باید هم روی موبایل و هم دسکتاپ خوانا و چشم‌نواز باشد.
