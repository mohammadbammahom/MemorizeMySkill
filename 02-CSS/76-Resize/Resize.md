# CSS Resize
---
## این مبحث چیست؟
ویژگی `resize` در CSS کنترل می‌کند که یک عنصر قابل تغییر اندازه باشد یا خیر و در چه جهتی این تغییر انجام شود. این ویژگی معمولاً برای textareaها و برخی عناصر بلوکی استفاده می‌شود.
---
## چرا از آن استفاده می‌کنیم؟
- برای اجازه دادن یا جلوگیری از تغییر اندازه المان‌ها.
- برای حفظ طراحی ثابت هنگام نمایش فرم.
- برای کنترل جهت تغییر اندازه (horizontal، vertical یا هر دو).
- برای بهبود تجربه کاربری در کنترل‌های متنی.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم textarea قابل تغییر باشد:
```css
textarea {
  resize: vertical;
}
```
- وقتی نیاز داریم textarea در جهت خاصی قابل تغییر باشد:
```css
textarea {
  resize: horizontal;
}
```
- وقتی می‌خواهیم تغییر اندازه را غیرفعال کنیم:
```css
textarea {
  resize: none;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی تغییر اندازه باعث شکستن طرح می‌شود.
```css
.card { resize: both; }
```
- وقتی element دیگر باید ثابت بماند.
```css
.header { resize: none; }
```
- وقتی مرورگر قدیمی هدف است و پشتیبانی محدود دارد.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `resize` | کنترل تغییر اندازه | تعیین می‌کند کاربر می‌تواند اندازه را تغییر دهد |
| `width/height` | اندازه پایه | مقدار اولیه را مشخص می‌کند |
| `overflow` | مدیریت محتوا | با resize برای کنترل ظاهر استفاده می‌شود |
---
## بهترین روش‌های استفاده
- تغییر اندازه را فقط روی textarea یا المان‌های منطقی بگذارید.
- با `max-width` و `max-height` محدودیت تعریف کنید.
- هنگام استفاده از `resize: none` از اسکرول داخلی پشتیبانی کنید.
- رفتار resize را در موبایل نیز تست کنید.
---
## اشتباهات رایج
- ❌ اجازه دادن به تغییر اندازه روی عناصر کوچک:
```css
.box { resize: both; }
```
- ❌ غیرفعال کردن resize بدون ارائه راه جایگزین برای محتوای طولانی.
- ❌ استفاده‌ی ناهماهنگ با layout responsive.
---
## نکات بازار کار
- در فرم‌های پیشرفته، کنترل تغییر اندازه تجربه کاربری را بهبود می‌دهد.
- در مصاحبه باید تفاوت `resize: none` و `resize: vertical` را توضیح دهید.
- در بازبینی کد بررسی کنید آیا محدودیت‌های `max-width` و `max-height` تنظیم شده‌اند.

## تمرین
یک بخش ورودی متنی (`textarea`) بسازید که تنها در جهت عمودی قابل تغییر باشد و از شکست طرح صفحه جلوگیری کند.

مراحل انجام تمرین:

1. در HTML یک `textarea` داخل یک `form` یا `div` قرار دهید.
   - یک برچسب (`label`) مناسب برای آن ایجاد کنید.

2. در CSS این قوانین را اعمال کنید:
   - `resize: vertical;`
   - `min-height: 120px;`
   - `max-height: 280px;`
   - `width: 100%;` تا در عرض‌های مختلف اندازه‌ی خود را تنظیم کند.

3. محدودیت‌های اضافی برای طراحی بهتر بنویسید:
   - `padding` مناسب برای فضای داخلی.
   - `border-radius` ملایم و `border` یا `box-shadow` ساده.
   - اگر محتوای زیاد وارد شد، `overflow: auto;` برای اسکرول داخلی تعریف کنید.

4. رفتار responsive را بررسی کنید:
   - در صفحه‌های موبایل textarea باید به‌صورت کامل در عرض قابل نمایش باشد.
   - ارتفاع آن هنگام افزایش محتوا قابل رشد باشد ولی از `max-height` تجاوز نکند.

نتیجه نهایی:
یک فیلد textarea بسازید که به‌صورت عمودی قابل تغییر اندازه باشد، در موبایل و دسکتاپ به‌خوبی نمایش داده شود و از خراب شدن طرح صفحه جلوگیری کند.
