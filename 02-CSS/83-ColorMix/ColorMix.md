# CSS Color Mix
---
## این مبحث چیست؟
تابع `color-mix()` امکان ترکیب دو رنگ را در CSS فراهم می‌کند. این تابع به شما اجازه می‌دهد رنگ‌های دقیق‌تری بسازید و افکت‌های پیچیده‌تری ایجاد کنید.
---
## چرا از آن استفاده می‌کنیم؟
- برای تولید رنگ‌های میان‌رنگی پویا.
- برای ساخت گرادیانت‌ها و حالت‌های hover بهتر.
- برای حفظ هماهنگی رنگ‌ها با قوانین برند.
- برای استفاده در CSS سفارشی بدون جاوااسکریپت.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم دو رنگ را با نسبت مشخص ترکیب کنیم:
```css
.button {
  background: color-mix(in srgb, #ff0000 60%, #0000ff 40%);
}
```
- وقتی می‌خواهیم رنگ متن را از ترکیب دو رنگ بسازیم:
```css
.text {
  color: color-mix(in display-p3, red 50%, white 50%);
}
```
- وقتی می‌خواهیم یک حالت hover ملایم بسازیم:
```css
.button:hover {
  background: color-mix(in srgb, #007bff 80%, black 20%);
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی کافی است از یک رنگ ثابت استفاده کنیم.
- وقتی پشتیبانی مرورگر محدود است و fallback نداریم.
- وقتی ترکیب رنگ‌ها باعث خوانایی ضعیف می‌شود.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `color-mix()` | ترکیب دو رنگ | خروجی یک رنگ جدید است |
| `mix-blend-mode` | ترکیب لایه‌ها | روی ترکیب دو لایه کار می‌کند |
| `rgba()` | تعیین رنگ با شفافیت | رنگ ثابت ایجاد می‌کند |
---
## بهترین روش‌های استفاده
- هنگام ترکیب رنگ، فضای رنگی مناسب (`srgb` یا `display-p3`) را انتخاب کنید.
- برای hover و حالت‌های فعال رنگ‌های نزدیک به هم استفاده کنید.
- با `color-mix` رنگ‌های برند را دقیق‌تر بسازید.
- از fallback رنگ ساده برای مرورگرهای قدیمی استفاده کنید.
---
## اشتباهات رایج
- ❌ ترکیب رنگ‌ها بدون توجه به قابل خواندن بودن متن.
- ❌ انتخاب درصدهای نامناسب که رنگ نهایی را نامتعادل می‌کند.
- ❌ عدم تعیین فضای رنگ برای رنگ‌هایی با gamut بالا.
---
## نکات بازار کار
- در طراحی مدرن، `color-mix()` به تولید پالت‌های دقیق کمک می‌کند.
- در مصاحبه باید تفاوت آن با ترکیب رنگ‌های CSS دیگر را توضیح دهید.
- در بازبینی کد بررسی کنید آیا ترکیب رنگ‌ها با رنگ برند همخوانی دارد.

## تمرین
یک دکمه سفارشی طراحی کنید که پس‌زمینه آن با `color-mix()` ساخته شده باشد.

مراحل انجام تمرین:

1. در HTML یک دکمه (`button`) ساده ایجاد کنید.
   - متن دکمه می‌تواند مثلاً «مشاهده بیشتر» باشد.

2. در CSS برای دکمه پس‌زمینه‌ای با `color-mix(in srgb, #0623ff 70%, #00bfff 30%)` تعریف کنید.

3. حالت hover دکمه را با یک ترکیب رنگ کمی تیره‌تر بسازید:
   - از `color-mix(in srgb, #0623ff 80%, #000000 20%)` یا مقدار مشابه استفاده کنید.

4. برای متن دکمه رنگی انتخاب کنید که کنتراست کافی داشته باشد و خوانا باشد.
   - به‌عنوان مثال `color: white;` یا `color: #f8f9fa;`.

5. دکمه را با `padding`, `border-radius`, `transition` و `box-shadow` کمی شکیل کنید.

نتیجه نهایی:
یک دکمه مدرن بسازید که پس‌زمینه آن به کمک `color-mix()` ترکیب شده، حالت hover آن به صورت ملایم تغییر رنگ می‌دهد و متن دکمه روی آن خوانا باقی می‌ماند.
