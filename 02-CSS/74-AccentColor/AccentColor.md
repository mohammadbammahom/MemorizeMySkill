# CSS Accent Color
---
## این مبحث چیست؟
CSS Accent Color یک ویژگی است که اجازه می‌دهد رنگ پیش‌فرض اجزای فرم مانند checkbox و radio را تغییر دهید. این ویژگی کمک می‌کند طراحی فرم با رنگ‌بندی کلی سایت سازگارتر شود.
---
## چرا از آن استفاده می‌کنیم؟
- برای هماهنگ کردن اجزای فرم با برند سایت.
- برای بهبود ظاهر پیش‌فرض checkbox و radio.
- برای ساده‌تر کردن سفارشی‌سازی فرم بدون نیاز به HTML اضافی.
- برای افزایش خوانایی و تطابق رنگ در فرم‌ها.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم رنگ checkbox را تغییر دهیم:
```css
input[type="checkbox"] {
  accent-color: #1a73e8;
}
```
- وقتی رنگ radio button را با تم سایت یکپارچه می‌کنیم:
```css
input[type="radio"] {
  accent-color: #ff4500;
}
```
- وقتی می‌خواهیم slider یا progress هم با رنگ جدید نمایش داده شود:
```css
input[type="range"] {
  accent-color: #22c55e;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی مرورگرهای قدیمی هدف هستند.
```css
input[type="checkbox"] { accent-color: #ff0000; }
```
- وقتی طراحی فرم نیاز به سفارشی‌سازی کامل دارد.
```css
.custom-checkbox { background: #000; }
```
- وقتی بخش‌های فرم باید رنگ‌های متفاوت و پیچیده داشته باشند بدون هماهنگی.
```css
input[type="radio"] { accent-color: pink; }
```
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `accent-color` | رنگ فرم‌های تعاملی | فقط روی عناصر فرم داخلی تاثیر دارد |
| `color` | رنگ متن | روی خود المان‌های فرم مستقیماً اثر ندارد |
| `background-color` | رنگ پس‌زمینه | روی ظاهر کنترل‌های فرم داخلی تاثیر ندارد |
---
## بهترین روش‌های استفاده
- از رنگ‌های برند برای `accent-color` استفاده کنید.
- برای رنگ‌های روشن و تیره، خوانایی را بررسی کنید.
- برای عناصر فرم مختلف رنگ متناسب انتخاب کنید.
- اگر مرورگر پشتیبانی نکرد، استایل‌های fallback تعریف کنید.
---
## اشتباهات رایج
- ❌ انتخاب رنگی که با پس‌زمینه تداخل دارد:
```css
input[type="checkbox"] { accent-color: #ffffff; }
```
- ❌ فرض اینکه `accent-color` روی همه مرورگرها کار می‌کند:
```css
input[type="radio"] { accent-color: #000; }
```
- ❌ استفاده از رنگ‌های ناخوانا در حالت انتخاب شده:
```css
input[type="checkbox"] { accent-color: #ffcccc; }
```
---
## نکات بازار کار
- در پروژه‌های حرفه‌ای، `accent-color` برای فرم‌های مدرن استفاده می‌شود.
- در مصاحبه باید بدانید کدام inputها را پوشش می‌دهد.
- در بازبینی کد بررسی کنید استایل فرم با تم کلی مطابقت دارد.
- برای طرح‌های برندینگ، رنگ فرم باید همگام با رابط کاربری باشد.

## تمرین

در این تمرین یک بخش فرم بسازید که از `accent-color` برای کنترل‌های فرم استفاده کند.

مراحل انجام تمرین:

1. در HTML یک فرم با موارد زیر ایجاد کنید:
   - یک checkbox با برچسب (`label`).
   - یک radio button با برچسب.
   - یک input از نوع range با برچسب.

2. در CSS از `accent-color` برای هر کنترل استفاده کنید:
   - `input[type="checkbox"] { accent-color: #1a73e8; }`
   - `input[type="radio"] { accent-color: #ff4500; }`
   - `input[type="range"] { accent-color: #22c55e; }`

3. استایل فرم را به صورت منظم و خوانا تنظیم کنید:
   - فاصله بین هر ردیف ورودی کافی باشد.
   - برچسب‌ها واضح و نزدیک به کنترل‌ها قرار گیرند.

4. مطمئن شوید هر کنترل با طراحی کلی فرم هماهنگ شود و نمایش آن در مرورگر قابل فهم باشد.

نتیجه نهایی:
یک فرم تمیز بسازید که checkbox، radio و range هر کدام رنگ مشخص داشته باشند و استایل کلی بخش فرم حرفه‌ای و منظم باشد.
