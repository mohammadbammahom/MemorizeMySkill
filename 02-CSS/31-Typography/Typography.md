# عنوان درس

## این مبحث چیست؟

- `font-family` خانواده‌ی تایپ‌فیس را مشخص می‌کند.
- `font-size` اندازه‌ی متن را کنترل می‌کند.
- `font-weight` ضخامت فونت را تعیین می‌کند.
- `font-style` حالت ایتالیک یا normal را فعال می‌کند.
- `line-height` ارتفاع خط برای خوانایی بهتر است.
- `letter-spacing` و `word-spacing` فاصله‌ی حروف و کلمات را تنظیم می‌کنند.
- `text-align` و `text-transform` جهت و تبدیل متن را کنترل می‌کنند.
- `text-decoration` خط زیر یا خط‌خورده را اضافه می‌کند.
- `text-indent` تورفتگی اولین خط پاراگراف را تعیین می‌کند.
- `text-wrap` نحوه‌ی شکستن و پیچیدن متن را کنترل می‌کند.

## چرا از آن استفاده می‌کنیم؟

- برای افزایش خوانایی و سطرخوانی بهتر
- برای ساخت hierarchy قوی در UI
- برای تبدیل ظاهری متن به حالت‌های حرفه‌ای و برندمحور
- برای بهبود تجربه‌ی خواندن در landing page و articleها

## چه زمانی استفاده می‌کنیم؟

- وقتی با content-heavy pages کار می‌کنیم
- وقتی hero text یا pricing section باید strong hierarchy داشته باشد
- وقتی typography باید خوانا، شیک و قابل‌اسکن باشد

## چه زمانی نباید استفاده کنیم؟

- وقتی font family و spacing به‌صورت تصادفی تنظیم می‌شوند
- وقتی متن با اندازه‌های خیلی کوچک یا line-height خیلی کم ساخته می‌شود
- وقتی text-align و transform بدون intent استفاده می‌شوند

## تفاوت با روش‌های مشابه

- `font-size` برای اندازه‌ی متن است، نه برای container.
- `line-height` و `letter-spacing` بیشتر روی rhythm و readability اثر دارند.
- `text-transform` فقط ظاهر را تغییر می‌دهد، نه semantic content.
- `text-wrap` برای رفتار شکستن کلمات و خطوط استفاده می‌شود.

## بهترین روش‌های استفاده

- برای text-heavy layouts از scale hierarchy استفاده کن.
- `line-height` را به‌صورت قابل‌خواندن و متناسب با تایپ‌فیس نگه دار.
- در titles از `font-weight` و `letter-spacing` با restraint استفاده کن.
- برای pricing page، headline و CTA از typography intentional استفاده کن.

## اشتباهات رایج

- استفاده از چند font family بدون intention
- اعمال `letter-spacing` زیاد روی متن‌های بلند
- غفلت از `line-height` برای Readability
- استفاده از `text-transform` برای همه‌ی text‌ها بدون نیاز

## نکات بازار کار

- در بازارکار، typography جزو مهارت‌های مهم UI polish است.
- Front-End engineer باید بتواند hierarchy پنج‌گانه‌ی متن را در کامپوننت‌ها مدیریت کند.
- در interviewها، این موضوع معمولاً با readability، consistency و accessibility ترکیب می‌شود.

## چک‌لیست یادگیری

- [ ] `font-family`، `font-size` و `font-weight` را به درستی می‌نویسم.
- [ ] `line-height` و `letter-spacing` را برای خوانایی تنظیم می‌کنم.
- [ ] `text-align` و `text-transform` را هدفمند به کار می‌برم.
- [ ] typography hierarchy در یک realistic page می‌سازم.
