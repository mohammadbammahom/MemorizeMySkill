# CSS Backdrop Filter
---
## این مبحث چیست؟
CSS Backdrop Filter یک ویژگی CSS است که به شما اجازه می‌دهد فیلترهایی مانند blurry، brightness و contrast را روی محتوای پشت یک عنصر اعمال کنید. این یعنی خود عنصر شفاف یا نیمه‌شفاف است و پشت آن به صورت مات یا فیلترشده دیده می‌شود.
---
## چرا از آن استفاده می‌کنیم؟
- برای ایجاد جلوه‌های glassmorphism و کارت‌های شیشه‌ای.
- برای جدا کردن محتوا از پس‌زمینه اما حفظ دید به پشت.
- برای افزایش حس عمق در رابط کاربری.
- برای نمایش مودال‌ها و منوهای شفاف با کیفیت طراحی بالا.
---
## چه زمانی استفاده می‌کنیم
- وقتی بخواهیم یک کارت اطلاعاتی شفاف روی تصویر پس‌زمینه نمایش دهیم:
```css
.glass-card {
  background: rgba(255, 255, 255, 0.25);
  backdrop-filter: blur(12px);
}
```
- وقتی یک navbar ثابت روی محتوا داریم:
```css
.navbar {
  background: rgba(255, 255, 255, 0.5);
  backdrop-filter: blur(10px);
}
```
- وقتی مودالی می‌خواهیم که پس‌زمینه پشت آن تار شود:
```css
.modal {
  background: rgba(0, 0, 0, 0.35);
  backdrop-filter: blur(15px) brightness(0.9);
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی محتوای پشت عنصر باید کاملاً واضح بماند.
```css
.header {
  backdrop-filter: blur(30px);
}
```
این مقدار زیاد باعث محو شدن بیش از حد می‌شود.
- وقتی عملکرد صفحه مهم است.
```css
.page {
  backdrop-filter: blur(20px);
}
```
در دستگاه‌های ضعیف ممکن است لگ ایجاد شود.
- وقتی پس‌زمینه کاملاً تاریک یا سفید است.
```css
.overlay {
  backdrop-filter: brightness(1.2);
}
```
بدون پس‌زمینه نیمه‌شفاف اثر واضح نمی‌شود.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `backdrop-filter` | فیلتر روی محتوا پشت عنصر | پشت عنصر را مات می‌کند |
| `filter` | فیلتر روی خود عنصر | خود عنصر را تغییر می‌دهد |
| `opacity` | تنظیم شفافیت کل عنصر | تمام محتوا و لایه را شفاف می‌کند |
---
## بهترین روش‌های استفاده
- از `background: rgba(...)` یا `background: hsla(...)` با شفافیت استفاده کنید.
- از `backdrop-filter: blur()` در لایه‌های محدود و مشخص بهره ببرید.
- برای سازگاری مرورگر `-webkit-backdrop-filter` را اضافه کنید.
- مقدار blur را معمولاً بین `6px` تا `16px` نگه دارید.
- همیشه در موبایل و دسکتاپ تست کنید.
---
## اشتباهات رایج
- ❌ بدون پس‌زمینه نیمه‌شفاف:
```css
.glass {
  backdrop-filter: blur(10px);
}
```
- ❌ مقدار blur زیاد:
```css
.modal {
  backdrop-filter: blur(30px);
}
```
- ❌ استفاده روی کل صفحه:
```css
body {
  backdrop-filter: blur(20px);
}
```
- ❌ فراموش کردن پیش‌وند WebKit:
```css
.card {
  backdrop-filter: blur(10px);
}
```

## تمرین

در این تمرین یک کارت glassmorphism بسازید که روی پس‌زمینه‌ای مات قرار دارد.

مراحل انجام تمرین:

1. در HTML یک کارت (`div`) ایجاد کنید که شامل موارد زیر باشد:
   - یک عنوان (`h2`).
   - یک پاراگراف کوتاه.
   - یک دکمه.

2. در CSS برای کارت این موارد را اعمال کنید:
   - `background: rgba(255, 255, 255, 0.25);`
   - `backdrop-filter: blur(12px);`
   - `-webkit-backdrop-filter: blur(12px);`
   - یک `border` با شفافیت کم و `border-radius` نرم.
   - یک `box-shadow` ملایم برای جدا شدن کارت از پس‌زمینه.

3. کارت باید واکنش‌گرا باشد:
   - در موبایل عرض کارت کمتر شود.
   - اندازه متن و فاصله داخلی کارت متناسب با صفحه تغییر کند.

4. برای حالت نشانه‌گیری موس (`hover`) استایل زیر را اضافه کنید:
   - مقدار `filter` یا `background-color` کمی روشن‌تر شود.
   - کارت کمی شناور‌تر به نظر برسد.

نتیجه نهایی:
یک کارت شیشه‌ای مدرن بسازید که روی یک پس‌زمینه تار قرار دارد، متن واضح است و کارت در موبایل و دسکتاپ به درستی نمایش داده می‌شود.
