# CSS Motion Path
---
## این مبحث چیست؟
CSS Motion Path یک مجموعه ویژگی CSS است که به شما اجازه می‌دهد عناصر را روی مسیرهای تعریف‌شده حرکت دهید. مسیر می‌تواند خطی، منحنی یا SVG path باشد و با انیمیشن‌های معمولی تفاوت دارد.
---
## چرا از آن استفاده می‌کنیم؟
- برای ساخت انیمیشن‌های حرکتی دقیق و طبیعی.
- برای حرکت دادن اشیاء به صورت غیرخطی بدون JavaScript اضافی.
- برای طراحی بخش‌های تعاملی و تزئینی در رابط کاربری.
- برای انتقال عناصر به صورت داینامیک و هنری.
---
## چه زمانی استفاده می‌کنیم
- وقتی یک آیکون باید روی یک منحنی حرکت کند:
```css
.icon {
  offset-path: path('M0,0 C100,100 200,-100 300,0');
  animation: travel 6s ease-in-out infinite;
}
```
- وقتی می‌خواهیم یک عنصر دور یک دایره بچرخد:
```css
.ball {
  offset-path: circle(50% at 50% 50%);
  offset-rotate: auto;
  animation: spin 4s linear infinite;
}
```
- وقتی باید یک المان از نقطه‌ای به نقطه دیگری حرکت کند:
```css
.element {
  offset-path: path('M0,0 L300,0');
  offset-distance: 100%;
  animation: move 3s forwards;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی حرکت ساده با `transform` کافی است.
```css
.button {
  transform: translateX(100px);
}
```
- وقتی پشتیبانی مرورگر برای پروژه حیاتی است.
```css
.popup {
  offset-path: path('M0,0 L100,100');
}
```
- برای عناصر تعاملی که باید به دقت کلیک شوند.
```css
.link {
  offset-path: circle(40%);
}
```
ممکن است رفتار کلیک غیرقابل پیش‌بینی شود.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `offset-path` | تعیین مسیر حرکت | مسیر حرکت را مشخص می‌کند |
| `offset-distance` | فاصله روی مسیر | موقعیت عنصر را روی مسیر تعیین می‌کند |
| `transform` | تغییر مکان ساده | نمی‌تواند مسیر پیچیده بسازد |
| `animation` | زمان‌بندی حرکت | مسیر را تعیین نمی‌کند |
---
## بهترین روش‌های استفاده
- از `offset-rotate: auto` برای چرخش طبیعی استفاده کنید.
- مسیرهای ساده و قابل درک بنویسید.
- سرعت انیمیشن را با `ease-in-out` یا `linear` کنترل کنید.
- برای وضوح بیشتر، مسیرهای SVG را تست کنید.
- روی مرورگرهای هدف خود پشتیبانی را بررسی کنید.
---
## اشتباهات رایج
- ❌ مسیر ناقص بدون endpoint:
```css
.element {
  offset-path: path('M0,0 C100,100');
}
```
- ❌ استفاده از `offset-distance` بدون انیمیشن:
```css
.icon {
  offset-distance: 0;
}
```
- ❌ عدم استفاده از `offset-rotate` برای اشیاء چرخان:
```css
.arrow {
  offset-path: circle(50%);
  offset-rotate: 0deg;
}
```
- ❌ حرکت روی عنصر تعاملی بدون توجه به نقاط کلیک:
```css
.button {
  offset-path: path('M0,0 L100,0');
}
```

## تمرین

در این تمرین یک انیمیشن حرکت دایره‌ای با Motion Path بسازید.

مراحل انجام تمرین:

1. در HTML یک کانتینر و یک عنصر کوچک متحرک قرار دهید.
   - عنصر متحرک می‌تواند یک `div` مربع یا دایره با آیکون یا متن کوتاه باشد.

2. در CSS موارد زیر را اعمال کنید:
   - روی کانتینر `position: relative;` تعریف کنید.
   - برای عنصر متحرک از `position: absolute;` استفاده کنید.
   - از `offset-path: circle(40% at 50% 50%);` برای مسیر حرکت دایره‌ای استفاده کنید.
   - `offset-rotate: auto;` را اضافه کنید تا عنصر در طول مسیر چرخش طبیعی داشته باشد.
   - انیمیشن `animation: move 6s linear infinite;` یا مشابه تعریف کنید.

3. ظاهر عنصر متحرک را مشخص کنید:
   - یک پس‌زمینه رنگی، حاشیه نرم و سایه ملایم داشته باشد.
   - داخل آن یک متن کوتاه یا آیکون قرار دهید.

4. سازگاری موبایل را حفظ کنید:
   - حجم کانتینر و مسیر حرکت روی صفحه‌های کوچک نیز قابل نمایش باشد.
   - اندازه عنصر متحرک در موبایل مناسب باشد.

نتیجه نهایی:
یک دمو حرکت دایره‌ای بسازید که عنصر داخل مسیر دایره‌ای به طور پیوسته حرکت کند، با چرخش طبیعی و ظاهری حرفه‌ای.
