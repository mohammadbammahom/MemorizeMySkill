# CSS SVG Filters
---
## این مبحث چیست؟
فیلترهای SVG مجموعه‌ای از افکت‌های تصویری هستند که می‌توانند روی عناصر HTML و SVG اعمال شوند. این فیلترها شامل تار شدن، تغییر رنگ، سایه و جلوه‌های خلاقانه‌تر هستند.
---
## چرا از آن استفاده می‌کنیم؟
- برای افزودن افکت‌های پیچیده بصری.
- برای ساختن پس‌زمینه‌ها و تصاویر با جلوه‌های خاص.
- برای ترکیب محتوای SVG با عناصر HTML.
- برای ایجاد طراحی‌های چشم‌نواز و حرفه‌ای.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم یک افکت blur به تصویر بدهیم:
```css
.image {
  filter: blur(5px);
}
```
- وقتی می‌خواهیم یک افکت خاکستری روی عنصر اعمال کنیم:
```css
.image {
  filter: grayscale(100%);
}
```
- وقتی می‌خواهیم چند افکت را ترکیب کنیم:
```css
.image {
  filter: drop-shadow(0 10px 10px rgba(0,0,0,0.25)) brightness(0.9);
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی فیلترها عملکرد صفحه را کند می‌کنند.
```css
.hero { filter: blur(10px); }
```
- وقتی افکت فقط برای زیبایی است و نیاز واقعی ندارد.
- وقتی محتوای مهم باید واضح باقی بماند.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `filter` | اعمال افکت بصری | روی عناصر HTML و SVG کار می‌کند |
| `box-shadow` | سایه‌ی ساده | فقط سایه می‌سازد |
| `background-blend-mode` | ترکیب پس‌زمینه | روی رنگ پس‌زمینه اثر دارد |
---
## بهترین روش‌های استفاده
- فیلترها را فقط زمانی استفاده کنید که افزودن ارزش بصری داشته باشد.
- افکت‌ها را به صورت ترکیبی و با دقت انتخاب کنید.
- عملکرد را هنگام استفاده از فیلترهای سنگین تست کنید.
- برای محتوای متنی، وضوح و خوانایی را حفظ کنید.
---
## اشتباهات رایج
- ❌ استفاده از فیلترهای سنگین روی تصاویر پس‌زمینه بزرگ.
- ❌ ترکیب تعداد زیادی فیلتر بدون نیاز واقعی.
- ❌ انتقال ناگهانی افکت‌ها بدون smoothness.
---
## نکات بازار کار
- در طراحی مدرن، filter می‌تواند ظاهر حرفه‌ای‌تر ایجاد کند.
- در مصاحبه باید تفاوت بین `filter` و SVG filter primitives را بدانید.
- در بازبینی کد بررسی کنید آیا فیلترها عملکرد را تحت تأثیر قرار می‌دهند.

## تمرین
یک کارت تبلیغاتی طراحی کنید که از فیلترهای CSS برای بهبود ظاهر تصویر و تاکید روی متن استفاده می‌کند.

مراحل انجام تمرین:

1. در HTML یک کارت شامل تصویر، عنوان و دکمه ایجاد کنید.
   - تصویر می‌تواند داخل یک `div` یا `img` قرار گیرد.
   - عنوان و دکمه زیر تصویر یا روی تصویر قرار گیرند.

2. در CSS برای تصویر یا کارت از فیلترهای زیر استفاده کنید:
   - `filter: drop-shadow(0 10px 20px rgba(0,0,0,0.15)) brightness(0.9);`
   - اگر تصویر داخل `div` است، روی آن `background-image` با CSS تنظیم کنید.

3. یک افکت hover ملایم اضافه کنید:
   - هنگام hover تصویری با `filter: grayscale(20%);` یا مشابه ظاهر شود.
   - متن یا دکمه روی تصویر همچنان خوانا باقی بماند.

4. طراحی کارت باید حرفه‌ای و متعادل باشد:
   - فضای داخلی مناسب و `border-radius` داشته باشد.
   - رنگ متن و دکمه باید با تصویر سازگار باشد.

نتیجه نهایی:
یک کارت تبلیغاتی بسازید که تصویر آن با فیلترهای drop-shadow و brightness کمی تیره شده، هنگام hover ملایمی داشته باشد و بخش‌های متنی آن همیشه خوانا باقی بمانند.
