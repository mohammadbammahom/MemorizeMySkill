# CSS Place Items
---
## این مبحث چیست؟
ویژگی `place-items` یک میانبر برای تنظیم هم‌ترازسازی عمودی و افقی در grid و flexbox است. این ویژگی می‌تواند `align-items` و `justify-items` را با یک مقدار واحد مشخص کند.
---
## چرا از آن استفاده می‌کنیم؟
- برای ساده کردن هم‌ترازسازی محتوای داخلی شبکه.
- برای کاهش تعداد قوانین CSS.
- برای تنظیم سریع چیدمان آیتم‌ها در grid یا flex container.
- برای ایجاد افقی و عمودی مرکزی راحت‌تر.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم آیتم‌های داخل grid را مرکز کنیم:
```css
.grid {
  display: grid;
  place-items: center;
}
```
- وقتی می‌خواهیم آیتم‌ها به طور عمودی و افقی هم‌تراز شوند:
```css
.grid {
  place-items: start stretch;
}
```
- وقتی می‌خواهیم تنظیمات align و justify را با یک دستور انجام دهیم:
```css
.grid {
  place-items: center start;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی نیاز به تنظیم جداگانه `align-items` و `justify-items` داریم.
- وقتی container از flexbox استفاده می‌کند و `justify-items` پشتیبانی نمی‌شود.
- وقتی می‌خواهیم فقط یک جهت را تغییر دهیم.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `place-items` | تنظیم هم‌ترازسازی | میانبر برای align-items و justify-items |
| `align-items` | هم‌ترازسازی عمودی | فقط یک جهت را تنظیم می‌کند |
| `justify-items` | هم‌ترازسازی افقی | فقط جهت دیگر را تنظیم می‌کند |
---
## بهترین روش‌های استفاده
- برای مواردی که هر دو جهت باید هماهنگ شوند `place-items` را استفاده کنید.
- در grid از آن بیشتر استفاده می‌شود.
- اگر به یک جهت خاص نیاز دارید، ویژگی اصلی را استفاده کنید.
- در طرح‌های card و modalها برای قرار دادن محتوای مرکزی مفید است.
---
## اشتباهات رایج
- ❌ استفاده از `place-items` در flex container بدون توجه به پشتیبانی.
- ❌ فرض اینکه `place-items` همیشه هر دو جهت را در همه مرورگرها کنترل می‌کند.
- ❌ استفاده از مقدار نادرست مانند `place-items: center center` به جای `center`.
---
## نکات بازار کار
- در طراحی grid layout، `place-items` کد را کوتاه و خواناتر می‌کند.
- در مصاحبه باید بدانید چه زمانی از این میانبر استفاده بهتری دارد.
- در بازبینی کد، دقت کنید آیا `place-items` مناسب یا `align-items`/`justify-items` جداگانه بهتر است.

## تمرین
یک کارت را در وسط صفحه قرار دهید به طوری که محتوای درون آن هم عمودی و هم افقی مرکز باشد.

مراحل انجام تمرین:

1. در HTML یک بخش wrapper ایجاد کنید و داخل آن یک کارت (`div`) با عنوان و دکمه قرار دهید.

2. در CSS برای wrapper از `display: grid;` استفاده کنید.
   - `place-items: center;` را روی wrapper اعمال کنید.
   - عرض wrapper را به اندازه‌ای قرار دهید که کارت در مرکز صفحه قرار گیرد.

3. برای کارت استایل‌های پایه بنویسید:
   - `background-color`, `border-radius`, `padding`, `box-shadow`.
   - فضای داخلی کافی برای عنوان و دکمه تعریف کنید.

4. از کارت در صفحه‌های کوچک نیز تست کنید تا محتوا همچنان مرکز قرار گیرد.

نتیجه نهایی:
یک کارت متمرکز بسازید که عنوان و دکمه آن به صورت عمودی و افقی در مرکز wrapper قرار داشته باشند و طراحی کارت ساده و قابل خواندن باشد.
