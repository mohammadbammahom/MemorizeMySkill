# CSS Appearance
---
## این مبحث چیست؟
ویژگی `appearance` به شما اجازه می‌دهد تا کنترل کنید یک عنصر فرم چگونه از ظاهر پیش‌فرض سیستم تقلید کند. این ویژگی برای حذف استایل پیش‌فرض مرورگر و ایجاد کنترل‌های فرم سفارشی بسیار مفید است.
---
## چرا از آن استفاده می‌کنیم؟
- برای حذف ظاهر پیش‌فرض دکمه‌ها، inputها و selectها.
- برای ساخت فرم‌های کاملاً سفارشی با استایل یکنواخت.
- برای هماهنگ کردن کنترل‌های فرم با طراحی سایت.
- برای کاهش وابستگی به استایل مرورگرها.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم دکمه و input را از ظاهر پیش‌فرض خارج کنیم:
```css
button,
input,
select {
  appearance: none;
}
```
- وقتی می‌خواهیم استایل دلخواه برای عناصر فرم ایجاد کنیم:
```css
input[type="range"] {
  appearance: none;
}
```
- وقتی می‌خواهیم مرورگر default styling را برداریم و کنترل را کامل طراحی کنیم:
```css
button {
  appearance: none;
  background: #0d6efd;
  color: white;
  border-radius: 8px;
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی می‌خواهیم کنترل فرم رفتار و ظاهر پیش‌فرض مرورگر را حفظ کند.
```css
button { appearance: auto; }
```
- وقتی کنترل فرم باید مانند system native باقی بماند.
- وقتی fallback برای مرورگرهای قدیمی تنظیم نشده است.
```css
select { appearance: none; }
```
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `appearance` | کنترل ظاهر پیش‌فرض سیستم | حذف یا بازگردانی استایل پیش‌فرض |
| `border-radius` | گوشه‌ها را گرد می‌کند | فقط شکل را تغییر می‌دهد |
| `background` | رنگ پس‌زمینه را تعیین می‌کند | روی ظاهر داخلی کنترل تأثیر دارد |
---
## بهترین روش‌های استفاده
- فقط روی عناصر فرم که واقعاً نیاز به تغییر دارند `appearance: none` بگذارید.
- بعد از حذف appearance، استایل کاملی برای عنصر تعریف کنید.
- برای دسترسی‌پذیری، focus و hover را فراموش نکنید.
- استایل فرم را برای مرورگرهای مختلف تست کنید.
---
## اشتباهات رایج
- ❌ حذف appearance بدون اضافه کردن استایل جایگزین:
```css
input { appearance: none; }
```
- ❌ فرض اینکه `appearance: none` همه مرورگرها را پوشش می‌دهد.
- ❌ حذف ظاهر پیش‌فرض بدون حفظ نشانه‌های تعاملی برای کاربر.
---
## نکات بازار کار
- در طراحی فرم حرفه‌ای، `appearance` به شما امکان می‌دهد کنترل‌های تمیز و مدرن بسازید.
- در مصاحبه، با بیان تفاوت بین `appearance: none` و `appearance: auto` امتیاز می‌گیرید.
- در بازبینی کد، بررسی کنید آیا کنترل فرم پس از حذف ظاهر پیش‌فرض هنوز قابل استفاده و دسترس‌پذیر است.
- برای طراحی سفارشی checkbox و radio معمولا `appearance` اولین قدم است.

## تمرین
یک فرم کنترل سفارشی بسازید که از `appearance` برای حذف استایل پیش‌فرض مرورگر استفاده کند.

مراحل انجام تمرین:

1. در HTML یک فرم ساده ایجاد کنید که شامل این عناصر باشد:
   - یک `button` برای ارسال یا اقدام.
   - یک `input` متنی.
   - هر دو عنصر در داخل یک `div` یا `form` قرار گیرند.

2. در CSS برای هر دو عنصر `button` و `input` از `appearance: none;` استفاده کنید.

3. پس از حذف استایل پیش‌فرض، این ویژگی‌ها را اعمال کنید:
   - `background-color` مشخص و هماهنگ با طراحی.
   - `border-radius` برای گوشه‌های نرم.
   - `padding` مناسب برای راحتی کلیک و تایپ.
   - `border` یا `box-shadow` ملایم برای برجسته‌سازی.

4. برای حالت فوکوس نیز استایل اضافه کنید:
   - `outline` یا `box-shadow` واضح باشد.
   - رنگ فوکوس با طراحی فرم هماهنگ باشد.

نتیجه نهایی:
یک فرم کنترل مدرن بسازید که متنی خوانا و دکمه‌ای حرفه‌ای داشته باشد. این فرم باید به گونه‌ای باشد که ظاهر پیش‌فرض مرورگر حذف شده و استایل جدید کاملاً مشخص، قابل استفاده و دسترس‌پذیر باشد.
