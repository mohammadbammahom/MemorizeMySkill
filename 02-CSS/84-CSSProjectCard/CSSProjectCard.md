# CSS Project Card
---
## این مبحث چیست؟
این پروژه یک کارت کاربردی CSS است که بر اساس استایل‌های مدرن طراحی شده. هدف آن نشان دادن چگونگی استفاده از سایه، گذار و چیدمان داخلی برای ساخت یک کارت حرفه‌ای است.
---
## چرا از آن استفاده می‌کنیم؟
- برای تمرین ساخت اجزای UI قابل استفاده.
- برای ترکیب افکت‌ها و استایل‌های مدرن.
- برای یادگیری طراحی کارت‌های responsive.
- برای ایجاد یک نمونه عملی که در portfolios نمایش داده شود.
---
## چه زمانی استفاده می‌کنیم
- وقتی می‌خواهیم کارت محصول یا مقاله طراحی کنیم:
```css
.card {
  background: white;
  border-radius: 16px;
  box-shadow: 0 18px 40px rgba(0,0,0,0.08);
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
  transform: translateY(-10px);
  box-shadow: 0 24px 50px rgba(0,0,0,0.12);
}
```
- وقتی می‌خواهیم محتوای داخل کارت خوب چینش پیدا کند:
```css
.card-content {
  padding: 24px;
  display: grid;
  gap: 16px;
}
```
- وقتی می‌خواهیم کارت responsive باشد:
```css
@media (max-width: 600px) {
  .card { padding: 18px; }
}
```
---
## چه زمانی نباید استفاده کنیم
- وقتی نیاز به کارت‌های فوق‌العاده ساده داریم.
- وقتی زیاده‌روی در افکت‌ها باعث شلوغ شدن طراحی می‌شود.
- وقتی عملکرد اولویت بالاتری نسبت به ظاهر دارد.
---
## تفاوت با ویژگی‌های مشابه
| ویژگی | کاربرد | تفاوت |
|-------|--------|-------|
| `box-shadow` | سایه دادن | عمق و جدایی کارت را نشان می‌دهد |
| `transition` | نرم کردن تغییرات | حرکت و hover را ملایم می‌کند |
| `border-radius` | گرد کردن گوشه‌ها | شکل کارت را تعیین می‌کند |
---
## بهترین روش‌های استفاده
- کارت را با فضای داخلی کافی و سایه ملایم طراحی کنید.
- hover و focus را برای تعامل بهتر اضافه کنید.
- از شبکه یا گرید برای چینش متن و دکمه استفاده کنید.
- کارت را در عرض‌های مختلف تست کنید.
---
## اشتباهات رایج
- ❌ سایه‌های خیلی تند یا سنگین.
- ❌ حداقل padding و فضای کم داخلی.
- ❌ استفاده از transformهای بزرگ روی hover.
---
## نکات بازار کار
- کارت‌های محصول و معرفی یکی از بخش‌های رایج در پروژه‌های وب هستند.
- در مصاحبه کارت‌هایی را نشان دهید که responsive و دارای تعامل خوب باشند.
- در بازبینی کد بررسی کنید کارت با بقیه رابط کاربری هماهنگ است.

## تمرین
یک کارت پروژه حرفه‌ای با استایل مدرن ایجاد کنید.

مراحل انجام تمرین:

1. در HTML یک کارت شامل موارد زیر بسازید:
   - یک عنوان پروژه (`h2`).
   - یک توضیح کوتاه در قالب پاراگراف.
   - یک دکمه فراخوانی اقدام.

2. در CSS برای کارت این موارد را اعمال کنید:
   - `box-shadow` ملایم برای جدا شدن کارت از پس‌زمینه.
   - `border-radius` برای گوشه‌های نرم.
   - `padding` داخلی مناسب.
   - `background-color` روشن یا متناسب با طراحی.

3. برای hover کارت این موارد را اضافه کنید:
   - `transform: translateY(-8px);` یا مقدار مشابه.
   - `transition: transform 0.3s ease, box-shadow 0.3s ease;`.
   - سایه کمی قوی‌تر یا واضح‌تر در حالت hover.

4. کارت باید responsive باشد:
   - در موبایل عرض کارت کامل شود.
   - فضای داخلی و اندازه متن با صفحه کوچک سازگار باشد.

نتیجه نهایی:
یک کارت پروژه تمیز و حرفه‌ای بسازید که در حالت hover کمی بالا بیاید، ظاهری نرم و مدرن داشته باشد و در موبایل و دسکتاپ قابل مشاهده باشد.
