# عنوان درس

## این مبحث چیست؟

- CSS زبان استایل‌دهی به عناصر HTML است.
- این زبان برای رنگ، فاصله، ترتیب، سایز، نمایش و واکنش‌پذیری استفاده می‌شود.
- در پروژه‌های واقعی، CSS به UI یک محصول نگاه ساختاری و حرفه‌ای می‌دهد.

## چرا از آن استفاده می‌کنیم؟

- برای جداسازی ظاهر از محتوای HTML
- برای ایجاد consistency در پروژه
- برای مدیریت design system و maintenance بهتر
- برای کنترل دقیق layout، spacing و stateها

## چه زمانی استفاده می‌کنیم؟

- وقتی یک interface باید برای کاربر حرفه‌ای و خوانا باشد
- وقتی باید یک design system یا component library ساخته شود
- وقتی نیاز به هماهنگی بین فایل‌های HTML و CSS وجود دارد

## چه زمانی نباید استفاده کنیم؟

- وقتی فقط یک تگ ساده نیاز به رنگ دارد و CSS external اضافه می‌کند
- وقتی هدف یک prototype سریع و بدون ساختار است
- وقتی style inline برای یک change کوچک کاملاً کافی است

## تفاوت با روش‌های مشابه

- Inline CSS در همان تگ اعمال می‌شود و برای اصلاح سریع مناسب است.
- Internal CSS در `<style>` داخل HTML قرار می‌گیرد و برای یک فایل کوچک خوب است.
- External CSS جداسازی بهتر، reuse و maintainability بیشتری فراهم می‌کند.
- Cascade یعنی همان ترتیب و اولویت قوانین است و در پروژه‌های واقعی اهمیت زیادی دارد.

## بهترین روش‌های استفاده

- برای پروژه‌های بزرگ، External CSS را ترجیح بده.
- از Inline CSS فقط برای exception یا quick fix استفاده کن.
- style را در فایل‌های منظم و قابل خواندن نگه دار.
- از naming قابل فهم برای classها استفاده کن.

## اشتباهات رایج

- اضافه کردن استایل زیاد در HTML
- نبودن ساختار در فایل‌های CSS
- استفاده‌ی بی‌رویه از `!important`
- تکرار قوانین مشابه در چند بخش

## نکات بازار کار

- در پروژه‌های واقعی، CSS نه‌تنها ظاهر بلکه maintainability و performance را هم مدیریت می‌کند.
- Front-End engineerها باید cascade، specificity و naming را بلد باشند.
- clean CSS در team collaboration ارزش بالایی دارد.

## چک‌لیست یادگیری

- [ ] تفاوت Inline، Internal و External CSS را می‌دانم.
- [ ] سینتکس پایه CSS را می‌شناسم.
- [ ] cascade را به زبان ساده می‌توانم توضیح بدهم.
- [ ] سبک‌یابی پروژه را به کمک فایل‌های جداگانه انجام می‌دهم.

## تمرین

اکنون فایل CSSIntroduction.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی landing با header و hero بساز.
2. یک button primary با inline CSS در HTML اعمال کن.
3. همان button را با internal CSS در داخل `<style>` به‌روزرسانی کن.
4. یک `class` مشترک برای چند کارت طراحی کن.
5. یک layout ساده با `display: flex` بساز.
6. سه رنگ اصلی و یک accent color به پروژه اضافه کن.
7. یک سایت ساده برای معرفی سرویس طراحی کن.
8. یک نسخه‌ی متفاوت از همان landing با spacing بهتر بساز.
9. یک component card مانند pricing section بساز.
10. یک صفحه‌ی professional برای معرفی product طراحی کن.
