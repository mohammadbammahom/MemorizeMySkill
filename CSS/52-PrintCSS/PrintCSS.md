# عنوان درس

## این مبحث چیست؟

- Print CSS شامل قوانین و تکنیک‌هایی است که صفحات وب را برای چاپ آماده می‌کند.
- استفاده از `@media print` و `@page` برای تنظیم سایز، حاشیه، و مخفی‌سازی عناصر interactive ضروری است.

## چرا از آن استفاده می‌کنیم؟

- برای ارائهٔ خروجی چاپی مرتب و خوانا به کاربران.
- برای حذف عناصر نامناسب برای چاپ مثل نِویگیشن‌های پیچیده و کنترل‌های تعاملی.

## چه زمانی استفاده می‌کنیم؟

- وقتی کاربران نیاز به چاپ مقالات، رسیدها یا گزارش‌ها دارند.

## چه زمانی نباید استفاده کنیم؟

- وقتی محتوای وب صرفا برای نمایش دیجیتال طراحی شده و چاپ اهمیت ندارد.

## تفاوت با روش‌های مشابه

- Print CSS متمرکز بر چاپ است؛ برخلاف responsive CSS که برای نمایش روی صفحه است.

## بهترین روش‌های استفاده

- از `@media print` برای پوشش حالت چاپ استفاده کن.
- عناصر غیرضروری را با `display:none` مخفی کن.
- از سایز مناسب صفحه و margin در `@page` استفاده کن.

## اشتباهات رایج

- فراموش کردن مخفی‌سازی عناصر interactive
- استفاده از رنگ‌های پس‌زمینه سنگین که چاپ را گران می‌کند

## نکات بازار کار

- مهارت در تولید PDF و printable layouts برای محصولات enterprise مهم است.

## چک‌لیست یادگیری

- [ ] `@media print` را می‌شناسم.
- [ ] `@page` و margin/sizes را تنظیم کرده‌ام.
- [ ] عناصر تعاملی را مناسب مخفی می‌کنم.

## تمرین

اکنون فایل

PrintCSS.Exercises.html

را ایجاد کن.

1. یک article طولانی بساز و pagination برای چاپ شبیه‌سازی کن.
2. header/footer برای چاپ اضافه کن.
3. تصاویر را برای چاپ بهینه کن (grayscale یا lower-res).
4. اطمینان حاصل کن که linkها و URLها در چاپ قابل فهم باشند.
5. یک receipt با اندازه A6 بساز.
6. یک جدول بزرگ برای چاپ فرمت کن.
7. بررسی کن که چگونه page-break-* رفتار می‌کند.
8. CSS for print را برای یک SPA تنظیم کن.
9. بررسی کن که چگونه browsers متفاوت print را رندر می‌کنند.
10. generate a print-friendly PDF from the page and compare results.

## درس بعدی

در درس بعدی `Browser Compatibility` و fallbacks بررسی می‌شود.
