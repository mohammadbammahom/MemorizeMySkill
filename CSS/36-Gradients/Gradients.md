# عنوان درس

## این مبحث چیست؟

- `linear-gradient()` برای گذرهای خطی و استاندارد کاربرد دارد.
- `radial-gradient()` برای تمرکز رنگ به سمت مرکز یا بخش خاص استفاده می‌شود.
- `conic-gradient()` برای رنگ‌های دایره‌ای و رنگ‌پاشی‌های نقشه‌ای مفید است.
- Gradientها می‌توانند ترکیب شده و overlay-based به زیبایی UI کمک کنند.

## چرا از آن استفاده می‌کنیم؟

- برای جذابیت بصری پس‌زمینه‌ها
- برای ساخت hero banners و callout blocks
- برای branding و طراحی خاص landing pages

## چه زمانی استفاده می‌کنیم؟

- وقتی background need visual energy دارد
- وقتی section باید identity و mood خاصی داشته باشد
- وقتی یک CTA یا hero باید standout شود

## چه زمانی نباید استفاده کنیم؟

- وقتی پس‌زمینه به‌صورت شدید و پرتغییر رنگی می‌شود
- وقتی text readability در gradient background کاهش می‌یابد
- وقتی overlay و content contrast به‌درستی کنترل نمی‌شود

## تفاوت با روش‌های مشابه

- `background-color` برای رنگ ثابت است.
- `background-image` می‌تواند رنگ‌های ثابت یا gradient را بپذیرد.
- `gradient` برای transition نرم و multi-stop colors استفاده می‌شود.
- overlay techniques برای ترکیب image و gradient به‌صورت حرفه‌ای به کار می‌روند.

## بهترین روش‌های استفاده

- برای hero، product launches و marketing banners از gradient استفاده کن.
- برای readability، overlay یا darkened gradient اضافه کن.
- از multiple gradients برای depth و energy استفاده کن.
- به contrast و accessibility توجه داشته باش.

## اشتباهات رایج

- اشتباه استفاده از very bright gradients روی متن
- استفاده از gradient در همه‌ی بخش‌ها بدون hierarchy
- نادیده گرفتن overlay برای readable foreground

## نکات بازار کار

- gradients در landing page، dashboards و product pages به‌طور حرفه‌ای دیده می‌شوند.
- UI engineer باید بتواند gradient را به‌صورت brand-aware و readable استفاده کند.
- این موضوع در design reviewهای مدرن بسیار رایج است.

## چک‌لیست یادگیری

- [ ] `linear-gradient()`, `radial-gradient()` و `conic-gradient()` را می‌شناسم.
