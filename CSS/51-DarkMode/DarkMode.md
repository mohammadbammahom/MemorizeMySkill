# عنوان درس

## این مبحث چیست؟

- Dark Mode شامل طراحی و پیاده‌سازی حالت تاریک با استفاده از متغیرهای CSS و بررسی prefers-color-scheme است.
- باید رنگ‌ها، contrast و assetهای تصویری مربوطه را مدیریت کنیم.

## چرا از آن استفاده می‌کنیم؟

- تجربهٔ کاربری بهتر برای کاربران در نور کم و کاهش خستگی چشم.
- افزایش دسترسی و رضایت کاربر.

## چه زمانی استفاده می‌کنیم؟

- وقتی سرویس ما کاربران شبانه یا long-reading دارد.

## چه زمانی نباید استفاده کنیم؟

- وقتی رنگ‌بندی برند به‌طور کامل روی readability تأثیر منفی می‌گذارد، باید گزینهٔ دستی قرار دهیم.

## تفاوت با روش‌های مشابه

- prefers-color-scheme اتوماتیک است؛ toggle دستی باید به‌علاوهٔ گزینهٔ کاربر ارائه شود.

## بهترین روش‌های استفاده

- از CSS variables برای سادگی سوییچ استفاده کن.
- تصاویر و آیکون‌ها را برای dark/light برچسب‌گذاری کن یا از SVG با currentColor استفاده کن.
- حالات transition نرم برای تغییر رنگ‌ها اضافه کن اما `prefers-reduced-motion` را رعایت کن.

## اشتباهات رایج

- تغییر تنها background بدون اصلاح contrast متن
- غیرفعال کردن transitions بدون در نظر گرفتن reduced-motion

## نکات بازار کار

- توانایی طراحی theme-system ارزشمند است.
- کار با design tokens و theme variables در شرکت‌ها متداول است.

## چک‌لیست یادگیری

- [ ] prefers-color-scheme را می‌دانم.
- [ ] CSS variables برای themes پیاده‌سازی کرده‌ام.
- [ ] تصاویر برای dark/light بهینه شده‌اند.

## تمرین

اکنون فایل

DarkMode.Exercises.html

را ایجاد کن.

1. یک toggle بزن که در localStorage ذخیره کند.
2. تصویر آیکون را بر اساس theme تغییر بده.
3. transitions نرم برای تغییر theme پیاده کن.
4. prefers-reduced-motion را رعایت کن.
5. بررسی کن که چگونه theme در SSR یا static hosting مدیریت می‌شود.
6. design tokens برای رنگ‌ها بساز.
7. یک fallback برای مرورگرهای قدیمی بنویس.
8. بررسی کن که چگونه contrast audit در Chrome انجام می‌شود.
9. یک theme switcher با سه حالت (light, dark, system) بساز.
10. مستند کن که چگونه themeها در کامپوننت‌ها استفاده می‌شوند.
