# Custom Attributes

## این مبحث چیست؟

ویژگی‌های سفارشی در HTML، ویژگی‌هایی هستند که به‌صورت دلخواه توسط توسعه‌دهنده اضافه می‌شوند. این ویژگی‌ها معمولاً برای داده‌های خاص یا رفتارهای خاص در UI استفاده می‌شوند.

## چرا از آن استفاده می‌کنیم؟

- افزودن metadata اختصاصی به عنصر
- ارتباط مستقیم با منطق کد یا سفارشیسازی UI
- حمایت از فریم‌ورک‌ها یا ابزارهای خاص

## چه زمانی استفاده می‌کنیم؟

- در پروژه‌های خاص و تجاری
- برای اتصال به کتابخانه‌هایی که نیاز به داده‌ی خاص دارند
- برای کارهای داخلی یک تیم یا محصول

## چه زمانی نباید استفاده کنیم؟

- وقتی `data-*` می‌تواند همان نیاز را پاسخ دهد
- وقتی این ویژگی برای استانداردهای HTML مناسب نیست
- وقتی قابلیت خوانایی و نگهداری کد کاهش می‌یابد

## تفاوت با عناصر مشابه

- `data-*` استاندارد و قابل‌پیش‌بینی است
- `custom attributes` ممکن است برای نیازهای خاص استفاده شود
- `id` و `class` معنای ساختاری دارند

## بهترین روش‌های استفاده

- فقط در مواقع واقعی استفاده کنید
- نام‌گذاری را واضح و قابل‌فهم نگه دارید
- از `data-*` در بیشتر موارد اولویت داشته باشید

## اشتباهات رایج

- استفاده از custom attribute برای هر مقداری
- فراموش کردن استانداردها و سازگاری
- جایگزینی `data-*` با نام‌های غیرمعمول

## نکات بازار کار

در تیم‌های حرفه‌ای، از custom attributes فقط در حالت‌های خاص استفاده می‌شود. بهتر است برای اکثر نیازها از `data-*` استاندارد استفاده کنید.

## چک‌لیست یادگیری

- [ ] تفاوت `data-*` و custom attribute را می‌دانم
- [ ] از custom attribute فقط در موقعیت مناسب استفاده می‌کنم
- [ ] استانداردها را رعایت می‌کنم
- [ ] برای داده‌های استاندارد از `data-*` استفاده می‌کنم

## تمرین

اکنون یک فایل جدید با نام

CustomAttributes.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک کارت با `custom-status` بساز.
2. یک دکمه با `custom-role` و `custom-state` ایجاد کن.
3. یک جدول با `custom-category` برای هر ردیف بساز.
4. یک فرم با `custom-step` برای مراحل انجام کار ایجاد کن.
5. یک منو با `custom-visibility` بساز.
6. یک صفحه‌ی داشبورد با وضعیت‌های سفارشی طراحی کن.
7. یک لیست محصولات با `custom-tag` بساز.
8. یک widget با custom attribute برای انتخاب حالت ایجاد کن.
9. یک نمونه‌ی UI برای ارتباط داده‌های سفارشی بساز.
10. یک صفحه‌ی حرفه‌ای با چند attribute سفارشی و ساختار استاندارد طراحی کن.
