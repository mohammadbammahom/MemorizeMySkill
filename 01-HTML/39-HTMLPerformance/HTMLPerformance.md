# HTML Performance

## این مبحث چیست؟

HTML Performance به مجموعه‌ای از بهترین روش‌ها برای ساختاردهی و بارگذاری بهتر صفحه اشاره دارد. این موضوع به‌طور مستقیم روی سرعت لود، تجربه‌ی کاربر و کیفیت اجرای پروژه اثر می‌گذارد.

## چرا از آن استفاده می‌کنیم؟

- کاهش زمان بارگذاری
- بهبود تجربه‌ی کاربر
- کاهش فشار روی مرورگر و شبکه

## چه زمانی استفاده می‌کنیم؟

- سایت‌های شرکتی و فروشگاهی
- صفحه‌های بالای درگاه‌های پرتیراژ
- داشبوردهای بزرگ و UI‌های پیچیده

## چه زمانی نباید استفاده کنیم؟

- وقتی HTML نامنظم و شلوغ نوشته شده باشد
- وقتی حجم تصاویر و رسانه‌ها بدون کنترل است
- وقتی از عناصر غیرضروری و تکراری زیاد استفاده می‌شود

## تفاوت با عناصر مشابه

- HTML clean یعنی ساختار ساده و معنادار
- lazy loading به بارگذاری تنبل اشاره دارد
- performance به کل فرایند صفحه از ساختار تا نمایش مربوط است

## بهترین روش‌های استفاده

- HTML را به‌صورت clean و معنایی بنویسید
- تصاویر را بهینه کنید و از `loading="lazy"` استفاده کنید
- از تگ‌های مناسب و از divهای غیرضروری کمتر استفاده کنید

## اشتباهات رایج

- استفاده‌ی بی‌رویه از تصاویر بزرگ
- استفاده‌ی excessive از تگ‌های غیرضروری
- نوشتن HTML بدون نظم و semantic

## نکات بازار کار

در شرکت‌ها، HTML Performance یکی از مهارت‌های مهم برای front-end engineer به حساب می‌آید. مخصوصاً در پروژه‌های واقعی که نیاز به سرعت بالا و UX خوب دارند.

## چک‌لیست یادگیری

- [ ] HTML تمیز و semantic را می‌نویسم
- [ ] برای تصاویر از بهینه‌سازی و lazy loading استفاده می‌کنم
- [ ] عملکرد صفحه را با ساختار مناسب بهبود می‌دهم
- [ ] از کدهای تکراری و شلوغ اجتناب می‌کنم

## تمرین

اکنون یک فایل جدید با نام

HTMLPerformance.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی فروشگاهی با تصاویر lazy loading بساز.
2. یک صفحه‌ی خبر با HTML تمیز و semantic مناسب طراحی کن.
3. یک صفحه‌ی landing با بخش‌های کوتاه و بهینه بساز.
4. یک صفحه‌ی شرکت با structure ساده و قابل نگهداری طراحی کن.
5. یک صفحه‌ی محصول با HTML clean و بدون ساختار اضافی بساز.
6. یک نمونه‌ی داشبورد با بخش‌های بهینه و بارگذاری هوشمند طراحی کن.
7. یک صفحه‌ی وبلاگ با محتوای منظم و سبک‌وزن ایجاد کن.
8. یک صفحه‌ی marketing با کاهش تگ‌های غیرضروری بساز.
9. یک نسخه‌ی حرفه‌ای از صفحه‌ی خدمات با content structure بهینه طراحی کن.
10. یک نمونه‌ی پروژه‌ی real-world با تمرکز روی عملکرد HTML بساز.
