# Project Admin Dashboard

## این مبحث چیست؟

این پروژه نمونه‌ای از داشبورد مدیریتی است که در آن sidebar، topbar، آمار، جدول و profile برای تمرین ساختارهای واقعی UI پیاده‌سازی می‌شود.

## چرا از آن استفاده می‌کنیم؟

- تمرین layout‌های حرفه‌ای
- آشنایی با ساختار داده‌های مدیریتی
- استفاده از semantic structure برای بخش‌های مختلف

## چه زمانی استفاده می‌کنیم؟

- در پنل‌های مدیریت و حسابداری
- در داشبوردهای محصول و کاربر
- در سیستم‌های داخلی سازمان‌ها

## چه زمانی نباید استفاده کنیم؟

- برای صفحه‌های خبر یا landing page ساده
- در پروژه‌های کم‌محتوا که نیاز به sidebar ندارند

## تفاوت با عناصر مشابه

- dashboard از layout‌های چندبخشی و table-heavy استفاده می‌کند
- در مقابل landing page، بیشتر روی داده و کنترل تمرکز دارد

## بهترین روش‌های استفاده

- sidebar و stats را با semantic مناسب نگه دارید
- table را برای داده‌های جدولی استفاده کنید
- profile و topbar را به شکل professional تنظیم کنید

## اشتباهات رایج

- استفاده‌ی نامناسب برای sidebar یا table
- نداشتن ساختار برای blocks اصلی صفحه
- عدم گروه‌بندی عناصر مدیریتی

## نکات بازار کار

داشبوردهای مدیریتی از مهم‌ترین پروژه‌های واقعی برای front-end engineer هستند. این پروژه برای تمرین HTML حرفه‌ای و ساختار محور کاملاً مناسب است.

## چک‌لیست یادگیری

- [ ] ساختار dashboard را semantic می‌نویسم
- [ ] sidebar و topbar را به‌درستی می‌سازم
- [ ] table و profile را به‌صورت منظم می‌گذارم
- [ ] layout را برای واقعیات پروژه آماده می‌کنم

## تمرین

اکنون فایل AdminDashboard.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک sidebar با لینک‌های مدیریتی بساز.
2. یک topbar با profile و اعلان بساز.
3. سه کارت آماری برای کاربران، فروش و درآمد بساز.
4. یک جدول کاربران با وضعیت و دکمه‌های عملیاتی طراحی کن.
5. یک بخش profile با اطلاعات مدیر ایجاد کن.
6. یک footer برای داشبورد طراحی کن.
7. یک نسخه‌ی dashboard با بخش گزارش‌ها بساز.
8. یک صفحه‌ی مدیریتی با sidebar و main structure حرفه‌ای طراحی کن.
9. یک قالب dashboard با cards و table ایجاد کن.
10. یک پروژه‌ی full dashboard برای پروژه‌ی واقعی بساز.
