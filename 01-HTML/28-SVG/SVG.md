# SVG

## این مبحث چیست؟

SVG یک فرم از گرافیک برداری در وب است که با کد نوشته می‌شود و برای آیکون، لوگو، نمودار و عناصر تصویری با کیفیت بالا بسیار مناسب است.

## چرا از آن استفاده می‌کنیم؟

- کیفیت بالا در همه‌ی اندازه‌ها
- مناسب برای آیکون و لوگو
- قابل دسترس‌پذیری و قابل‌ویرایش

## چه زمانی استفاده می‌کنیم؟

- آیکون‌های سایت و اپلیکیشن
- نمودارهای ساده و اینفوگرافیک
- عناصر گرافیکی که در اندازه‌های مختلف نیاز به وضوح دارند

## چه زمانی نباید استفاده کنیم؟

- برای تصاویر فوتوگرافی پیچیده
- برای گرافیک‌های بسیار بزرگ و پرجزئیات که بهتر با raster انجام می‌شود
- وقتی فقط یک تصویر ساده‌ی bitmap کافی است

## تفاوت با عناصر مشابه

- SVG برداری است و کیفیتش ثابت می‌ماند
- Canvas برای ترسیم‌های پویا و برنامه‌نویسی‌محور بهتر است
- img برای نمایش تصویر آماده استفاده می‌شود

## بهترین روش‌های استفاده

- برای آیکون‌ها و برندینگ از SVG استفاده کنید
- از `role` و `aria-label` برای دسترس‌پذیری استفاده کنید
- SVG را در صورت امکان inline یا به‌صورت فایل جداگانه نگه دارید

## اشتباهات رایج

- استفاده از SVG برای تصویرهای بزرگ و پیچیده
- نادیده گرفتن دسترس‌پذیری
- قرار دادن SVG بدون viewBox مناسب

## نکات بازار کار

در پروژه‌های واقعی، SVG در UI‌ها و طراحی سیستم‌ها بسیار پرکاربرد است. مخصوصاً برای آیکون‌ها، دکمه‌ها و عناصر برندینگ.
