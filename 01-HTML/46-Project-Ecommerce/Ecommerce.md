# Project Ecommerce

## این مبحث چیست؟

این پروژه نمونه‌ای از صفحه‌ی اصلی فروشگاه آنلاین است که در آن header، جست‌وجو، دسته‌بندی، کارت محصول، تخفیف و newsletter برای تمرین HTML واقعی پیاده‌سازی می‌شوند.

## چرا از آن استفاده می‌کنیم؟

- تمرین ساختار فروشگاه آنلاین
- آشنایی با section‌های تکرارشونده
- ایجاد صفحه‌ای حرفه‌ای برای product listing

## چه زمانی استفاده می‌کنیم؟

- برای فروشگاه‌های اینترنتی
- برای landing page‌های فروش محصول
- برای داشبوردهای فروش و پیشنهادات ویژه

## چه زمانی نباید استفاده کنیم؟

- وقتی تمرکز اصلی روی محتوا و وبلاگ است
- وقتی پروژه یک portfolio ساده و تک‌صفحه‌ای است

## تفاوت با عناصر مشابه

- homepage فروشگاهی نسبت به landing page بیشتر روی محصول، دسته‌بندی و جست‌وجو تمرکز دارد
- به‌رغم اینکه مشابه است، محتوای آن به‌صورت commercial و transactional است

## بهترین روش‌های استفاده

- برای کارت محصول از `article` استفاده کنید
- `nav` و `search` را برای دسترسی راحت بگذارید
- newsletter را در کنار footer یا بخش دوم صفحه قرار دهید

## اشتباهات رایج

- ساختار نامنظم محصولات
- نبودن label برای فرم خبرنامه
- استفاده‌ی نادرست از `article` در کارت‌های محصول

## نکات بازار کار

در پروژه‌های واقعی، homepage فروشگاه‌ها معمولاً از semantic ساختار قوی و تقسیم‌بندی آگاهانه استفاده می‌کنند. این تمرین در مرور HTML کاربردی حرفه‌ای است.

## چک‌لیست یادگیری

- [ ] ساختار فروشگاه را semantic می‌نویسم
- [ ] بخش جست‌وجو و categories را درست می‌گذارم
- [ ] کارت محصولات را به شکل real-world می‌سازم
- [ ] newsletter و footer را کامل می‌کنم

## تمرین

اکنون فایل Ecommerce.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی اصلی فروشگاه با header و navigation بساز.
2. یک بخش جست‌وجو و دسته‌بندی اضافه کن.
3. کارت‌های محصول با عنوان، قیمت و دکمه‌ی سفارش بساز.
4. یک offer section برای تخفیف‌های ویژه اضافه کن.
5. یک newsletter برای عضویت کاربران بساز.
6. یک footer با لینک‌های مهم طراحی کن.
7. یک فروشگاه با نمایش سه محصول و پیشنهاد ویژه بساز.
8. یک home page برای فروشگاه الکترونیکی با layout حرفه‌ای طراحی کن.
9. یک نسخه‌ی متفاوت از homepage با categories و cards بساز.
10. یک پروژه‌ی کامل برای فروشگاه دیجیتال طراحی کن.

## درس بعدی

در درس بعدی پروژه‌ی داشبورد مدیریتی با sidebar، topbar و statistics cards ساخته می‌شود.
