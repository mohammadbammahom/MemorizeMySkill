# متن و پاراگراف‌ها

---

## این مبحث چیست؟

تگ‌های متنی HTML:

- `<p>` - پاراگراف
- `<h1>` تا `<h6>` - عناوین (از بزرگ تا کوچک)
- `<br>` - شکستن خط
- `<hr>` - خط افقی
- `<small>` - متن کوچک
- `<code>` - کد برنامه‌نویسی

---

## چرا وجود دارند؟

- **معنایی**: SEO و accessibility متن را می‌فهمند
- **سلسله مراتب**: Headings ساختار منطقی ایجاد می‌کند
- **خوانایی**: `<p>` و proper spacing خواندن را آسان می‌کند
- **بازار کار**: بدون proper text structure، pull request reject می‌شود

---

## چه زمانی استفاده کنیم

**`<h1>`**: فقط یک بار در صفحه (عنوان اصلی)

**`<h2>` تا `<h6>`**: بخش‌های داخلی

**`<p>`**: متن معمولی و پاراگراف‌ها

**`<br>`**: شکستن خط در شاعری یا آدرس

**`<code>`**: نام متغیرها یا کدهای کوتاه

---

## چه زمانی نباید استفاده کنیم

❌ چند `<h1>` در یک صفحه:
```html
<h1>عنوان ۱</h1>
<h1>عنوان ۲</h1> <!-- نادرست - فقط یک باید باشد -->
```

❌ `<br>` برای spacing:
```html
<p>متن</p>
<br>
<br>
<br>
<p>متن دیگر</p> <!-- CSS margin استفاده کن -->
```

❌ Heading برای styling:
```html
<h1>عنوان کوچک</h1> <!-- بد SEO -->
```

---

## تفاوت با عناصر مشابه

| تگ | نقش | SEO | Size |
|----|--------|-----|------|
| `<h1>` | عنوان اصلی | ✓ مهم | بزرگ |
| `<h2>` | قسمت | ✓ مهم | متوسط |
| `<h3>` تا `<h6>` | زیر‌قسمت | ✓ |کم |
| `<p>` | پاراگراف | ✗ | معمولی |

---

## بهترین روش‌ها

✅ یک `<h1>` در صفحه برای عنوان اصلی

✅ Heading hierarchy: `<h1>` → `<h2>` → `<h3>` (نه جهش)

✅ مناسب line-height (۱.۶-۱.۸) برای خوانایی

✅ `<p>` برای هر پاراگراف جداگانه

✅ `<code>` برای نام‌های کلاس یا متغیر

---

## اشتباهات رایج

❌ بدون `<p>` تگ، فقط متن:
```html
<body>
    متن بدون پاراگراف <!-- بد accessibility -->
</body>
```

❌ `<br>` برای layout:
```html
سطر اول<br><br><br>سطر دوم <!-- CSS استفاده کن -->
```

❌ Heading برای Bold:
```html
<h1>Bold text</h1> <!-- بد SEO، استفاده از <strong> کن -->
```

## نکات بازار کار

- **WAVE**: accessibility checker heading hierarchy را چک می‌کند
- **Lighthouse**: proper heading structure برای SEO امتیاز می‌دهد
- **Code Review**: بدون `<p>` headings، reject می‌شود
- **Screen Readers**: از heading structure برای ناوبری استفاده می‌کند
