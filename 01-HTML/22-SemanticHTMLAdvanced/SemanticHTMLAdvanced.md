# Semantic HTML پیشرفته

## این مبحث چیست؟

در HTML پیشرفته، فقط آشنایی با عناصر ساده کافی نیست. باید بدانیم چه زمانی از عناصر معنایی پیشرفته مثل `<article>`, `<aside>`، `<nav>` و `<main>` استفاده کنیم تا صفحه‌ی منظم، دسترس‌پذیر و سئوپسند باشد.

## چرا از آن استفاده می‌کنیم؟

- ساختار واضح‌تر برای مرورگر و موتورهای جست‌وجو
- افزایش دسترس‌پذیری
- سهولت نگهداری و توسعه

## چه زمانی استفاده می‌کنیم؟

- سایت‌های خبری و وبلاگ
- صفحات محصول و فروشگاهی
- داشبوردها و پنل‌های مدیریتی

## چه زمانی نباید استفاده کنیم؟

- وقتی یک ساختار ساده‌تر با `<div>` کافی است
- وقتی عنصر semantic به‌درستی معانی صفحه را منتقل نمی‌کند
- وقتی انتخاب اشتباه، ساختار را گیج‌کننده می‌کند

## تفاوت با عناصر مشابه

- `<section>` برای بخش‌های موضوعی استفاده می‌شود
- `<article>` برای محتوای مستقل و قابل‌استفاده دوباره است
- `<aside>` برای اطلاعات جانبی است
- `<div>` فقط برای گروه‌بندی بدون معنای خاص

## بهترین روش‌های استفاده

- از عناصر semantic به‌جای divهای بی‌معنا استفاده کنید
- هر بخش را بر اساس هدفش انتخاب کنید
- ساختار صفحه را برای کاربر و موتور جست‌وجو روشن کنید

## اشتباهات رایج

- استفاده‌ی زیاد از `<div>` بدون دلیل
- قرار دادن چند `<article>` در یک `<section>` بدون هدف مشخص
- استفاده‌ی نادرست از `<aside>` برای هر چیزی در حاشیه

## نکات بازار کار

در کدهای حرفه‌ای، انتخاب درست عنصر semantic یکی از مهارت‌های مهم برای code review و نگهداری است. این موضوع در پروژه‌های بزرگ ارزش زیادی دارد.

## چک‌لیست یادگیری

- [ ] مفهوم semantic را می‌فهمم
- [ ] تفاوت `section` و `article` را می‌دانم
- [ ] از `aside` و `main` درست استفاده می‌کنم
- [ ] ساختار صفحه را برای SEO و accessibility بهبود می‌دهم

## تمرین

اکنون یک فایل جدید با نام

SemanticHTMLAdvanced.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی وبلاگ با `header`، `main` و `aside` بساز.
2. یک صفحه‌ی محصول با `article` و بخش‌های مرتبط ایجاد کن.
3. یک صفحه‌ی شرکت با `section` و `article` طراحی کن.
4. یک صفحه‌ی خبری با چند بخش semantic بساز.
5. یک صفحه‌ی آموزش با `nav` و `aside` ایجاد کن.
6. یک نمونه‌ی وبسایت فروشگاهی با ساختار معنایی درست بساز.
7. یک صفحه‌ی مستندات با چند بخش جداگانه طراحی کن.
8. یک صفحه‌ی landing با hero section و article بساز.
9. ساختار یک صفحه‌ی dashboard با semantic sections ایجاد کن.
10. یک نسخه‌ی حرفه‌ای از یک سایت شرکت با همه‌ی عناصر semantic بساز.

## درس بعدی

در درس بعدی به ساختار صفحه با `header`، `main` و `footer` می‌پردازیم و کاربرد آن‌ها را در قالب‌های واقعی بررسی می‌کنیم.
