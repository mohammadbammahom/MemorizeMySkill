# Details و Summary

## این مبحث چیست؟

عناصر `<details>` و `<summary>` برای نمایش محتوای قابل باز و بسته استفاده می‌شوند. این ساختار معمولاً برای FAQ، راهنمایی سریع و اطلاعات فشرده به کار می‌رود.

## چرا از آن استفاده می‌کنیم؟

- کاهش شلوغی صفحه
- ارائه‌ی اطلاعات در قالبی قابل‌گسترش
- ساختار ساده و native بدون نیاز به JavaScript

## چه زمانی استفاده می‌کنیم؟

- بخش سوالات متداول
- توضیحات محصول در حالت خلاصه
- منوی‌های قابل کشو برای اطلاعات تکمیلی

## چه زمانی نباید استفاده کنیم؟

- برای محتوای مهمی که باید همیشه دیده شود
- برای اطلاعاتی که کاربر باید در همان ابتدا ببیند
- برای جایگزینی منوهای پیچیده

## تفاوت با عناصر مشابه

- `<details>` برای بسته/باز بودن یک بخش مناسب است
- `<dialog>` برای پنجره‌ی مدال است
- `<div>` فقط برای گروه‌بندی ساده است

## بهترین روش‌های استفاده

- متن `summary` باید واضح و کوتاه باشد
- محتوا را کوتاه و کاربردی نگه دارید
- برای اطلاعات طولانی، از نسخه‌ی کامل‌تر استفاده کنید

## اشتباهات رایج

- استفاده از `summary` با متن مبهم
- قرار دادن محتوای بسیار طولانی داخل `details`
- استفاده‌ی نامناسب برای منوهای اصلی

## نکات بازار کار

در سایت‌های اطلاعاتی، پشتیبانی و فروشگاهی، این ساختار برای کاهش شلوغی صفحه و بهبود خوانایی خیلی مفید است.

## چک‌لیست یادگیری

- [ ] مفهوم `details` و `summary` را می‌فهمم
- [ ] کاربردهای واقعی آن را می‌شناسم
- [ ] از آن برای FAQ و اطلاعات فشرده استفاده می‌کنم
- [ ] آن را در موقعیت مناسب به‌کار می‌برم

## تمرین

اکنون یک فایل جدید با نام

DetailsAndSummary.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک FAQ ساده با چند `details` بساز.
2. یک بخش توضیحات محصول با `summary` طراحی کن.
3. یک صفحه‌ی راهنما با جزئیات قابل باز و بسته بساز.
4. یک بخش سیاست‌های بازگشت کالا ایجاد کن.
5. یک نمونه‌ی منوی اطلاعات تکمیلی طراحی کن.
6. یک صفحه‌ی آموزش با جزئیات نکات مهم بساز.
7. یک بخش پشتیبانی با چند سوال ایجاد کن.
8. یک نمونه‌ی جعبه‌ی اطلاعات برای کارت محصول بساز.
9. یک صفحه‌ی FAQ حرفه‌ای با دسته‌بندی بساز.
10. یک نسخه‌ی کامل از صفحه‌ی راهنمای کاربر طراحی کن.
