# Canvas Basics

## این مبحث چیست؟

عنصر `<canvas>` برای ترسیم گرافیک پویا و برنامه‌نویسی‌محور در مرورگر استفاده می‌شود. این عنصر برای نمودار، بازی، ابزار طراحی و انیمیشن مناسب است.

## چرا از آن استفاده می‌کنیم؟

- ترسیم عناصر گرافیکی به‌صورت پویا
- کنترل دقیق روی شکل‌ها و انیمیشن‌ها
- مناسب برای ابزارهای تعاملی و صفحه‌های داده‌محور

## چه زمانی استفاده می‌کنیم؟

- نمودارهای زنده
- بازی‌های ساده
- ابزارهای نقاشی و طراحی آنلاین

## چه زمانی نباید استفاده کنیم؟

- برای عناصر گرافیکی ثابت و ساده
- برای تصاویر آماده و آیکون‌های تکرارشونده
- وقتی نیاز به دسترس‌پذیری و سئو بالا داریم

## تفاوت با عناصر مشابه

- Canvas برای ترسیم برنامه‌نویسی‌محور مناسب است
- SVG برای گرافیک برداری و عناصر قابل‌استفاده مجدد بهتر است
- img برای نمایش تصویر آماده مناسب است

## بهترین روش‌های استفاده

- برای انیمیشن و تعامل از Canvas استفاده کنید
- از canvas API به‌صورت منظم و تمیز استفاده کنید
- اگر محتوای بصری مهم است، از SVG یا img در کنار Canvas استفاده کنید

## اشتباهات رایج

- استفاده از Canvas برای محتوای ایستا
- فراموش کردن مدیریت redraw و به‌روزرسانی
- نادیده گرفتن دسترس‌پذیری و جایگزین مناسب

## نکات بازار کار

Canvas در ابزارهای داده‌محور، بازی‌های وب و تجربه‌های تعاملی بسیار کاربرد دارد. در پروژه‌های پیشرفته، این دانش ارزش بالایی دارد.
