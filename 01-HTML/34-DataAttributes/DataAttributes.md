# Data Attributes

## این مبحث چیست؟

ویژگی‌های `data-*` به ما اجازه می‌دهند داده‌های سفارشی را به‌صورت معنایی در عناصر HTML ذخیره کنیم. این داده‌ها معمولاً توسط JavaScript برای رفتارهای تعاملی استفاده می‌شوند.

## چرا از آن استفاده می‌کنیم؟

- ذخیره اطلاعات مرتبط با یک عنصر
- دسترسی ساده‌تر در JavaScript
- حذف نیاز به داده‌های جانبی یا state پیچیده

## چه زمانی استفاده می‌کنیم؟

- کارت‌های محصول و اطلاعات مرتبط
- دکمه‌های با داده‌ی خاص
- عناصر UI که نیازمند metadata هستند

## چه زمانی نباید استفاده کنیم؟

- برای داده‌های اصلی صفحه که بهتر در JavaScript state یا backend ذخیره می‌شوند
- برای جایگزینی `id` و `class` در موقعیت‌های semantic
- برای اطلاعاتی که باید در HTML معنایی داشته باشند

## تفاوت با عناصر مشابه

- `data-*` برای داده‌ی سفارشی است
- `id` برای شناسایی منحصربه‌فرد است
- `class` برای گروه‌بندی است

## بهترین روش‌های استفاده

- از نام‌های واضح و قابل فهم استفاده کنید
- برای داده‌های واقعی و مرتبط از `data-*` استفاده کنید
- داده‌ها را به‌صورت ساختارمند نگه دارید

## اشتباهات رایج

- استفاده‌ی بیش‌ازحد از `data-*` برای همه چیز
- نام‌گذاری نامناسب و مبهم
- استفاده‌ی اشتباه به‌جای `id` یا `class`

## نکات بازار کار

در پروژه‌های فعلی، `data-*` برای اتصال UI به منطق JavaScript و ساخت کامپوننت‌های پویا بسیار مهم است.

## چک‌لیست یادگیری

- [ ] مفهوم `data-*` را می‌فهمم
- [ ] داده‌های سفارشی را با آن ذخیره می‌کنم
- [ ] از `dataset` در JavaScript استفاده می‌کنم
- [ ] از آن در موقعیت درست استفاده می‌کنم

## تمرین

اکنون یک فایل جدید با نام

DataAttributes.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک دکمه با `data-product-id` و `data-price` بساز.
2. چند کارت محصول با `data-*` متفاوت ایجاد کن.
3. یک فرم با داده‌های سفارشی برای هر فیلد بساز.
4. یک لیست کارها با `data-status` ایجاد کن.
5. یک بخش فیلتر با `data-category` بساز.
6. یک صفحه‌ی داشبورد با کارت‌های داده‌محور طراحی کن.
7. یک نمونه‌ی انتخاب رنگ با `data-color` بساز.
8. یک منوی ناوبری با `data-role` ایجاد کن.
9. یک صفحه‌ی سفارش با `data-*` برای سبد خرید طراحی کن.
10. یک نسخه‌ی حرفه‌ای از UI تعاملی با داده‌های سفارشی بساز.

## درس بعدی

در درس بعدی با ویژگی‌های سفارشی و تفاوتشان با `data-*` آشنا می‌شویم.
