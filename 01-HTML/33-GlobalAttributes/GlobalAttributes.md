# Global Attributes

## این مبحث چیست؟

ویژگی‌های جهانی در HTML به تمام عناصر کمک می‌کنند تا رفتار، معنا و تعاملشان را بهتر کنترل کنند. این ویژگی‌ها در بیشتر عناصر قابل استفاده‌اند و در پروژه‌های واقعی بسیار پرکاربردند.

## چرا از آن استفاده می‌کنیم؟

- تنظیم هویت و دسته‌بندی عناصر
- کنترل نمایش و دسترسی‌پذیری
- بهبود تعامل کاربر و تجربه‌ی استفاده

## چه زمانی استفاده می‌کنیم؟

- برای شناسایی عناصر با `id`
- برای دسته‌بندی با `class`
- برای راهنما و tooltip با `title`
- برای کنترل نمایش با `hidden`

## چه زمانی نباید استفاده کنیم؟

- برای چیزهایی که باید با CSS یا JavaScript مدیریت شوند
- برای اضافه کردن اطلاعات بدون هدف مشخص
- برای جایگزینی عناصر semantic مناسب

## تفاوت با عناصر مشابه

- `id` برای شناسه‌ی منحصربه‌فرد استفاده می‌شود
- `class` برای گروه‌بندی چند عنصر است
- `title` برای راهنمایی و tooltip است
- `hidden` برای پنهان کردن عنصر است

## بهترین روش‌های استفاده

- `id` را منحصربه‌فرد و معنی‌دار استفاده کنید
- `class` را برای سبک و گروه‌بندی منطقی به کار ببرید
- `tabindex` را فقط در موارد ضروری استفاده کنید
- `contenteditable` را با دقت به کار ببرید

## اشتباهات رایج

- استفاده‌ی زیاد از `id` تکراری
- استفاده‌ی بی‌هدف از `hidden`
- استفاده‌ی نادرست از `contenteditable` در فرم‌های ساده

## نکات بازار کار

در کدهای حرفه‌ای، این ویژگی‌ها بخش جدایی‌ناپذیر از ساختار و تعامل هستند. استفاده‌ی درستشان روی خوانایی و نگهداری کد اثر مستقیم دارد.

## چک‌لیست یادگیری

- [ ] `id` و `class` را درست استفاده می‌کنم
- [ ] `title` و `hidden` را در موقعیت مناسب به کار می‌برم
- [ ] `tabindex` را به‌درستی مدیریت می‌کنم
- [ ] `contenteditable` را فقط وقتی لازم است استفاده می‌کنم

## تمرین

اکنون یک فایل جدید با نام

GlobalAttributes.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک صفحه با چند عنصر دارای `id` و `class` بساز.
2. یک دکمه با `title` و `tabindex` ایجاد کن.
3. یک بخش پنهان با `hidden` طراحی کن.
4. یک متن قابل ویرایش با `contenteditable` بساز.
5. یک کارت با `draggable` ایجاد کن.
6. یک فرم با `spellcheck` و `contenteditable` طراحی کن.
7. یک لیست با چند عنصر دارای `class` مشترک بساز.
8. یک صفحه‌ی نمونه با ابزارهای jQuery-like ساختار و ویژگی‌های جهانی ایجاد کن.
9. یک فرم ویرایش اطلاعات با `title` و `tabindex` بساز.
10. یک نسخه‌ی حرفه‌ای از UI با ویژگی‌های جهانی طراحی کن.

## درس بعدی

در درس بعدی با `data-*` attributes آشنا می‌شویم و کاربردشان در JavaScript را بررسی می‌کنیم.
