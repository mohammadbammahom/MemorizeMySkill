# Interview Questions

## این مبحث چیست؟

این درس مجموعه‌ای از سوالات مصاحبه‌ی HTML برای مرور و آمادگی بازار کار است. هدف این است که شما مفاهیم اصلی را به‌صورت حرفه‌ای و کاربردی مرور کنید.

## چرا از آن استفاده می‌کنیم؟

- آمادگی برای مصاحبه‌های فنی
- مرور سریع مفاهیم مهم
- درک بهتر کاربرد HTML در پروژه‌های واقعی

## چه زمانی استفاده می‌کنیم؟

- قبل از مصاحبه
- هنگام مرور نهایی دوره
- برای آماده‌سازی برای پروژه‌های شغلی

## چه زمانی نباید استفاده کنیم؟

- وقتی هنوز مفاهیم پایه را کامل نکرده‌اید
- وقتی فقط به حفظ لغات تکیه می‌کنید
- وقتی تمرین عملی انجام نشده است

## تفاوت با عناصر مشابه

- این درس تمرکز روی پرسش و تفکر است نه آموزش تگ‌های جدید
- هدف اصلی تقویت مهارت توضیح و تصمیم‌گیری است

## بهترین روش‌های استفاده

- سعی کنید هر سؤال را با مثال جواب دهید
- تفاوت semantic و non-semantic را واضح بگویید
- از تجربه‌ی واقعی پروژه‌ها در جواب‌ها استفاده کنید

## اشتباهات رایج

- حفظ کردن اصطلاحات بدون فهم
- پاسخ به سؤال با مثال‌های ساده و غیرواقعی
- نداشتن تمرین عملی و مثال شهودی

## نکات بازار کار

در مصاحبه‌ها، سؤالات HTML معمولاً روی semantic، accessibility، form و performance تمرکز دارند. این بخش کمک می‌کند از همان ابتدا مسیر درست را ببینید.

## چک‌لیست یادگیری

- [ ] مفاهیم پایه را می‌فهمم
- [ ] semantic را به‌خوبی توضیح می‌دهم
- [ ] سوالات فرم و دسترس‌پذیری را می‌شناسم
- [ ] برای مصاحبه به تمرین عملی آماده‌ام
