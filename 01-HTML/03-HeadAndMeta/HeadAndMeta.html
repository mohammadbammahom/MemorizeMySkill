Meta Tags و Head Elements

چه چیزهایی در Head مهم است؟

Meta Tags ضروری

Character Encoding

<meta charset="UTF-8">

برای پشتیبانی از فارسی و نویسه‌های خاص ضروری است.

Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">

بدون آن، موبایل صفحه را کوچک نمایش می‌دهد.

Description

<meta name="description" content="...">

توضیحی که Google در نتایج نمایش می‌دهد. حداکثر ۱۶۰ کاراکتر.

Open Graph (شبکه‌های اجتماعی)

هدف

وقتی لینک را در Facebook/Twitter مشاهره می‌دهید، کدام عکس و متن نمایش داده شود؟

پاسخ: Open Graph tags!

Tags

og:title, og:description, og:image, og:url, og:type

تمام این tags برای بهتری نمایش در شبکه‌های اجتماعی ضروری‌اند.
