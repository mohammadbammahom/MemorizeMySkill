# HTML Roadmap

## هدف دوره

این دوره یک مروری حرفه‌ای و project-based برای یادگیری HTML است. تمرکز اصلی روی ساختار semantic، پروژه‌های واقعی و توانایی مرور سریع مفاهیم است.

## ترتیب درس‌ها

1. HTML Basics
2. HTML Structure
3. Text Content
4. Links and Navigation
5. Images and Media
6. Tables
7. Forms
8. Semantic HTML
9. Accessibility
10. SEO Basics
11. Meta Tags
12. Layout Fundamentals
13. HTML5 Elements
14. Responsive Structure
15. Audio and Video
16. SVG Basics
17. Canvas Basics
18. Web Components
19. Iframe and Embeds

27. Project Ecommerce
28. Project Admin Dashboard
29. Final Challenge

## مسیر یادگیری

- شروع با اصول پایه و semantic
- تمرین ساختارهای واقعی
- مرور با پروژه‌های landing page، blog، ecommerce، dashboard
- پایان با challenge نهایی و مرور کل دوره

## چک‌لیست نهایی

- [ ] HTML پایه را حفظ می‌کنم
- [ ] semantic structure را به‌خوبی می‌نویسم
- [ ] project-oriented یادگیری را انجام می‌دهم
- [ ] فرم‌ها، media و accessibility را مرور می‌کنم
- [ ] چالش نهایی را با ساختار حرفه‌ای پیاده می‌کنم

## توصیه برای مرور

- هر درس را به‌صورت عملی اجرا کن
- برای پروژه‌ها از فایل‌های HTML/CSS جدا استفاده کن
- بعد از هر درس، یک راه‌حل کوتاه و زبان‌محور بنویس

## جمع‌بندی

این دوره برای مرور سریع و حرفه‌ای HTML طراحی شده است و می‌تواند به‌عنوان یک مسیر مجدد برای برنامه‌نویسان و توسعه‌دهندگان front-end کاربردی باشد.
