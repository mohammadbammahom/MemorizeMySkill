# Progress و Meter

## این مبحث چیست؟

عناصر `<progress>` و `<meter>` برای نمایش وضعیت یا سطح ارزش در رابط کاربری استفاده می‌شوند. این دو عنصر در ظاهر شبیه‌اند، اما از نظر معنایی و کاربردی متفاوت هستند.

## چرا از آن استفاده می‌کنیم؟

- نمایش پیشرفت پروژه یا تسک‌ها
- نمایش سطح امتیاز، کیفیت یا ظرفیت
- ارائه‌ی اطلاعات عددی در قالبی قابل فهم‌تر

## چه زمانی استفاده می‌کنیم؟

- داشبوردهای مدیریتی
- فرم‌های ثبت‌نام و امتیازدهی
- وضعیت بارگذاری یا تکمیل پروسه

## چه زمانی نباید استفاده کنیم؟

- وقتی فقط یک درصد یا یک عدد ساده لازم است
- وقتی بخواهیم از طریق CSS یک شاخص سفارشی بسازیم
- وقتی مفهوم «مقدار» یا «پیشرفت» دقیقاً لزوماً وجود ندارد

## تفاوت با عناصر مشابه

- `<progress>` برای پیشرفت یک کار استفاده می‌شود
- `<meter>` برای نمایش مقدار نسبت به محدوده‌ی معقول استفاده می‌شود
- `<div>` یا `<span>` برای این موارد semantic نیستند

## بهترین روش‌های استفاده

- از `max` و `value` به‌درستی استفاده کنید
- برای `meter` از `low`، `high` و `optimum` استفاده کنید
- در کنار آنها متن توضیحی قرار دهید

## اشتباهات رایج

- استفاده از `progress` برای نمایش امتیاز کلی
- نادیده گرفتن دسترس‌پذیری
- استفاده از مقدار نامعتبر یا خارج از محدوده

## نکات بازار کار

در UI‌های حرفه‌ای، این عناصر برای نمایش وضعیت و شاخص‌های عملکرد بسیار مفیدند و در داشبوردها و پنل‌های مدیریتی زیاد دیده می‌شوند.

## چک‌لیست یادگیری

- [ ] تفاوت `progress` و `meter` را می‌دانم
- [ ] برای پیشرفت از `progress` استفاده می‌کنم
- [ ] برای سطح ارزش از `meter` استفاده می‌کنم
- [ ] دسترس‌پذیری را رعایت می‌کنم

## تمرین

اکنون یک فایل جدید با نام

ProgressAndMeter.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک نوار پیشرفت برای پروژه‌ی طراحی ساختار.
2. یک `meter` برای امتیاز عملکرد کارمند بساز.
3. یک داشبورد با چند `progress` نمایش بده.
4. یک صفحه‌ی حسابرسی با `meter` برای معیارهای کیفیت بساز.
5. یک بخش وضعیت بارگذاری با `progress` بساز.
6. چند `meter` برای سطح انرژی، سرعت و دقت طراحی کن.
7. یک صفحه‌ی مدیریت تسک با وضعیت پیشرفت ایجاد کن.
8. یک بخش آماری برای فروش با `progress` و `meter` بساز.
9. یک قالب حرفه‌ای برای پنل مدیریتی طراحی کن.
10. یک صفحه‌ی کامل با هر دو عنصر و استایل مناسب بساز.
