# Project Blog

## این مبحث چیست؟

این پروژه نمایی از صفحه‌ی اصلی یک وبلاگ حرفه‌ای است که در آن header، navigation، categories، featured article، sidebar و footer به‌صورت real-world طراحی می‌شوند.

## چرا از آن استفاده می‌کنیم؟

- تمرین semantic HTML در ساختار منظم
- آموزش layout مناسب برای محتوای چندبخشی
- آشنایی با تمرین‌های پروژه‌ای واقعی

## چه زمانی استفاده می‌کنیم؟

- برای سایت‌های خبری و فرهنگی
- برای مجله‌ها و وبلاگ‌های تخصصی
- برای نمونه‌های portfolio یا content-heavy websites

## چه زمانی نباید استفاده کنیم؟

- وقتی محتوا به‌صورت یک‌صفحه‌ای و ساده است
- وقتی منبع اصلی پروژه فروشگاهی است

## تفاوت با عناصر مشابه

- blog homepage نسبت به landing page بیشتر روی مقالات و دسته‌بندی‌ها تمرکز دارد
- sidebar برای اطلاعات جانبی و مقالات مرتبط استفاده می‌شود

## بهترین روش‌های استفاده

- برای مقاله‌های ویژه از `article` استفاده کنید
- از `aside` برای sidebar و اطلاعات مرتبط استفاده کنید
- nav و categories را به‌صورت منظم organiz کنید

## اشتباهات رایج

- داشتن sidebar بدون semantic مناسب
- دسته‌بندی‌ها بدون ساختار منظم
- تداخل بین محتوا و فوتر

## نکات بازار کار

وبلاگ‌های حرفه‌ای در شرکت‌ها یا مجله‌های دیجیتال از HTML semantic و structure مناسب بهره می‌برند. این نوع پروژه برای یادگیری real-world HTML بسیار ارزشمند است.

## چک‌لیست یادگیری

- [ ] صفحه‌ی وبلاگ را semantic می‌نویسم
- [ ] featured article و sidebar را درست می‌سازم
- [ ] categories و recent posts را منظم می‌کنم
- [ ] footer را کاربردی می‌گذارم

## تمرین

اکنون فایل Blog.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی وبلاگ با header و navigation بساز.
2. یک featured article برای مقاله‌ی اصلی اضافه کن.
3. یک sidebar با دسته‌بندی و recent posts بساز.
4. یک بخش comments برای مقالات اضافه کن.
5. یک footer با لینک‌های مهم طراحی کن.
6. یک نسخه‌ی متفاوت از blog homepage ایجاد کن.
7. یک صفحه‌ی مجله‌ی دیجیتال با categories و sidebar بساز.
8. یک layout برای مقاله‌های خبری طراحی کن.
9. یک نمونه‌ی blog با focus روی featured post بساز.
10. یک نسخه‌ی حرفه‌ای از صفحه‌ی اصلی وبلاگ طراحی کن.

## درس بعدی

در درس بعدی پروژه‌ی فروشگاهی با header، دسته‌بندی، کارت محصول و newsletter ساخته می‌شود.
