# Audio

## این مبحث چیست؟

عنصر `<audio>` برای پخش فایل‌های صوتی در صفحه استفاده می‌شود. این عنصر برای پادکست، آهنگ، اعلان‌های صوتی و فایل‌های آموزشی بسیار کاربردی است.

## چرا از آن استفاده می‌کنیم؟

- اضافه کردن صدا به تجربه‌ی کاربری
- ارائه‌ی محتوای صوتی در وب
- ساخت پخش‌کننده‌ی ساده و استاندارد

## چه زمانی استفاده می‌کنیم؟

- پادکست و آموزش‌های صوتی
- سایت‌های موسیقی و رسانه
- بخش‌های اطلاع‌رسانی و خبر

## چه زمانی نباید استفاده کنیم؟

- وقتی صدا برای کاربر ضروری نیست
- وقتی فایل صوتی حجم زیادی دارد و بارگذاری آن مشکل‌ساز است
- وقتی صدا برای تجربه‌ی کاربری ضروری نیست و فقط مزاحمت ایجاد می‌کند

## تفاوت با عناصر مشابه

- `<audio>` برای فایل‌های صوتی است
- `<video>` برای فایل‌های ویدیویی است
- `<img>` برای تصاویر است

## بهترین روش‌های استفاده

- از `controls` برای دسترسی کاربر استفاده کنید
- از چند `source` برای پشتیبانی بهتر استفاده کنید
- برای کاهش بارگذاری از `preload` معقول استفاده کنید

## اشتباهات رایج

- حذف `controls` و در نتیجه عدم دسترسی کاربر
- استفاده از فایل‌های بی‌کیفیت یا حجیم بدون بهینه‌سازی
- نادیده گرفتن متن جایگزین یا توضیح برای کاربر

## نکات بازار کار

در وب‌سایت‌های رسانه‌ای، آموزشی و برندینگ، پخش‌کننده‌ی صوتی جزو بخش‌های رایج است. استفاده‌ی درست از این عنصر در UI حرفه‌ای اهمیت دارد.

## چک‌لیست یادگیری

- [ ] عنصر `audio` را می‌شناسم
- [ ] از `source` و `controls` استفاده می‌کنم
- [ ] برای پادکست و رسانه‌های صوتی مناسب است
- [ ] بارگذاری و دسترس‌پذیری را در نظر می‌گیرم

## تمرین

اکنون یک فایل جدید با نام

Audio.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک پخش‌کننده‌ی صوتی ساده با controls بساز.
2. یک بخش پادکست با چند فایل صوتی ایجاد کن.
3. یک صفحه‌ی آموزشی با فایل صوتی و متن همراه بساز.
4. یک نمونه‌ی رادیو آنلاین با `audio` ایجاد کن.
5. یک بخش معرفی برند با فایل صوتی کوتاه بساز.
6. یک صفحه‌ی رسانه با چند source طراحی کن.
7. یک قالب پخش‌کننده‌ی حرفه‌ای با استایل ساده بساز.
8. یک صفحه‌ی معرفی محصول با فایل صوتی توضیحی بساز.
9. یک نمونه‌ی صفحه‌ی پادکست با عنوان و زمان ایجاد کن.
10. یک صفحه‌ی کامل رسانه‌ای با `audio` و اطلاعات مرتبط بساز.
