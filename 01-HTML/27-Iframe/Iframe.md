# Iframe

## این مبحث چیست؟

عنصر `<iframe>` برای جاسازی محتوای خارجی در صفحه‌ی وب استفاده می‌شود. این محتوا می‌تواند شامل نقشه، ویدیو، فرم، یا صفحه‌ی دیگری باشد.

## چرا از آن استفاده می‌کنیم؟

- جاسازی محتواهای خارجی بدون ترک صفحه
- نمایش ابزارها و سرویس‌های ثالث
- ساخت تجربه‌ی کاربری ترکیبی و چندمنظوره

## چه زمانی استفاده می‌کنیم؟

- نقشه‌ی گوگل
- ویدیوهای خارجی
- فرم‌ها و ابزارهای تعبیه‌شده
- پلتفرم‌های ابری و سرویس‌های آنلاین

## چه زمانی نباید استفاده کنیم؟

- وقتی محتوای اصلی باید مستقیماً در صفحه باشد
- وقتی iframe از نظر امنیتی یا عملکردی ریسک دارد
- وقتی جایگزین ساده‌تر و امن‌تری وجود دارد

## تفاوت با عناصر مشابه

- `<iframe>` برای embed خارجی است
- `<video>` و `<audio>` برای رسانه‌ی مستقیم داخل صفحه‌اند
- `<img>` برای تصویر است

## بهترین روش‌های استفاده

- از `title` برای دسترس‌پذیری استفاده کنید
- `loading="lazy"` را برای بهینه‌سازی استفاده کنید
- فقط از منابع معتبر و مطمئن استفاده کنید
- برای امنیت، iframe را با دقت کنترل کنید

## اشتباهات رایج

- استفاده‌ی بی‌دلیل از iframe
- نادیده گرفتن `title`
- جاسازی منابع غیرمعتبر یا پرهزینه

## نکات بازار کار

در پروژه‌های واقعی، iframe برای جاسازی ابزارهای خارجی بسیار پرکاربرد است. اما استفاده‌ی درست و ایمن آن برای کیفیت کد و امنیت اهمیت دارد.

2. یک iframe برای ویدیوی خارجی اضافه کن.
3. یک صفحه‌ی پشتیبانی با iframe ابزار چت طراحی کن.
4. یک بخش جاسازی فرم از سرویس خارجی ایجاد کن.
5. یک نمونه‌ی صفحه‌ی رزرو با iframe نقشه بساز.
6. یک صفحه‌ی آموزشی با چند iframe مختلف ایجاد کن.
7. یک صفحه‌ی وبسایت شرکت با بخش جاسازی محتوا طراحی کن.
8. یک صفحه‌ی رسانه‌ای با iframe ویدیو بساز.
9. یک صفحه‌ی محصول با iframe دمو یا نقشه ایجاد کن.
10. یک نسخه‌ی حرفه‌ای از صفحه‌ی اطلاعات تماس با iframe نقشه بساز.
