# Header، Main و Footer

## این مبحث چیست؟

این سه عنصر پایه‌ای‌ترین بخش‌های ساختار یک صفحه‌ی وب هستند. `header` برای اطلاعات اولیه، `main` برای محتوای اصلی و `footer` برای اطلاعات پایانی استفاده می‌شوند.

## چرا از آن استفاده می‌کنیم؟

- ساختار واضح‌تر برای صفحه
- بهبود دسترس‌پذیری
- کمک به سئو و درک بهتر محتوا

## چه زمانی استفاده می‌کنیم؟

- سایت‌های شرکتی
- فروشگاه‌ها و صفحه‌های محصول
- وبلاگ و صفحه‌های آموزشی

## چه زمانی نباید استفاده کنیم؟

- برای بخش‌های داخلی صفحه که محتوای اصلی نیستند
- برای چندین `main` در یک صفحه
- برای قرار دادن محتوای جانبی در `header` یا `footer`

## تفاوت با عناصر مشابه

- `header` برای شروع صفحه یا بخش است
- `main` تنها محتوای اصلی صفحه است
- `footer` اطلاعات پایان صفحه را شامل می‌شود
- `div` جایگزین ساده‌تر ولی معنایی ندارد

## بهترین روش‌های استفاده

- فقط یک `main` در هر صفحه داشته باشید
- `header` را در سطح صفحه یا در بخش‌های بزرگ به‌کار ببرید
- `footer` را برای اطلاعات تکمیلی و لینک‌های مفید استفاده کنید

## اشتباهات رایج

- استفاده از `header` برای منوهای داخلی بدون هدف semantic
- قرار دادن چند `main` در یک صفحه
- استفاده‌ی بی‌هدف از `footer` برای بخش‌های غیرمرتبط

## نکات بازار کار

این ساختار در پروژه‌های واقعی برای خوانایی کد و فهم بهتر صفحه بسیار مهم است. در code review معمولاً یکی از اولین موارد بررسی‌شده است.

## چک‌لیست یادگیری

- [ ] تفاوت `header` و `main` را می‌دانم
- [ ] یک `main` در هر صفحه استفاده می‌کنم
- [ ] `footer` را برای اطلاعات پایانی به‌کار می‌برم
- [ ] ساختار صفحه را خوانا می‌سازم

## تمرین

اکنون یک فایل جدید با نام

HeaderMainFooter.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی شرکت با `header`، `main` و `footer` بساز.
2. یک وبلاگ با هدر، محتوای اصلی و پاورقی ایجاد کن.
3. یک صفحه‌ی فروشگاهی با ساختار اصلی طراحی کن.
4. یک صفحه‌ی آموزشی با بخش‌های مختلف ایجاد کن.
5. یک صفحه‌ی landing با هدر و footer حرفه‌ای بساز.
6. یک قالب dashboard با بخش‌های اصلی ایجاد کن.
7. یک صفحه‌ی خدمات با ساختار واضح بساز.
8. یک صفحه‌ی مستندات را با ساختار semantic کامل طراحی کن.
9. یکصفحه‌ی شخصی با معرفی و لینک‌های مهم بساز.
10. یک نسخه‌ی حرفه‌ای از سایت شرکتی طراحی کن.
