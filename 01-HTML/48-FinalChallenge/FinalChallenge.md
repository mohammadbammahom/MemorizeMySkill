# Final Challenge

## این مبحث چیست؟

این بخش چالش نهایی برای تمرین طراحی یک پروژه‌ی چندصفحه‌ای و جمع‌بندی مهارت‌های HTML در سطح حرفه‌ای است.

## چرا از آن استفاده می‌کنیم؟

- مرور تمام مهارت‌های HTML در تمرین واقعی
- ساختن نمونه‌ای مشابه پروژه‌های واقعی
- التقاط مهارت‌های ساختار، فرم، semantic و layout

## چه زمانی استفاده می‌کنیم؟

- در پایان دوره برای ارزیابی نهایی
- در پروژه‌های واقعی برای ساخت یک بنیاد حرفه‌ای
- برای فهم بهتر اینکه چه چیزهایی در HTML برتر هستند

## چه زمانی نباید استفاده کنیم؟

- در ابتدای مسیر یادگیری
- زمانی که فقط تمرینات پایه مورد نیاز است

## تفاوت با عناصر مشابه

- این چالش، یک تمرین پروژه‌ای نهایی است و به جای تئوری، روی اجرای کامل تمرکز دارد
- برخلاف درس‌های قبلی، هیچ راه‌حل آماده‌ای ارائه نمی‌شود

## بهترین روش‌های استفاده

- ابتدا صفحه‌ی اصلی را طراحی کن
- سپس صفحات فرعی برای بخش‌های اصلی بساز
- در پایان semantic و accessibility را بازبینی کن

## اشتباهات رایج

- شروع بدون مفاهیم ساختار
- نداشتن تمرین عملی دقیق
- نادیده گرفتن پیاده‌سازی قابل‌فهم و maintainable

## نکات بازار کار

چالش نهایی نشان می‌دهد که HTML تنها زبان تگ‌ها نیست؛ یک مهارت سازمان‌یافته برای ساخت تجربه‌ی کاربری قابل‌پیش‌بینی است.

## چک‌لیست یادگیری

- [ ] صفحه‌ی اصلی را با ساختار semantic می‌سازم
- [ ] صفحات فرعی را به‌صورت coherent طراحی می‌کنم
- [ ] لینک‌ها و فرم‌ها را درست تنظیم می‌کنم
- [ ] پروژه را برای مرور نهایی آماده می‌کنم

## تمرین

اکنون یک پروژه‌ی کامل چندصفحه‌ای طراحی کن که شامل این بخش‌ها باشد:

1. صفحه‌ی اصلی با hero و navigation
2. صفحه‌ی درباره‌ی ما
3. صفحه‌ی خدمات یا محصولات
4. صفحه‌ی تماس با فرم
5. footer و global layout
6. لینک‌گذاری بین صفحات
7. استفاده‌ی درست از semantic HTML
8. ساختمان‌بندی محتوا برای readability
9. نمایش real-world structure
10. یک پروژه‌ی نهایی بدون راه‌حل برای تمرین مستقل

## درس بعدی

در پایان دوره، دو فایل سطح بالا یعنی roadmap و cheat sheet ساخته می‌شوند.
