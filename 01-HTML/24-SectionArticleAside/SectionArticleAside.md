# Section، Article و Aside

## این مبحث چیست؟

این عناصر برای ساختاردهی محتوای صفحه استفاده می‌شوند. هر کدام نقش متفاوتی دارند و انتخاب درستشان در پروژه‌های واقعی اهمیت زیادی دارد.

## چرا از آن استفاده می‌کنیم؟

- ساختار معنایی بهتر
- سئو و دسترس‌پذیری بهتر
- نگهداری آسان‌تر کد

## چه زمانی استفاده می‌کنیم؟

- وبلاگ و خبرنامه
- فروشگاه‌ها و صفحات محصول
- صفحات مستندات و آموزشی

## چه زمانی نباید استفاده کنیم؟

- وقتی محتوای ویرایش‌شده‌ای نداریم که از نظر معنایی نیازمند جدا شدن باشد
- وقتی از این عناصر فقط برای استایل‌دهی استفاده می‌کنیم
- وقتی انتخاب‌اشتباه، مفهوم صفحه را مبهم می‌کند

## تفاوت با عناصر مشابه

- `<section>` برای بخش‌هایی با موضوع مشخص است
- `<article>` برای محتوای مستقل و قابل استفاده دوباره است
- `<aside>` برای اطلاعات مکمل و جانبی است
- `<div>` برای گروه‌بندی ساده و بدون معنا

## بهترین روش‌های استفاده

- از `section` برای بخش‌های منظم استفاده کنید
- `article` را فقط برای محتوای مستقل به‌کار ببرید
- `aside` را برای منوها، لینک‌های مرتبط و اطلاعات مکمل استفاده کنید

## اشتباهات رایج

- تبدیل همه‌ی بخش‌ها به `section`
- استفاده‌ی نادرست از `article` برای هر بلوک متن
- استفاده‌ی غیرمعنایی از `aside`

## نکات بازار کار

در تیم‌های بزرگ، انتخاب درست این عناصر به‌خاطر readability و maintainability بسیار مهم است. معمولاً در code review روی این موضوع تأکید می‌شود.

## چک‌لیست یادگیری

- [ ] تفاوت `section` و `article` را می‌دانم
- [ ] `aside` را برای اطلاعات جانبی استفاده می‌کنم
- [ ] تصمیم semantic خود را منطقی می‌گیرم
- [ ] از `div` فقط وقتی لازم است استفاده می‌کنم

## تمرین

اکنون یک فایل جدید با نام

SectionArticleAside.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. یک صفحه‌ی وبلاگ با `section` و چند `article` بساز.
2. یک صفحه‌ی محصول با بخش‌های مرتبط و `aside` ایجاد کن.
3. یک صفحه‌ی خبر با چند بخش جداگانه طراحی کن.
4. یک صفحه‌ی آموزشی با `section` و `aside` بساز.
5. یک صفحه‌ی خدمات با بخش‌های مستقل ایجاد کن.
6. یک صفحه‌ی مستندات با `article` و `section` طراحی کن.
7. یک صفحه‌ی فروشگاهی با محتوای جانبی و مطالب مرتبط بساز.
8. یک نسخه‌ی حرفه‌ای از صفحه‌ی وبلاگ با ساختار semantic درست طراحی کن.
9. یک صفحه‌ی رزرو خدمات با بخش‌های مرتبط و حاشیه‌ای بساز.
10. یک نمونه‌ی کامل از سایت خبری یا مجله طراحی کن.
