# HTML Best Practices

## این مبحث چیست؟

بهترین روش‌های HTML مجموعه‌ای از اصولی است که یک توسعه‌دهنده‌ی حرفه‌ای برای نوشتن کد تمیز، قابل فهم و قابل نگهداری باید رعایت کند.

## چرا از آن استفاده می‌کنیم؟

- خوانایی بهتر کد
- کاهش خطاها
- سازگاری با تیم، مرورگر و ابزارهای توسعه

## چه زمانی استفاده می‌کنیم؟

- هنگام پیاده‌سازی پروژه‌های واقعی
- زمان code review
- هنگام بازنویسی یا توسعه‌ی مجدد پروژه

## چه زمانی نباید استفاده کنیم؟

- وقتی کد بدون ساختار و semantic نوشته می‌شود
- وقتی هر بخش با `div` بی‌محتوا ساخته می‌شود
- وقتی نام‌گذاری‌ها مبهم و ناهماهنگ هستند

## تفاوت با عناصر مشابه

- بهترین روش‌ها به داوری حرفه‌ای مربوط‌اند
- HTML clean صرفاً از نظر ظاهر نیست، بلکه از نظر معنا، نگهداری و عملکرد مهم است

## بهترین روش‌های استفاده

- از semantic HTML به‌صورت طبیعی استفاده کنید
- کلاس‌ها و نام‌ها را معنی‌دار بگذارید
- برای هر عنصر هدف مشخص داشته باشید
- ساختار صفحه را برای SEO و accessibility بهینه کنید

## اشتباهات رایج

- استفاده‌ی بی‌رویه از `div`
- نام‌گذاری غیرمعنایی مانند `box1`
- کدهای تکراری و شلوغ

## نکات بازار کار

در تیم‌های واقعی، grade‌ی کد به میزان خوانایی، semantic و maintainability آن بستگی دارد. این مهارت یک مزیت واقعی برای یک front-end engineer است.

## چک‌لیست یادگیری

- [ ] HTML را semantic می‌نویسم
- [ ] نام‌گذاری‌ها را معنی‌دار می‌کنم
- [ ] ساختار صفحه را تمیز نگه می‌دارم
- [ ] برای production code آماده‌سازی می‌کنم

## تمرین

اکنون فایل HTMLBestPractices.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک فرم clean و semantic با label درست بساز.
2. یک صفحه‌ی خدمات با ساختار منظم و readable طراحی کن.
3. یک صفحه‌ی وبلاگ با بخش‌های semantic خوب بساز.
4. یک بخش landing page با naming مناسب ایجاد کن.
5. یک صفحه‌ی product با ساختار منظم و class‌های معنادار بساز.

9. یک نمونه‌ی dashboard با layout معنی‌دار بساز.
10. یک نسخه‌ی production-ready از یک سایت ساده طراحی کن.
