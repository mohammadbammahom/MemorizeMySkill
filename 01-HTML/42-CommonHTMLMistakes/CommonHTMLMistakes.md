# Common HTML Mistakes

## این مبحث چیست؟

اشتباهات رایج HTML معمولاً از سرعت، کم‌توجهی یا نداشتن تجربه‌ی کافی در ساختار و semantic به وجود می‌آیند. این درس به شما کمک می‌کند همان خطاها را شناسایی و اصلاح کنید.

## چرا از آن استفاده می‌کنیم؟

- جلوگیری از خرابی در نمایش و دسترس‌پذیری
- کاهش خطاهای سئو و maintainability
- بهبود کیفیت کد برای team collaboration

## چه زمانی استفاده می‌کنیم؟

- هنگام بازبینی کدها
- در تست پروژه‌های واقعی
- در جلسات code review و linting

## چه زمانی نباید استفاده کنیم؟

- وقتی کد از قبل semantic و درست است
- وقتی باید یک مشکل به‌صورت ریشه‌ای رفع شود
- وقتی فقط با ظاهر کد کار می‌کنیم و به معنای آن توجه نمی‌کنیم

## تفاوت با عناصر مشابه

- بعضی خطاها semantic هستند
- بعضی خطاها accessibility هستند
- بعضی خطاها به SEO و فرم‌ها مربوط می‌شوند

## بهترین روش‌های استفاده

- کد را به‌صورت خوانا و طبقه‌بندی‌شده بنویسید
- هر خطا را به‌صورت ریشه‌ای اصلاح کنید
- از validator و inspection استفاده کنید

## اشتباهات رایج

- تکرار `id`
- heading hierarchy نامناسب
- نبودن `alt` برای تصویر
- استفاده از `button` برای لینک
- `label` بدون `for`

## نکات بازار کار

در تیم‌های حرفه‌ای، بسیاری از مشکلات HTML به‌دلیل چند خطا ساده در ساختار یا semantic اتفاق می‌افتد. توانایی دیدن این اشتباهات در یک نگاه مهارت مهمی است.

## چک‌لیست یادگیری

- [ ] invalid nesting را می‌شناسم
- [ ] duplicate IDs را تشخیص می‌دهم
- [ ] heading hierarchy را درست می‌سازم
- [ ] خطاهای فرم و accessibility را می‌بینم

## تمرین

اکنون فایل CommonHTMLMistakes.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک HTML نامعتبر با nesting اشتباه پیدا و اصلاح کن.
2. یک `id` تکراری در صفحه ایجاد و دوباره درست کن.
3. یک عکس بدون `alt` را اصلاح کن.
4. یک heading hierarchy نامناسب را به‌صورت درست بازنویسی کن.
5. یک فرم با label و button نادرست را اصلاح کن.
6. یک بخش FAQ با semantic اشتباه را درست کن.
7. یک صفحه‌ی landing با `nav` نامناسب را اصلاح کن.
8. یک صفحه‌ی blog با title و heading ناسازگار را بازنویسی کن.
9. یک نمونه‌ی صفحه‌ی ecommerce با اشتباهات accessibility پیدا کن.
10. یک پروژه‌ی complete با مشکلات متداول را بازسازی کن.
