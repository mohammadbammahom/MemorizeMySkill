# Dialog

## این مبحث چیست؟

عنصر `<dialog>` برای ساخت پنجره‌های مدال یا دیالوگ در صفحه استفاده می‌شود. این عنصر تجربه‌ی کاربری را بهتر می‌کند و نیازی به ساختار پیچیده با JavaScript ندارد.

## چرا از آن استفاده می‌کنیم؟

- نمایش پیام‌های مهم یا تأیید اقدامات
- ساخت مودال‌های ساده و استاندارد
- بهبود تجربه‌ی تعامل در فرم‌ها و اقدامات کاربر

## چه زمانی استفاده می‌کنیم؟

- تأیید حذف یا ثبت اطلاعات
- نمایش جزئیات محصول یا فرم ورود
- پنجره‌های اطلاع‌رسانی و راهنمای کاربر

## چه زمانی نباید استفاده کنیم؟

- برای اعلان‌های کم‌اهمیت و ثابت
- برای بخش‌های عادی صفحه که باید همیشه در دسترس باشند
- وقتی فقط یک `<div>` ساده کافی است

## تفاوت با عناصر مشابه

- `<dialog>` برای پنجره‌ی تعاملی و مدال طراحی شده است
- `<div>` فقط برای گروه‌بندی است
- `<details>` برای محتواهای قابل باز و بسته است

## بهترین روش‌های استفاده

- برای مدال‌های مهم از `showModal()` استفاده کنید
- دکمه‌ی بستن واضح و قابل دسترس داشته باشید
- از `aria` و فشردن Escape پشتیبانی کنید

## اشتباهات رایج

- استفاده‌ی بی‌دلیل از مدال برای هر پیام
- نادیده گرفتن دسترس‌پذیری
- عدم بستن پنجره بعد از تعامل

## نکات بازار کار

در پروژه‌های وب مدرن، مدال‌ها برای تجربه‌ی کاربری حرفه‌ای بسیار مهم‌اند. اما بیش‌ازحد استفاده کردن از آنها تجربه را خراب می‌کند.

## چک‌لیست یادگیری

- [ ] مفهوم `dialog` را می‌فهمم
- [ ] تفاوت آن با `div` و `details` را می‌دانم
- [ ] یک مدال ساده باز و بسته می‌کنم
- [ ] در پروژه‌های واقعی از آن درست استفاده می‌کنم
