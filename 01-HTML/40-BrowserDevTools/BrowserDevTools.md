# Browser DevTools

## این مبحث چیست؟

DevTools ابزار اصلی برای بررسی، اشکال‌زدایی و بهینه‌سازی HTML و CSS در مرورگر است. این ابزار به شما کمک می‌کند ساختار صفحه را در لحظه ببینید، تگ‌ها را بررسی کنید و مشکلات واقعی UI را پیدا کنید.

## چرا از آن استفاده می‌کنیم؟

- بررسی سریع DOM و تگ‌ها
- فهم درست رفتار مرورگر
- پیدا کردن خطاها و بهبود UX

## چه زمانی استفاده می‌کنیم؟

- هنگام بررسی صفحه‌ی محصول
- در تست responsive بودن سایت
- هنگام رفع خطای semantic یا accessibility

## چه زمانی نباید استفاده کنیم؟

- وقتی کدها به‌طور کامل در فایل‌ها بررسی نشده‌اند
- وقتی هیچ بازبینی از ساختار HTML انجام نشده است
- وقتی فقط بر اساس حدس از مشکل عبور می‌کنیم

## تفاوت با عناصر مشابه

- Elements برای بررسی ساختار است
- Network برای بارگذاری و درخواست‌ها است
- Accessibility برای سنجش دسترس‌پذیری است

## بهترین روش‌های استفاده

- همیشه ابتدا HTML را در Elements ببینید
- Responsive Mode را برای قالب‌های موبایل استفاده کنید
- در Accessibility به تحلیل رفتار صفحه‌خوان توجه کنید

## اشتباهات رایج

- اعتماد به حدس و بدون بررسی DOM
- فراموش کردن `Network` برای بررسی بارگذاری
- عدم تست در حالت موبایل

## نکات بازار کار

در پروژه‌های واقعی، DevTools بخشی از روزمره‌ی توسعه‌دهنده‌‌ست. توانایی خواندن DOM و ردیابی مشکل در چند دقیقه مهارت مهمی است.

## چک‌لیست یادگیری

- [ ] Elements را می‌شناسم
- [ ] DOM را در مرورگر بازبینی می‌کنم
- [ ] Responsive Mode را استفاده می‌کنم
- [ ] Accessibility Panel را می‌فهمم
- [ ] workflow اشکال‌زدایی را می‌دانم

## تمرین

اکنون فایل BrowserDevTools.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. عنصر اصلی صفحه را در Elements بررسی کن.
2. یک `<div>` اضافه و آن را با ابزارهای DevTools حذف کن.
3. responsive layout برای موبایل بساز و نتیجه را تست کن.
4. یک `label` نامرتبط در فرم پیدا و اصلاح کن.
5. یک heading hierarchy نامناسب را اصلاح کن.
6. در Network یک تصویر یا فایل را بررسی کن.
7. یک مشکل accessibility در دکمه‌ها پیدا کن.
8. یک بخش FAQ را با DevTools بازبینی کن.
9. یک لینک نامرتبط را تشخیص داده و اصلاح کن.
10. یک صفحه‌ی واقعی را به‌صورت end-to-end debug کن.
