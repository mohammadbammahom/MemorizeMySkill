# ES9 / ES2018 Roadmap

## What changed in ES9?

ES9 introduced object rest/spread, promise.prototype.finally, and async iteration improvements.

## Why it matters

These updates made asynchronous code easier to manage and object manipulation more expressive.

## Key topics

- Object rest/spread
- `Promise.prototype.finally`
- Async iteration improvements

## Difficulty

Intermediate.

## Recommended order

1. Learn object spread
2. Understand `finally`
3. Use it in async workflows

## Interview topics

- How does object spread differ from object assign?
- Why is `finally` useful?
