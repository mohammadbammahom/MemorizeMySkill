# معماری چرخه‌ی عمر Promise در ES9

---

## این مبحث چیست؟

Promise.prototype.finally() به ما اجازه می‌دهد بعد از پایان Promise، بدون توجه به موفقیت یا شکست، یک کار cleanup انجام دهیم.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، باید هنگام پایان یک عملیات، state را reset، loader را خاموش، یا log ثبت کنیم.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام بارگذاری داده
- هنگام درخواست به API
- هنگام بستن connection یا session
- هنگام پاک‌سازی state

---

## چه زمانی نباید استفاده کنیم؟

اگر نیاز باشد نتیجه‌ی موفقیت یا شکست را در cleanup تغییر دهیم، بهتر است from try/catch و then/finally دقیق‌تر استفاده شود.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| then | پردازش موفقیت |
| catch | مدیریت خطا |
| finally | cleanup |

---

## مثال‌های واقعی

در صفحه‌ی پروفایل کاربر، بعد از دریافت داده، loading spinner بسته می‌شود و state به‌روزرسانی می‌شود.

---

## بهترین روش‌های استفاده

- برای cleanup از finally استفاده کن
- از finally برای بازگرداندن state به حالت اولیه استفاده کن
- خطا را در catch مدیریت کن

---

## اشتباهات رایج

1. استفاده از finally برای جایگزین کردن catch
2. انجام عملیات سنگین در finally
3. نادیده گرفتن خطاهای مهم

---

## نکات بازار کار

این مهارت برای مدیریت loading، error handling و state در برنامه‌های مدرن بسیار کاربردی است.
