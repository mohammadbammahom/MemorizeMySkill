# سیستم تبدیل داده در ES9

---

## این مبحث چیست؟

در این درس، داده‌ی خام برنامه به ساختاری امن، مرتب و مناسب برای API یا Front-End تبدیل می‌شود. این کار با Object Rest، Object Spread و تکنیک‌های کنترل‌شده‌ی تبدیل انجام می‌شود.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، داده‌ها از فرم داخلی به فرم عمومی و قابل‌استفاده تبدیل می‌شوند. این تبدیل باعث می‌شود اطلاعات حساس پنهان بماند و داده‌ی خروجی برای استفاده‌های بعدی آماده شود.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام آماده‌سازی پاسخ API
- هنگام تبدیل داده برای React state
- هنگام جدا کردن داده‌ی عمومی از داده‌ی داخلی
- هنگام آماده‌سازی report و service results

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها خیلی عمیق و nested باشند، spread فقط یک کپی سطحی انجام می‌دهد. در این حالت باید دقت بیشتری کرد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Object rest | جدا کردن بخش‌های خاص از object |
| Object spread | ساخت object جدید و ادغام داده |
| Object.assign() | ادغام object به‌صورت mutable |

---

## مثال‌های واقعی

در یک سرویس کاربری، داده‌ی passwordHash، internalNotes و اطلاعات حساس از object عمومی حذف می‌شوند تا یک نسخه‌ی امن برای UI ارسال شود.

---

## بهترین روش‌های استفاده

- داده‌های حساس را جدا کن
- از object rest برای حذف فیلدهای خاص استفاده کن
- از object spread برای ساخت نسخه‌ی جدید استفاده کن
- با دقت از shallow copy استفاده کن

---

## اشتباهات رایج

1. تصور اینکه spread deep copy انجام می‌دهد
2. mutation روی object اصلی
3. استفاده از داده‌ی حساس در output نهایی
