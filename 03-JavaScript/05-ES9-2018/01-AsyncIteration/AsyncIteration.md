# تکرار ناهمزمان در ES9

---

## این مبحث چیست؟

تکرار ناهمزمان (Async Iteration) یک روش است برای پردازش مقادیری که به‌صورت ناهمزمان می‌آیند. با استفاده از `Symbol.asyncIterator` و `for await...of`، می‌توانی داده‌های stream-like را به‌صورت منطقی پردازش کنی.

---

## چرا از آن استفاده می‌کنیم؟

وقتی داده‌ها از منابع ناهمزمان می‌آیند (مثل API، فایل‌ها، یا پایگاه داده‌ها)، نیاز داریم آن‌ها را به‌ترتیب و منطقی پردازش کنیم. Async iteration برای این کار طراحی شده است.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام خواندن داده‌های stream-like از API
- هنگام خواندن فایل‌ها و پردازش خط به خط
- هنگام سمولیت کردن داده‌های ناهمزمان
- هنگام پردازش داده‌های بزرگ به‌صورت تدریجی

---

## چه زمانی نباید استفاده کنیم؟

اگر تمام داده‌ها در حافظه موجود هستند و می‌توانی از Promise.all یا حلقه‌ی عادی استفاده کنی، نیازی به async iteration نیست.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| for...of | تکرار سنکرون بر روی آیتم‌ها |
| for await...of | تکرار ناهمزمان بر روی آیتم‌های ناهمزمان |
| Symbol.iterator | آیتریتور سنکرون |
| Symbol.asyncIterator | آیتریتور ناهمزمان |
| Promise.all() | اجرای همزمان چند Promise |

---

## مثال‌های واقعی

در یک سیستم خواندن فایل‌های بزرگ، می‌توانی هر خط را به‌صورت ناهمزمان بخوانی و پردازش کنی. یا در API pagination، می‌توانی صفحه‌های مختلفی را یکی‌یکی بارگذاری کنی.

---

## بهترین روش‌های استفاده

- Symbol.asyncIterator را به‌درستی پیاده‌سازی کن
- از for await...of برای خوانایی بهتر استفاده کن
- خطاها را در حلقه مدیریت کن
- timeout و error handling را شامل کن

---

## اشتباهات رایج

1. فراموش کردن Symbol.asyncIterator
2. بدون Promise در next() method
3. عدم handling خطاهای ناهمزمان
4. بی‌پایان loop

---

## نکات بازار کار

Async iteration یکی از قابلیت‌های مهم در Node.js و دنیای streams است. در مصاحبه‌های backend، سؤال رایجی است. در React، برای مدیریت داده‌های ناهمزمان بسیار کاربردی است.
