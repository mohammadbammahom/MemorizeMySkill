# سیستم اعتبارسنجی و parsing در ES9

---

## این مبحث چیست؟

در این درس، یک سیستم ساده اما کاربردی برای اعتبارسنجی و parsing داده‌ها ساخته می‌شود. این سیستم با RegExp، نتیجه‌ی اعتبارسنجی، و تبدیل داده‌ها کار می‌کند تا از ورودی‌های نامعتبر جلوگیری شود.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، ورودی‌ها همیشه تمیز و قابل‌اعتماد نیستند. باید قبل از پردازش یا ذخیره‌سازی، داده‌ها بررسی، استانداردسازی و در صورت لزوم اصلاح شوند.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام بررسی username یا transaction ID
- هنگام تحلیل لاگ‌ها
- هنگام بررسی ورودی API
- هنگام استانداردسازی داده‌های ورودی

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها خیلی پیچیده یا ساختارمند باشند، RegExp به‌تنهایی ممکن است کافی نباشد و بهتر است از منطق کسب‌وکار یا parser تخصصی‌تر استفاده شود.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| validation | بررسی درست یا نادرست بودن داده |
| parsing | استخراج اطلاعات از متن |
| normalization | تبدیل داده به فرم استاندارد |
| sanitization | حذف یا اصلاح داده‌های نامناسب |

---

## مثال‌های واقعی

در یک سیستم مالی، شناسه‌ی تراکنش یا قالب لاگ باید قبل از ثبت و گزارش‌گیری بررسی شود.

---

## بهترین روش‌های استفاده

- برای الگوهای واضح از RegExp استفاده کن
- نتیجه‌ی validation را ساختارمند بازگردان
- parsing را از validation جدا کن
- برای داده‌های پیچیده از منطق جداگانه استفاده کن

---

## اشتباهات رایج

1. تصور اینکه RegExp همه‌ی سناریوها را پوشش می‌دهد
2. استفاده‌ی بیش از حد از regex برای منطق پیچیده
3. نادیده گرفتن خطای کاربر در ورودی

---
