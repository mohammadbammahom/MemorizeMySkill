# تبدیل امن داده‌های object در ES9

---

## این مبحث چیست؟

در این درس، تمرکز روی تبدیل داده‌ی object به شکلی است که اطلاعات حساس جدا شوند و داده‌ی عمومی برای API یا UI آماده شود. این کار در ES9 با Object Rest و Object Spread به‌صورت روشن و قابل‌پیش‌بینی انجام می‌شود.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، داده‌ی کاربر یا مشتری باید قبل از ارسال به لایه‌های دیگر پاک‌سازی و تبدیل شود. اگر این کار انجام نشود، داده‌ی حساس ممکن است به اشتباه منتشر شود.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام ساخت پاسخ API
- هنگام آماده‌سازی داده برای Front-End
- هنگام تبدیل داده‌ی کاربر به state
- هنگام جدا کردن permission و metadata

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها عمیقاً تودرتو باشند، spread فقط یک کپی سطحی انجام می‌دهد. بنابراین برای nested objects باید دقت بیشتری کرد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Object rest | جدا کردن قسمت‌های خاص از object |
| Object spread | ساخت object جدید با ادغام داده |
| Object.assign() | ادغام object به‌صورت mutable |

---

## مثال‌های واقعی

در یک API، داده‌ی password از object کاربر حذف می‌شود و یک نسخه‌ی امن برای UI یا سرویس‌های دیگر ارسال می‌شود.

---

## بهترین روش‌های استفاده

- داده‌های حساس را جدا کن
- از object spread برای ساخت object جدید استفاده کن
- برای transform‌های کنترل‌شده از یک تابع مشخص استفاده کن

---

## اشتباهات رایج

1. تصور اینکه spread copy عمیق انجام می‌دهد
2. mutation روی object اصلی
3. ترکیب داده‌ی حساس با داده‌ی عمومی
