# IteratorsAndGenerators

---

## این مبحث چیست؟

Iterator و Generator در ES6 ساختارهایی برای تعریف توالی داده‌ها ارائه می‌دهند. Iterator به ما اجازه می‌دهد هر بار یک مقدار از مجموعه را برداریم و Generator یک روش ساده برای ایجاد iterableهای سفارشی است.

---

## چرا از آن استفاده می‌کنیم؟

این ابزارها به ما اجازه می‌دهند داده‌های تودرتو یا پیوسته را به صورت مرحله‌ای پردازش کنیم و کنترل بیشتری روی جریان اجرای داده داشته باشیم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- مقادیر را به صورت مرحله‌ای تولید کنیم
- یک مجموعه قابل پیمایش بسازیم
- از for...of یا spread روی یک مجموعه استفاده کنیم

مثال:

```javascript
function* countUpTo(limit) {
  let count = 1;
  while (count <= limit) {
    yield count;
    count += 1;
  }
}
```

---

## چه زمانی نباید استفاده کنیم

اگر داده‌ها ثابت و ساده هستند، نیازی به generator نیست. برای مجموعه‌های کوچک و پایدار می‌توان از آرایه یا ساختارهای عادی استفاده کرد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Iterator | پیمایش مرحله‌ای |
| Generator | تولید مقدار در صورت نیاز |
| Array | لیست کامل |
| for loop | پیمایش سنتی |

---

## بهترین روش‌های استفاده

- برای داده‌های بزرگ یا داینامیک از generator استفاده کن.
- iterableهای سفارشی را با Symbol.iterator بساز.
- از spread و for...of برای خواندن cleaner استفاده کن.

---

## اشتباهات رایج

1. استفاده از generator برای مجموعه‌های کوچک ثابت
2. باز کردن کل iterator در حافظه
3. فراموش کردن return یا done در iterator

---

## نکات بازار کار

در React و Node.js، iterableهای سفارشی برای پردازش داده و libraries مفید هستند. در مصاحبه‌ها ممکن است از شما بپرسند generator چگونه کار می‌کند یا چرا از iterator استفاده می‌کنید.
