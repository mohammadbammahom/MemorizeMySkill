# MapAndSet

---

## این مبحث چیست؟

Map و Set دو ساختار داده جدید در ES6 هستند که برای نگهداری مجموعه‌هایی از مقادیر کاربرد دارند. Map یک مجموعه کلید-مقدار نگه می‌دارد و Set مقادیر یکتا را ذخیره می‌کند.

---

## چرا از آن استفاده می‌کنیم؟

این ساختارها به ما کمک می‌کنند داده‌ها را با عملکرد بهتر و نگهداری ساده‌تر مدیریت کنیم. Map برای ذخیره اطلاعات با کلیدهای دلخواه مناسب است و Set برای حذف مقادیر تکراری کاربرد دارد.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- داده‌ها را با کلیدهای پویا نگهداری کنیم
- مقدارهای تکراری را حذف کنیم
- عملکرد بهتری نسبت به آبجکت خام داشته باشیم

مثال:

```javascript
const studentScores = new Map();
studentScores.set("Ali", 90);
```

---

## چه زمانی نباید استفاده کنیم

اگر ساختار داده ساده است و فقط چند مقدار ثابت دارد، نیازی به Map یا Set نیست. در این موارد می‌توانیم از آرایه یا آبجکت معمولی استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Map | مجموعه کلید-مقدار |
| Object | ساختار کلید-مقدار سنتی |
| Set | مجموعه بدون تکرار |
| Array | لیست مرتب |

---

## بهترین روش‌های استفاده

- برای انبار کلید-مقدارهای پویا از Map استفاده کن.
- برای حذف مقادیر تکراری از Set استفاده کن.
- از روش‌های داخلی size، has و delete استفاده کن.

---

## اشتباهات رایج

1. استفاده از Map به‌جای Object ساده وقتی نیازی به ویژگی‌های اضافی نیست.
2. افزودن مقادیر تکراری به Set و انتظار تغییرات نامشخص.
3. دسترسی به Map با نحو آبجکت به‌جای متد get.

---

## نکات بازار کار

در React و Node.js، Map و Set برای ذخیره‌سازی سریع و lookupهای بهینه مفید هستند. در مصاحبه‌ها ممکن است از شما بپرسند تفاوت Map و Object یا Set و Array چیست.
