# Classes

---

## این مبحث چیست؟

کلاس‌ها در ES6 سینتکس جدیدی برای تعریف اشیاء و رفتار آنها ارائه می‌دهند. این ساختار به سبک OOP نزدیک‌تر است و کد را منظم‌تر می‌کند.

---

## چرا از آن استفاده می‌کنیم؟

کلاس‌ها به ما اجازه می‌دهند اشیای مشابه را با constructor و متدهای مشترک تعریف کنیم. این روش در پروژه‌های بزرگ کمک می‌کند کد قابل نگه‌داری‌تر باشد.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- اشیاء با رفتار مشخص ایجاد کنیم
- constructor برای مقداردهی اولیه داشته باشیم
- متدهای مشترک را تعریف کنیم

مثال:

```javascript
class Account {
  constructor(owner, balance) {
    this.owner = owner;
    this.balance = balance;
  }
}
```

---

## چه زمانی نباید استفاده کنیم

اگر فقط چند شیء ساده دارید، کلاس ممکن است بیش از حد باشد. در پروژه‌های کوچک، توابع سازنده یا اشیا ساده کافی هستند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| class | تعریف اشیای OOP |
| constructor | مقداردهی اولیه |
| prototype | رفتار به اشتراک‌گذاشته |
| object literal | تعریف شیء ساده |

---

## بهترین روش‌های استفاده

- متدها را داخل class تعریف کن.
- از constructor برای مقداردهی اولیه استفاده کن.
- رفتار مشترک را داخل class قرار بده.

---

## اشتباهات رایج

1. تعریف متدها به صورت خارج از class
2. استفاده‌ی نادرست از this
3. ساختن کلاس‌های بسیار بزرگ

---

## نکات بازار کار

در React و Node.js، کلاس‌ها برای ساخت کامپوننت‌ها و مدل‌های داده‌ای کاربرد دارند. در مصاحبه‌ها اغلب از شما می‌خواهند تفاوت کلاس و prototype را شرح دهید.
