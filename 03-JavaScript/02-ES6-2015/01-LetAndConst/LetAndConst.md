# LetAndConst

---

## این مبحث چیست؟

let و const دو نوع اعلان متغیر در ES6 هستند. const برای مقادیری استفاده می‌شود که نباید دوباره اختصاص داده شوند و let برای متغیرهای قابل تغییر در بلوک‌های محلی به کار می‌رود.

---

## چرا از آن استفاده می‌کنیم؟

این دو ساختار به ما کمک می‌کنند از باگ‌های مرتبط با scope جلوگیری کنیم و کد را واضح‌تر و قابل نگهداری‌تر بنویسیم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- مقدار ثابت را تعریف کنیم
- متغیرهای محلی در بلوک‌ها داشته باشیم
- از خطاهای مربوط به hoisting جلوگیری کنیم

مثال:

```javascript
const maxStudents = 30;
let currentStudents = 18;
```

---

## چه زمانی نباید استفاده کنیم

اگر به مقدار بعداً نیاز به تغییر دارد، از const استفاده نکنیم. اگر متغیر در سطح global لازم نیست، از let در بلوک محلی استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| var | تابع یا global scope |
| let | بلوک scope |
| const | مقدار ثابت |
| function | تعریف تابع |

---

## بهترین روش‌های استفاده

- از const به‌صورت پیش‌فرض استفاده کن.
- برای متغیرهای تغییرپذیر تنها از let استفاده کن.
- از var در کد جدید استفاده نکن.

---

## اشتباهات رایج

1. استفاده از const برای مقادیر قابل تغییر
2. فراموش کردن بلوک scope برای let
3. اعتماد به hoisting در let و const

---

## نکات بازار کار

در پروژه‌های React و Node.js، استفاده مناسب از let و const نقش مهمی در کیفیت کد دارد. در مصاحبه‌ها از شما انتظار می‌رود تفاوت بین آنها را توضیح دهی.
