# WeakMapAndWeakSet

---

## این مبحث چیست؟

WeakMap و WeakSet ساختارهای داده‌ای جدید ES6 هستند که برای نگهداری اشیاء به صورت ضعیف طراحی شده‌اند. این مجموعه‌ها به garbage collector اجازه می‌دهند اگر دیگر ارجاعی به شیء نباشد، آن را پاک کنند.

---

## چرا از آن استفاده می‌کنیم؟

این ساختارها برای مدیریت داده‌های مرتبط با اشیاء و cacheهای موقت مناسب هستند. زمانی که نمی‌خواهیم ارجاع دائمی به شیء حفظ شود، WeakMap و WeakSet گزینه‌های بهتری نسبت به Map و Set معمولی هستند.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- اطلاعات کمکی برای شیءها ذخیره کنیم بدون ایجاد حلقه مرجع قوی
- کش موقت بسازیم
- وضعیت مرتبط با شیء را بدون مدیریت دستی حافظه نگه داریم

مثال:

```javascript
const userCache = new WeakMap();
userCache.set(userOne, { lastLogin: "2026-08-01" });
```

---

## چه زمانی نباید استفاده کنیم

اگر لازم است تعداد عناصر را دریافت کنیم یا همه‌ی کلیدها را پیمایش کنیم، WeakMap و WeakSet مناسب نیستند. آنها برای ذخیره‌سازی دائمی یا تکراری داده‌ها طراحی نشده‌اند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| WeakMap | ذخیره‌سازی داده‌های کمکی برای اشیاء |
| WeakSet | نگهداری مجموعه‌ای از اشیاء یکتا |
| Map | نگهداری کلید-مقدار با ارجاع قوی |
| Set | مجموعه‌ای از مقادیر یکتا |

---

## بهترین روش‌های استفاده

- در cacheهای موقت از WeakMap استفاده کن.
- برای مجموعه‌های اشیاء که نیاز به پاک شدن خودکار دارند، WeakSet را به‌کار ببر.
- از آنها فقط برای ذخیره‌سازی اطلاعات مرتبط با اشیاء استفاده کن.

## نکات بازار کار

در React و Node.js، WeakMap و WeakSet برای ذخیره‌ی metadata و cache بدون نگه داشتن ارجاع قوی کاربرد دارند. در مصاحبه‌ها از شما ممکن است بخواهند تفاوت کلیدی WeakMap و Map را شرح دهید.
