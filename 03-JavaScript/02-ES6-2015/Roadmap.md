# ES6 / ES2015 Roadmap

## What changed in ES6?

ES6 brought major improvements to JavaScript, including block-scoped variables, arrow functions, classes, modules, and improved syntax.

## Why it matters

- It made JavaScript more expressive.
- It helped developers write cleaner and more maintainable code.
- It laid the foundation for modern frontend development.

## Key topics

- `let` and `const`
- Arrow functions
- Template literals
- Destructuring
- Classes
- Modules

## Difficulty

Beginner to intermediate.

## Recommended order

1. `let` and `const`
2. Arrow functions
3. Template literals
4. Destructuring
5. Classes
6. Modules

## Interview topics

- What is the difference between `let` and `var`?
- Why use arrow functions?
- How do modules improve project structure?
