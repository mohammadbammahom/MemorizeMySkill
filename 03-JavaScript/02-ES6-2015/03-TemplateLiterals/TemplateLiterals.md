# TemplateLiterals

---

## این مبحث چیست؟

template literal یک روش جدید در ES6 برای ساخت رشته‌هاست. این ساختار با استفاده از backtick (`) امکان interpolation و چند خطی بودن رشته‌ها را فراهم می‌کند.

---

## چرا از آن استفاده می‌کنیم؟

استفاده از template literal باعث می‌شود رشته‌ها خواناتر شوند و نیازی به + برای ترکیب مقادیر نباشد. این ویژگی برای تولید پیام‌ها، HTML و گزارش‌های متنی بسیار مفید است.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- رشته‌ها را با مقادیر متغیر ترکیب کنیم
- متن چند خطی بسازیم
- قالب‌های مشخص تولید کنیم

مثال:

```javascript
const summary = `Student: ${studentName}
Course: ${courseName}`;
```

---

## چه زمانی نباید استفاده کنیم

اگر رشته‌ای کوتاه و ساده است، template literal ممکن است لازم نباشد. برای متن دینامیک پیچیده می‌توان از توابع قالب‌سازی بهره برد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| string concat | ترکیب رشته‌ها با + |
| template literal | interpolation و چند خطی |
| format | قالب‌بندی پیشرفته |
| string interpolation | جایگزینی مقادیر در رشته |

---

## بهترین روش‌های استفاده

- از template literal برای رشته‌های چند خطی استفاده کن.
- از interpolation برای مقادیر داینامیک بهره ببر.
- کد را با قالب‌های روشن و قابل خواندن بنویس.

---

## اشتباهات رایج

1. استفاده از + برای رشته‌های طولانی
2. نکردن escape صحیح در رشته‌ها
3. ترکیب template literal و string غیرمنظم

---

## نکات بازار کار

در React و Node.js، قالب‌های رشته‌ای به ویژه در متن‌های ساختاری و پیام‌های سرور بسیار کاربرد دارند. در مصاحبه‌ها هم توانایی ساخت رشته با template literal امتیاز مثبت دارد.
