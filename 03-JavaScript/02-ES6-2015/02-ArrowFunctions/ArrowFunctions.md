# ArrowFunctions

---

## این مبحث چیست؟

arrow function در ES6 یک نوشتار کوتاه‌تر برای تعریف تابع است. این سبک نوشتن به ویژه در callbackها و توابع مرتب‌سازی کاربرد دارد.

---

## چرا از آن استفاده می‌کنیم؟

استفاده از arrow function باعث می‌شود کد کوتاه‌تر، کمتر تکراری و خواناتر شود. همچنین بسیاری از الگوهای برنامه‌نویسی مدرن مثل React و functional programming با آن سازگارترند.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- توابع کوچک و ساده تعریف کنیم
- callbackها را تمیز کنیم
- کد functional بنویسیم

مثال:

```javascript
const squared = numbers.map(number => number * number);
```

---

## چه زمانی نباید استفاده کنیم

اگر تابع پیچیده است و بدنه‌ی زیادی دارد، بهتر است از تابع معمولی استفاده کنیم. همچنین اگر می‌خواهیم this خاصی را تعریف کنیم، arrow function مناسب نیست.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| function | تابع کلاسیک |
| arrow function | تابع کوتاه‌تر |
| callback | تابع پاس‌شده به تابع دیگر |
| method | متد در شیء |

---

## بهترین روش‌های استفاده

- برای callbackهای ساده از arrow function استفاده کن.
- برای توابعی که فقط یک عبارت بازمی‌گردانند، سینتکس کوتاه را به‌کار ببر.
- در متدهای شیء و زمانی که به this نیاز داری، از function معمولی استفاده کن.

---

## اشتباهات رایج

1. استفاده از arrow function برای متدهای شیء
2. تعریف توابع بزرگ با arrow function
3. فراموش کردن اینکه arrow function this ندارد

---

## نکات بازار کار

در React و پروژه‌های مدرن، arrow function در JSX و callbackها بسیار رایج است. در مصاحبه‌ها معمولا از شما می‌پرسند چرا از arrow function استفاده می‌کنید و تفاوت آن با function را توضیح دهید.
