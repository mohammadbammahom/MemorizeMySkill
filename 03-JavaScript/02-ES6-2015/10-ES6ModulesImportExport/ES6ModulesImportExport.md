# ES6ModulesImportExport

---

## این مبحث چیست؟

ماژول‌های ES6 روش استاندارد برای تقسیم کد بین فایل‌های مختلف هستند. با استفاده از export و import می‌توان بخش‌های مختلف برنامه را جدا، قابل استفاده مجدد و مرتب نگه داشت.

---

## چرا از آن استفاده می‌کنیم؟

استفاده از ماژول‌ها باعث می‌شود کد سازمان‌دهی‌شده‌تر شود، نگهداری آن آسان‌تر شود و امکان استفاده مجدد از توابع و مقادیر در پروژه‌های بزرگ فراهم شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- کد را بین چند فایل تقسیم کنیم
- توابع یا مقادیر مشترک را به اشتراک بگذاریم
- ساختار پروژه را تمیزتر کنیم

مثال:

```javascript
export const appName = "ES6 Module Demo";
export function getAppInfo() {
  return appName;
}
```

---

## چه زمانی نباید استفاده کنیم

اگر پروژه خیلی کوچک است و فقط یک فایل کافی است، استفاده از ماژول‌ها ممکن است بیش از حد باشد. همچنین برای کدهای آزمایشی ساده بهتر است از یک فایل واحد استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| export | ارسال مقدار یا تابع از ماژول |
| import | دریافت مقدار یا تابع از ماژول |
| module | فایل کد جداگانه |
| script | فایل کد بدون ماژول |

---

## بهترین روش‌های استفاده

- ماژول‌ها را برای بخش‌های مستقل و قابل استفاده مجدد بساز.
- از export و import برای جداسازی منطق استفاده کن.
- نام ماژول‌ها و مقادیر را واضح و معنادار انتخاب کن.

---

## اشتباهات رایج

1. استفاده‌ی بی‌دلیل از ماژول برای پروژه‌های خیلی کوچک
2. اشتباه در مسیر import
3. export نکردن مقادیر موردنیاز

---

## نکات بازار کار

در پروژه‌های React، Node.js و توسعه Front-End مدرن، ماژول‌سازی بخش مهمی از ساختار پروژه است. در مصاحبه‌ها، آشنایی با import/export یکی از مهارت‌های پایه محسوب می‌شود.
