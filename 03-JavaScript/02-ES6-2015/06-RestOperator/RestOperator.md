# RestOperator

---

## این مبحث چیست؟

عملگر rest در ES6 به ما اجازه می‌دهد تعداد نامشخصی پارامتر را داخل آرایه‌ای جمع کنیم. این ویژگی برای توابعی که با چند ورودی متغیر کار می‌کنند، بسیار کاربردی است.

---

## چرا از آن استفاده می‌کنیم؟

استفاده از rest operator کد تابع را ساده‌تر می‌کند و نیاز به نوشتن آرگومان‌های ثابت را از بین می‌برد. این روش در APIها و توابع کمکی کاربرد زیادی دارد.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- چند ورودی نامشخص را دریافت کنیم
- آرایه‌ای از مقادیر را پردازش کنیم
- توابعی ساده و قابل استفاده مجدد بسازیم

مثال:

```javascript
const sumAll = (...numbers) => numbers.reduce((total, number) => total + number, 0);
```

---

## چه زمانی نباید استفاده کنیم

اگر تعداد پارامترها همیشه ثابت است، بهتر است از پارامترهای مشخص استفاده کنیم. rest operator برای همه‌ی توابع مناسب نیست.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| rest operator | جمع کردن آرگومان‌ها به آرایه |
| spread operator | باز کردن آرایه به مقادیر |
| arguments | دسترسی به آرگومان‌ها در فانکشن‌های کلاسیک |
| array | نگهداری مجموعه‌ای از مقادیر |

---

## بهترین روش‌های استفاده

- زمانی که تعداد آرگومان نامشخص است، از rest استفاده کن.
- از بررسی typeof یا length برای پردازش مقدارها استفاده کن.
- ورودی‌های نامشخص را به صورت یک آرایه مدیریت کن.

---

## اشتباهات رایج

1. استفاده از rest برای پارامترهای ثابت
2. فراموش کردن reduce یا حلقه برای پردازش
3. تلاش برای تغییر مستقیم آرایهٔ rest

---

## نکات بازار کار

در React و Node.js، rest operator برای کامپوننت‌ها، هندلرهای رویداد و توابع utility بسیار کاربردی است. در مصاحبه‌ها از شما انتظار می‌رود تفاوت rest و spread را توضیح دهید.
