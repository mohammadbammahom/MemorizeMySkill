# DestructuringAssignment

---

## این مبحث چیست؟

destructuring assignment در ES6 یک روش مختصر برای استخراج مقادیر از اشیاء و آرایه‌ها است. این قابلیت کمک می‌کند کدهای پاک‌تر و خواناتر بنویسیم.

---

## چرا از آن استفاده می‌کنیم؟

این روش باعث می‌شود به‌جای نوشتن چند خط برای دسترسی به مقادیر، به‌سادگی آنها را استخراج کنیم. این کار به ویژه در زمان استفاده از پاسخ API و ساختاردهی داده‌ها مفید است.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- مقادیر خاصی از یک شیء بگیریم
- مقدارهای آرایه را به متغیرها اختصاص دهیم
- پارامترهای تابع را به صورت مستقیم باز کنیم

مثال:

```javascript
const { name, role } = user;
const [x, y] = point;
```

---

## چه زمانی نباید استفاده کنیم

اگر نیاز به استخراج تعداد زیادی مقدار با نام‌های خیلی متفاوت داریم، این روش ممکن است چشم‌نواز نباشد. برای مواقع ساده‌تر، دسترسی مستقیم با نقطه نیز کافی است.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| destructuring | استخراج مقادیر |
| dot notation | دسترسی مستقیم |
| array index | دسترسی به آرایه |
| default parameter | مقدار پیش‌فرض |

---

## بهترین روش‌های استفاده

- از destructuring برای پاسخ API و پارامترهای تابع استفاده کن.
- اگر نام متغیرها باید متفاوت باشد، از alias استفاده کن.
- برای کد خواناتر، از تخصیص چندگانه استفاده کن.

---

## اشتباهات رایج

1. استفاده‌ی نادرست از نام‌ها
2. فراموش کردن مقادیر پیش‌فرض
3. اشتباه در ترتیب مقادیر آرایه

---

## نکات بازار کار

در React و Node.js، destructuring برای props، state و پاسخ‌های API بسیار رایج است. در مصاحبه‌ها معمولاً از شما می‌خواهند destructuring را در مثال واقعی نشان دهید.
