# DefaultParameters

---

## این مبحث چیست؟

default parameters در ES6 به ما اجازه می‌دهند اگر هنگام فراخوانی تابع آرگومان خاصی ندادیم، مقدار پیش‌فرضی برای آن استفاده شود. این ویژگی باعث می‌شود توابع انعطاف‌پذیرتر و ساده‌تر شوند.

---

## چرا از آن استفاده می‌کنیم؟

با default parameters دیگر نیازی به بررسی undefined داخل تابع برای مقداردهی پیش‌فرض نداریم. تابع‌ها خواناتر می‌شوند و مدیریت مقدارهای گمشده آسان‌تر می‌شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- پارامترهای اختیاری داشته باشیم
- یک رفتار پیش‌فرض برای تابع مشخص کنیم
- کد را خلاصه‌تر و مطمئن‌تر بنویسیم

مثال:

```javascript
const createUser = (name = "Ali", role = "student") => {
  return { name, role, active: true };
};
```

---

## چه زمانی نباید استفاده کنیم

اگر مقدار پیش‌فرض باید به‌صورت داینامیک درون تابع محاسبه شود، بهتر است از منطق داخلی استفاده کنیم. default parameters برای همه موارد پیچیده مناسب نیست.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| default parameter | مقدار پیش‌فرض هنگام نبود آرگومان |
| ternary | شرط داخل مقداردهی |
| if statement | بررسی وضعیت درون تابع |
| optional argument | آرگومان اختیاری |

---

## بهترین روش‌های استفاده

- برای پارامترهای اختیاری، مقدار پیش‌فرض مشخص کن.
- از default parameters برای مقادیر ساده و قابل فهم استفاده کن.
- برای مقادیر پیچیده، محاسبه را داخل تابع نگه دار.

---

## اشتباهات رایج

1. استفاده از default parameter برای مقادیر null یا false
2. قرار دادن logic سنگین در مقدار پیش‌فرض
3. فراموش کردن تعریف مقدار پیش‌فرض برای مقادیر اختیاری

---

## نکات بازار کار

در React و Node.js، default parameters برای کامپوننت‌ها، توابع سرویس و APIها بسیار کاربردی است. در مصاحبه‌ها معمولاً از شما انتظار می‌رود دلیل استفاده از آن را توضیح دهید.
