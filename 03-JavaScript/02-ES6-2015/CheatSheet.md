# ES6 Cheat Sheet

## Syntax

```js
const name = 'Ada';
let count = 1;

const add = (a, b) => a + b;
```

## Common features

- `let`
- `const`
- Arrow functions
- Template literals
- Destructuring
- Classes
- Modules

## Quick reference

| Feature | Example |
| --- | --- |
| Block scope | `let x = 1;` |
| Constants | `const PI = 3.14;` |
| Arrow function | `const f = x => x * 2;` |
| Template literal | `` `Hello ${name}` `` |
| Destructuring | `const {a, b} = obj;` |
