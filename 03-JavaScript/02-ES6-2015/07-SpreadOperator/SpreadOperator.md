# SpreadOperator

---

## این مبحث چیست؟

عملگر spread در ES6 به ما اجازه می‌دهد آرایه‌ها و اشیا را به‌صورت جداگانه باز کنیم. این قابلیت برای کپی‌سازی سریع و ترکیب داده‌ها مناسب است.

---

## چرا از آن استفاده می‌کنیم؟

spread operator از روش‌های ساده و امن برای کپی آرایه و شیء پشتیبانی می‌کند. این باعث می‌شود بدون تغییر دادهٔ اولیه، مجموعه‌های جدید تولید کنیم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- یک آرایه را گسترش دهیم
- اشیا را با هم ادغام کنیم
- پارامترها را به یک تابع باز کنیم

مثال:

```javascript
const newArray = [...baseArray, "newItem"];
const config = { ...defaultConfig, theme: "dark" };
```

---

## چه زمانی نباید استفاده کنیم

اگر قصد داریم فقط یک refernce به آرایه یا شیء بسازیم، spread مناسب نیست. در این حالت باید از ارجاع مستقیم یا روش‌های کپی عمیق استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| spread | گسترش آرایه یا شیء |
| rest | جمع کردن آرگومان‌ها |
| Object.assign | ادغام اشیا |
| array concat | ترکیب آرایه‌ها |

---

## بهترین روش‌های استفاده

- برای کپی کردن آرایه یا شیء از spread استفاده کن.
- هنگام اضافه کردن مقدار جدید به آرایه، از spread استفاده کن.
- در React برای props و state به spread تکیه کن.

---

## اشتباهات رایج

1. گمان اینکه spread یک کپی عمیق ایجاد می‌کند
2. استفاده از spread برای اشیاء با توابع بزرگ
3. فراموش کردن ترتیب ادغام اشیا

---

## نکات بازار کار

در React، spread operator برای props و state update بسیار پرکاربرد است. در Node.js برای ترکیب تنظیمات و کپی داده‌ها بسیار مفید است. مصاحبه‌ها معمولا تفاوت spread و rest را می‌پرسند.
