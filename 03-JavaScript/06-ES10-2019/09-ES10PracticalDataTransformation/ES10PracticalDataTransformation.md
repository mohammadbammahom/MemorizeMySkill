# تبدیل داده‌ی عملی در ES10

---

## این مبحث چیست؟

در این درس، چند مفهوم ES10 در یک جریان عملی ترکیب می‌شوند: flat()، flatMap()، trimStart()، trimEnd()، Object.entries() و Object.values(). هدف، ساخت یک سیستم ساده اما کاربردی برای پاک‌سازی و تبدیل داده است.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، داده‌ها معمولاً هم تودرتو هستند و هم با متن‌های آلوده یا فضای اضافی. این درس نشان می‌دهد که چگونه این داده‌ها را به فرم قابل‌استفاده تبدیل کنیم.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام پردازش داده‌های API
- هنگام آماده‌سازی گزارش
- هنگام پاک‌سازی ورودی کاربر
- هنگام تبدیل داده برای Front-End یا Node.js

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها خیلی بزرگ و پیچیده باشند، ممکن است بهتر باشد ساختار را قبل از تبدیل واضح‌تر کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| flat() | صاف‌کردن آرایه‌های تودرتو |
| flatMap() | تبدیل و صاف‌کردن در یک مرحله |
| trimStart()/trimEnd() | حذف فضای اضافی از متن |
| Object.entries() | تبدیل object به آرایه‌ی زوج‌ها |

---

## مثال‌های واقعی

در یک برنامه‌ی فروش، داده‌ی کاربران، سفارش‌ها و مجوزها را باید قبل از گزارش‌گیری پاک‌سازی و تبدیل کرد.

---

## بهترین روش‌های استفاده

- داده را مرحله‌ای clean و transform کن
- برای آرایه‌های تودرتو از flat() یا flatMap() استفاده کن
- برای متن‌های ورودی از trimStart()/trimEnd() استفاده کن

---

## اشتباهات رایج

1. استفاده‌ی بی‌دلیل از flat(Infinity)
2. نادیده گرفتن whitespace در متن
3. تبدیل بیش از حد داده بدون نیاز

---

## نکات بازار کار

این مهارت برای کار با داده‌های API، React و Node.js بسیار ارزشمند است.
