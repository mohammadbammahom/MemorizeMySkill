# ES10 Cheat Sheet

## Syntax

```js
const flattened = arr.flat();
const mapped = arr.flatMap(x => [x, x * 2]);
const obj = Object.fromEntries(entries);
```

## Quick reference

| Feature | Example |
| --- | --- |
| Flat | `arr.flat()` |
| Flat map | `arr.flatMap()` |
| From entries | `Object.fromEntries(entries)` |
