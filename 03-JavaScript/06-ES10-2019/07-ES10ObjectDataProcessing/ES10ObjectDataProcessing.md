# پردازش داده‌ی object در ES10

---

## این مبحث چیست؟

در این درس، داده‌های object با روش‌های ES10 مثل Object.entries()، Object.values() و Object.keys() به فرم قابل‌پردازش تبدیل می‌شوند. این کار برای گزارش‌گیری، آماری‌سازی و آماده‌سازی داده‌ها بسیار کاربردی است.

---

## چرا از آن استفاده می‌کنیم؟

بسیاری از داده‌های برنامه‌ها از نوع object هستند. برای تبدیل آن‌ها به آرایه و اجرای عملیات‌های Array methods، این روش‌ها بسیار مفیدند.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام پردازش permission map
- هنگام ساخت report از object
- هنگام آماده‌سازی Front-End state
- هنگام تحلیل آمار از object

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها به‌صورت بسیار ساده و مستقیم باشند، استفاده از این روش‌ها ممکن است بیش از حد باشد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Object.keys() | گرفتن کلیدها |
| Object.values() | گرفتن مقادیر |
| Object.entries() | گرفتن زوج key/value |

---

## مثال‌های واقعی

در یک برنامه‌ی کاربری، map مجوزها یا آمار کاربران را می‌توان به‌صورت object نگه داشت و سپس برای report به آرایه تبدیل کرد.

---

## بهترین روش‌های استفاده

- برای پردازش داده از Object.entries() استفاده کن
- برای جمع‌آوری مقادیر از Object.values() استفاده کن
- برای فیلتر کردن و تبدیل داده‌ها از Array methods استفاده کن

---

## اشتباهات رایج

1. تصور اینکه object به‌صورت خودکار به آرایه تبدیل می‌شود
2. استفاده از Object.keys() برای کارهایی که Object.entries() بهتر است
3. نادیده گرفتن ساختار داده
