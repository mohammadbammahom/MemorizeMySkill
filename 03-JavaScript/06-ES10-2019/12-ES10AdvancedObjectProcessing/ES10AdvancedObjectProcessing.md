# بازسازی و پردازش پیشرفته‌ی Object در ES10

---

## این مبحث چیست؟

در این درس، Object.entries() و Object.fromEntries() برای تبدیل، فیلتر و بازسازی آبجکت‌ها استفاده می‌شوند. این کار برای کار با داده‌ی API، تنظیمات، مجوزها و گزارش‌ها بسیار مفید است.

---

## چرا از آن استفاده می‌کنیم؟

چندین بار در برنامه‌ها لازم می‌شود آبجکت‌ها را تبدیل، تغییر نام کلیدها و بازسازی کنیم. این روش‌ها این فرآیند را ساده‌تر و خواناتر می‌کنند.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام تبدیل آبجکت به آرایه و برعکس
- هنگام تنظیم کردن داده‌ی API
- هنگام ساخت گزارش از تنظیمات و مجوزها
- هنگام بازسازی آبجکت‌های ورودی

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها به‌صورت عمیق و پیچیده‌اند، بازسازی ساده ممکن است کافی نباشد و بهتر است ساختار داده را دوباره طراحی کنیم.

---

## تفاوت با مفاهیم مشابه

| روش | کاربرد |
|---|---|
| Object.keys() | گرفتن کلیدها |
| Object.values() | گرفتن مقادیر |
| Object.entries() | گرفتن زوج‌های کلید و مقدار |
| Object.fromEntries() | بازسازی آبجکت از زوج‌ها |

---

## مثال‌های واقعی

در برنامه‌های Front-End یا Node.js، می‌توان اطلاعات کاربر، تنظیمات و مجوزها را به فرم مناسب برای نمایش یا ارسال تبدیل کرد.

---

## بهترین روش‌های استفاده

- برای تبدیل آبجکت به فرم قابل‌پردازش از Object.entries() استفاده کن
- برای بازسازی از Object.fromEntries() استفاده کن
- قبل از بازسازی، داده‌ها را فیلتر یا تبدیل کن

---

## اشتباهات رایج

1. استفاده‌ی بی‌دلیل از Object.fromEntries()
2. نادیده گرفتن اینکه این روش shallow است
3. فراموش کردن تبدیل داده قبل از بازسازی
