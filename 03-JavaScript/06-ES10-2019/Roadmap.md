# ES10 / ES2019 Roadmap

## What changed in ES10?

ES10 introduced `Array.prototype.flat()`, `flatMap()`, `Object.fromEntries()`, and `String.prototype.trimStart()` / `trimEnd()`.

## Why it matters

These features simplify working with nested arrays and string cleanup.

## Key topics

- `flat()`
- `flatMap()`
- `Object.fromEntries()`

## Difficulty

Intermediate.

## Recommended order

1. Learn `flat()` and `flatMap()`
2. Use `Object.fromEntries()` for transforms
3. Practice string trim helpers

## Interview topics

- When is `flat()` helpful?
- How does `Object.fromEntries()` differ from `Object.entries()`?
