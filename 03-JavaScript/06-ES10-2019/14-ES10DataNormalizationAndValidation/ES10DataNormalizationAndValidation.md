# نرمال‌سازی و اعتبارسنجی داده در ES10

---

## این مبحث چیست؟

این درس یک pipeline عملی برای پاک‌سازی، اعتبارسنجی و نرمال‌سازی داده‌ها ارائه می‌دهد. هدف این است که داده‌های خام را به فرم قابل استفاده برای برنامه‌های Front-End یا سرویس‌های Node.js تبدیل کنیم.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، داده‌ها از منبع‌های مختلف می‌آیند و معمولاً نیاز به پاک‌سازی و پردازش دارند. نرمال‌سازی باعث می‌شود داده‌ها یکنواخت شوند و کار با آن‌ها ساده‌تر شود.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام پردازش داده‌ی API
- هنگام آماده‌سازی داده برای React
- هنگام ساخت گزارش و آمار
- هنگام مدیریت داده‌ی کاربر و سفارش

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها از قبل تمیز و استاندارد هستند، این مرحله ممکن است بیش از حد باشد.

---

## تفاوت با مفاهیم مشابه

| مرحله | کار |
|---|---|
| cleaning | حذف فضای اضافی و آماده‌سازی اولیه |
| validation | بررسی معتبر بودن داده |
| normalization | تبدیل داده به فرم یکنواخت |

---

## مثال‌های واقعی

در یک سیستم سفارش، نام کاربر، مجوزها و نقش‌های او باید قبل از ذخیره یا نمایش نرمال شوند.

---

## بهترین روش‌های استفاده

- clean، validate و normalize را از هم جدا کن
- داده‌ها را قبل از استفاده‌ی نهایی استاندارد کن
- برای داده‌های API از اینpipeline استفاده کن

---

## اشتباهات رایج

1. ترکیب کردن همه‌ی مراحل در یک تابع بزرگ
2. نادیده گرفتن اعتبارسنجی
3. نرمال‌سازی بدون پاک‌سازی اولیه

---

## نکات بازار کار

این مهارت در کار با داده‌ی واقعی، React، Node.js و سرویس‌های Backend بسیار مهم است.
