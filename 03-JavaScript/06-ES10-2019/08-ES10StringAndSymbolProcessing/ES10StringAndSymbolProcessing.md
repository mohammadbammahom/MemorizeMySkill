# پردازش متن و Symbol در ES10

---

## این مبحث چیست؟

در این درس، دو مفهوم مهم ES10 برای پاک‌سازی متن و کار با Symbols بررسی می‌شود: trimStart() و trimEnd() برای متن، و Symbol.description برای دسترسی به توضیح Symbol.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، ورودی کاربر یا داده‌ی API معمولاً با فضای اضافی همراه است. همچنین Symbols برای شناسه‌های داخلی و قابل‌ردیابی مفیدند.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام پاک‌سازی ورودی کاربر
- هنگام آماده‌سازی متن برای terminal output
- هنگام استفاده از Symbol برای شناسه‌های داخلی
- هنگام دیباگ و ردیابی داده‌ها

---

## چه زمانی نباید استفاده کنیم؟

اگر متن خیلی پیچیده باشد، trimStart() و trimEnd() فقط فضای ابتدایی و انتهایی را حذف می‌کنند و کارهای پیچیده‌تر را انجام نمی‌دهند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| trim() | حذف فضای شروع و پایان |
| trimStart() | حذف فضای شروع |
| trimEnd() | حذف فضای پایان |
| Symbol.description | خواندن توضیح Symbol |

---

## مثال‌های واقعی

در یک برنامه‌ی Node.js، ورودی کاربر را قبل از نمایش در terminal پاک‌سازی می‌کنیم. همچنین می‌توانیم از Symbol برای برچسب‌های داخلی استفاده کنیم.

---

## بهترین روش‌های استفاده

- برای پاک‌سازی ورودی از trimStart() و trimEnd() استفاده کن
- از Symbol.description برای دیباگ استفاده کن
- برای متن‌های پیچیده از منطق مناسب‌تر استفاده کن

---

## اشتباهات رایج

1. جایگزین کردن trimStart() با trim()
2. تصور اینکه Symbol.description همیشه معنا دارد
3. استفاده‌ی بیش از حد از Symbol برای داده‌های عمومی
