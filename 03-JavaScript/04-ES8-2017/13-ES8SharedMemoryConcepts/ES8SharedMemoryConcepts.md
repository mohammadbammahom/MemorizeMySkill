# SharedArrayBuffer و مفهوم اشتراک حافظه

---

## این مبحث چیست؟

SharedArrayBuffer در ES8 امکان اشتراک یک بافر حافظه میان چند execution context را فراهم می‌کند. این مفهوم به دسته‌ای از مشکلات مربوط به هم‌زمانی و هماهنگی اشاره دارد و معمولاً در سناریوهای پیشرفته‌تر مثل workerها کاربرد دارد.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌هایی که چند بخش به‌صورت هم‌زمان روی داده‌های یکسان کار می‌کنند، معمولاً نیاز به اشتراک حافظه وجود دارد. با SharedArrayBuffer می‌توان یک بافر مشترک بین بخش‌های مختلف ایجاد کرد، اما باید مراقب هم‌زمانی و خطرات race condition بود.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام طراحی برنامه‌های هم‌زمان پیشرفته
- هنگام استفاده از workerها یا محیط‌های چندexecution
- هنگام نیاز به اشتراک داده‌های عددی بین بخش‌های پردازشی

---

## چه زمانی نباید استفاده کنیم؟

اگر کد شما ساده است و فقط یک thread اصلی دارد، SharedArrayBuffer معمولاً لازم نیست. این مفهوم برای سناریوهای حرفه‌ای و پیچیده‌تر مناسب است و نباید به‌صورت اجباری در کدهای کاربردی عادی استفاده شود.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Array | آرایه معمولی و محلی |
| TypedArray | آرایه عددی با نوع مشخص |
| SharedArrayBuffer | بافر اشتراکی میان execution contexts |
| Atomics | عملیات ایمن و هم‌زمان برای حافظه اشتراکی |

---

## مثال‌های واقعی

یک برنامه پیچیده ممکن است بخواهد بین چند worker داده‌ای مشترک را بخواند و به‌روزرسانی کند. برای چنین هدفی، SharedArrayBuffer و Atomics راه‌حل‌های مرتبط هستند. اما این مدل برای کدنویسی معمولی و روزمره JavaScript مناسب نیست.

---

## بهترین روش‌های استفاده

- فقط در سناریوهای محاسباتی یا هم‌زمانی پیشرفته به‌کار ببرید
- در محیط‌های worker یا سیستم‌های پیچیده از آن استفاده کنید
- هم‌زمانی را با Atomics مدیریت کنید

---

## اشتباهات رایج

2. استفاده از SharedArrayBuffer بدون درک از هم‌زمانی
3. نادیده گرفتن محدودیت‌های محیط اجرا

این مبحث بیشتر برای درک عمیق‌تر concurrency و memory model در JavaScript است. در پروژه‌های حرفه‌ای و مصاحبه‌ها، نشان دادن آگاهی از SharedArrayBuffer و Atomics می‌تواند بسیار ارزشمند باشد.

## تمرین

یک SharedArrayBuffer بساز و روی آن با typed array چند مقدار را ثبت و به‌روزرسانی کن. سپس توضیح بده که چرا چنین ساختاری برای برنامه‌های ساده لازم نیست و در چه سناریوهایی واقعاً کاربرد دارد.
