# ES8 Cheat Sheet

## Syntax

```js
const entries = Object.entries(obj);
const values = Object.values(obj);
```

## Quick reference

| Feature | Example |
| --- | --- |
| Object entries | `Object.entries(obj)` |
| Object values | `Object.values(obj)` |
| Property descriptors | `Object.getOwnPropertyDescriptors(obj)` |
