# Object.values()

---

## این مبحث چیست؟

Object.values() یک روش ES8 است که تمام مقادیر یک object را به‌صورت آرایه بازمی‌گرداند. این روش برای پردازش داده‌ها، جمع‌آوری اعداد، فیلتر کردن مقادیر و تحلیل داده‌های ساختارمند بسیار مفید است.

---

## چرا از آن استفاده می‌کنیم؟

در بسیاری از سناریوها، ما داده‌ها را به‌صورت object نگه می‌داریم، اما برای محاسبه، فیلتر کردن یا گزارش‌گیری باید به آرایه تبدیل شوند. Object.values() این تبدیل را سریع و خوانا انجام می‌دهد.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام جمع‌آوری اعداد از یک object
- هنگام محاسبه میانگین، مجموع یا بیشترین مقدار
- هنگام تولید گزارش‌های آماری
- هنگام پیاده‌سازی منطق فیلتر روی داده‌ها

---

## چه زمانی نباید استفاده کنیم؟

اگر باید روی کلیدها هم کار کنیم، Object.entries() یا Object.keys() بهتر است. اگر داده‌ها از نوع Map هستند، روش‌های مربوط به Map مناسب‌ترند. همچنین اگر ساختار object خیلی پیچیده و غیرقابل‌بررسی است، مدل‌سازی آن باید اصلاح شود.

---

## تفاوت با مفاهوم مشابه

| روش | خروجی | کاربرد |
|---|---|---|
| Object.keys() | کلیدها | بررسی نام ویژگی‌ها |
| Object.values() | مقادیر | پردازش داده‌ها |
| Object.entries() | [key, value] | تحلیل کامل جفت‌ها |

---

## مثال‌های واقعی

در یک سیستم فروش، اطلاعات فروش هر کاربر در یک object نگهداری می‌شود. با Object.values() می‌توان مجموع فروش را محاسبه کرد، کاربران با فروش بالا را فیلتر کرد و گزارش نهایی را ساخت. در Front-End، این تکنیک برای نمایش داده‌های فرم، وضعیت‌های UI و سناریوهای داشبورد کاربرد دارد.
