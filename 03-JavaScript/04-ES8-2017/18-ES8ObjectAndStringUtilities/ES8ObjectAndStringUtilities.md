# ابزارهای Object و String در ES8

---

## این مبحث چیست؟

در ES8، چند ابزار بسیار کاربردی برای بررسی و قالب‌بندی داده‌ها معرفی شدند. این ابزارها باعث می‌شوند داده‌های object و string برای پردازش و نمایش بهتر آماده شوند.

---

## چرا از آن استفاده می‌کنیم؟

هنگام کار با داده‌های پیچیده، باید بتوانیم مقادیر، کلیدها و توصیف‌کننده‌های object را استخراج کنیم و همچنین رشته‌ها را برای نمایش بهتر قالب‌بندی کنیم.

---

## چه زمانی استفاده می‌کنیم؟

- هنگام پردازش داده‌های API
- هنگام ساخت گزارش‌ها و داشبوردها
- هنگام کار با tabel و داده‌های tabular
- هنگام آماده‌سازی خروجی‌های CLI

---

## چه زمانی نباید استفاده کنیم؟

اگر داده‌ها بسیار ساده هستند و نیاز به استخراج کامل ساختار object ندارید، این ابزارها ممکن است به‌صورت اضافی به نظر برسند. ولی در پروژه‌های واقعی، این کارها معمولاً لازم هستند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Object.values() | استخراج فقط مقادیر |
| Object.entries() | استخراج کلید و مقدار |
| Object.getOwnPropertyDescriptors() | بررسی جزئیات ویژگی‌ها |
| padStart() | اضافه‌کردن کاراکتر در ابتدای رشته |
| padEnd() | اضافه‌کردن کاراکتر در انتهای رشته |

---

## مثال‌های واقعی

اگر به یک لیست کاربران دسترسی داریم، می‌توانیم با Object.entries آن‌ها را به‌صورت جفت key/value بررسی کنیم. برای نمایش کدهای سفارش، می‌توانیم از padStart برای صفرگذاری و padEnd برای یکدست‌سازی استفاده کنیم.

---

## بهترین روش‌های استفاده

- برای استخراج مقادیر، Object.values را استفاده کنید
- برای چاپ key/value از Object.entries بهره ببرید
- برای بررسی کامل object، Object.getOwnPropertyDescriptors را تحلیل کنید
- برای نمایش منظم، padStart و padEnd را به کار ببرید

---

## اشتباهات رایج

1. استفاده از Object.keys به‌جای Object.values
2. فراموش کردن تبدیل به string قبل از pad
3. بررسی اشتباه روی property descriptors
