# ES8 / ES2017 Roadmap

## What changed in ES8?

ES8 introduced `Object.entries`, `Object.values`, `Object.getOwnPropertyDescriptors`, and async iteration helpers.

## Why it matters

These features made object handling and async patterns more practical.

## Key topics

- `Object.entries`
- `Object.values`
- `Object.getOwnPropertyDescriptors`

## Difficulty

Intermediate.

## Recommended order

1. Learn object helpers
2. Compare them with `Object.keys`
3. Practice with real configuration objects

## Interview topics

- How do `Object.entries()` and `Object.keys()` differ?
- Why are object helpers useful in modern JavaScript?
