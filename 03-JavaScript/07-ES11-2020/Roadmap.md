# ES11 / ES2020 Roadmap

## What changed in ES11?

ES11 introduced `nullish coalescing`, optional chaining, and `Promise.allSettled()`.

## Why it matters

These features made code safer when working with uncertain or missing values.

## Key topics

- Nullish coalescing
- Optional chaining
- `Promise.allSettled()`

## Difficulty

Intermediate.

## Recommended order

1. Learn optional chaining
2. Learn nullish coalescing
3. Study `allSettled()` for error-safe async workflows

## Interview topics

- What is the difference between `||` and `??`?
- Why is optional chaining useful?
