# ES7 / ES2016 Roadmap

## What changed in ES7?

ES7 added a small but useful feature: the `Array.prototype.includes()` method.

## Why it matters

It makes value checking easier and more readable than using indexOf.

## Key topics

- `includes()`
- Readability improvements

## Difficulty

Beginner.

## Recommended order

1. Learn `includes()`
2. Compare it with `indexOf`
3. Use it in real validation logic

## Interview topics

- When should you use `includes()` instead of `indexOf`?
- What does `includes()` return?
