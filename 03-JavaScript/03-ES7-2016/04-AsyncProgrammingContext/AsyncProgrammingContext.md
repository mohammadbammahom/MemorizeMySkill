# AsyncProgrammingContext

---

## این مبحث چیست؟

مدل اجرای غیرهمزمان در JavaScript به معنای این است که بعضی کارها بعد از انجام کارهای اصلی اجرا می‌شوند. در همین مسیر، مفهوم context یا این‌که this در هر لحظه به چه چیزی اشاره می‌کند، بسیار مهم می‌شود.

> نکته مهم: async/await در ES8 معرفی شد و نه ES7. بنابراین این درس درباره فضای اجرای غیرهمزمان و مدیریت context است، نه معرفی async/await.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، کارهایی مثل زمان‌بر شدن درخواست‌ها، خواندن فایل، تایمرها، رویدادهای صفحه و عملیات شبکه، روی زمان اجرای کد اثر می‌گذارند. به همین دلیل لازم است به درستی بفهمیم کد در چه لحظه‌ای اجرا می‌شود و this چه مقدارهایی می‌گیرد.

---

## چه زمانی استفاده می‌کنیم؟

زمانی که:

- از setTimeout یا setInterval استفاده می‌کنیم
- با رویدادهای DOM کار می‌کنیم
- callback‌ها را اجرا می‌کنیم
- می‌خواهیم context متد‌های آبجکتی را حفظ کنیم

---

## مثال ساده

```javascript
const user = {
  name: "Muhammad",
  greet() {
    console.log(this.name);
  }
};

user.greet();

const greetLater = user.greet;
greetLater();
```

در مثال بالا، ممکن است this در حالت دوم به مقدار اشتباه اشاره کند. برای حفظ context باید از bind یا arrow function استفاده شود.

---

## تفاوت‌ها

| مفهوم | کاربرد |
|---|---|
| synchronous | اجرای هم‌زمان و سریالی |
| asynchronous | اجرای بعداً و غیرهمزمان |
| this | context اجرایی |
| bind | حفظ context |

---

## مثال‌های واقعی

در برنامه‌های وب، هنگام کلیک روی دکمه، callback باید بداند کدام instance یا component را مدیریت می‌کند. اگر context از دست برود، داده‌ها و state ممکن است به اشتباه تغییر کنند.

---

## نکات مهم

- callback به‌تنهایی context خودش را از دست می‌دهد
- bind context را ثابت می‌کند
- arrow function از نظر lexical this رفتار بهتری دارد
- درک async و context برای debugging حیاتی است

---

## اشتباهات رایج

1. استفاده از متد بدون bind وقتی context لازم است
2. فرض کردن this در callback همان مقدار اولیه است
3. نادیده گرفتن ترتیب اجرای کد در محیط غیرهمزمان

---

## بازار کار

در React، Node.js و Front-End، درک درست context و async flow یکی از مهارت‌های مهم برای رفع خطا و نگهداری کد است. این مفهوم پایه‌ای برای یادگیری promises و async/await در نسخه‌های بعدی است.
