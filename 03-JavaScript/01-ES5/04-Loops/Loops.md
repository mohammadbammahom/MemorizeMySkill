# Loops

---

## این مبحث چیست؟

حلقه‌ها به ما کمک می‌کنند تا روی مجموعه‌ای از داده‌ها به‌صورت خودکار کار کنیم. در برنامه‌های واقعی، بسیاری از کارها تکراری هستند؛ برای مثال نمایش چندین سفارش، بررسی چند کاربر، یا پردازش چند فایل.

---

## چرا از آن استفاده می‌کنیم؟

بدون حلقه‌ها، برای پردازش چندین آیتم باید کد تکراری زیادی بنویسیم. حلقه‌ها باعث می‌شوند کد کوتاه‌تر، خواناتر و قابل نگهداری‌تر شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم روی داده‌های زیادی تکرار کنیم، از حلقه‌ها استفاده می‌کنیم.

مثال 1: حلقه for

```javascript
for (var i = 0; i < items.length; i++) {
  console.log(items[i]);
}
```

مثال 2: حلقه while

```javascript
var attempt = 0;
while (attempt < 3) {
  attempt = attempt + 1;
}
```

مثال 3: حلقه do while

```javascript
do {
  console.log("Try again");
} while (attempt < 3);
```

---

## چه زمانی نباید استفاده کنیم

استفاده از حلقه‌های بی‌رویه در کدهای پیچیده می‌تواند باعث افت عملکرد و کم‌خوانایی شود.

```javascript
for (var i = 0; i < 1000000; i++) {
  console.log(i);
}
```

در چنین شرایطی باید عملکرد و نیاز برنامه را دقیق بررسی کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| for | تکرار بر اساس تعداد مشخص |
| while | تکرار تا زمانی که شرط درست باشد |
| do while | حداقل یک بار اجرا می‌شود |
| for in | پیمایش روی ویژگی‌های آبجکت |

---

## بهترین روش‌های استفاده

- از حلقه مناسب برای هر موقعیت استفاده کن.
- از متغیرهای روشن برای شمارنده‌ها استفاده کن.
- از حلقه‌های بیش از حد پیچیده اجتناب کن.
- در حلقه‌ها فقط منطق ضروری را قرار بده.
