# OperatorsAndExpressions

---

## این مبحث چیست؟

عملگرها و عبارت‌ها ابزارهایی هستند که به JavaScript کمک می‌کنند داده‌ها را محاسبه، مقایسه و تحلیل کند. با استفاده از آن‌ها می‌توانیم تصمیم‌گیری کنیم، قیمت‌ها را حساب کنیم، وضعیت ورود کاربر را بررسی کنیم و منطق کسب‌وکار را در برنامه‌ها پیاده‌سازی کنیم.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، همیشه با داده‌ها کار می‌کنیم. برای مثال، در یک فروشگاه آنلاین باید قیمت نهایی سفارش را حساب کنیم، در یک پلتفرم آموزشی باید بررسی کنیم که کاربر دسترسی دارد یا نه، و در یک داشبورد مدیریتی باید وضعیت‌ها را با هم مقایسه کنیم.

عملگرها از مهم‌ترین بخش‌های منطق برنامه‌نویسی هستند. بدون آن‌ها، هیچ برنامه‌ای نمی‌تواند تصمیم بگیرد یا محاسبه انجام دهد.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- مبلغ نهایی سفارش را حساب کنیم
- شرایط ورود کاربر را بررسی کنیم
- وضعیت عضویت یا تخفیف را ارزیابی کنیم
- تصمیم بگیریم آیا کاربر دسترسی به یک بخش دارد یا نه

مثال 1: عملگرهای حسابی

```javascript
var productPrice = 150;
var quantity = 3;
var totalPrice = productPrice * quantity;
```

مثال 2: عملگرهای مقایسه

```javascript
var enteredPassword = "123456";
var storedPassword = "123456";
var isPasswordCorrect = enteredPassword === storedPassword;
```

مثال 3: عملگرهای منطقی

```javascript
var isLoggedIn = true;
var isAdmin = false;
var canManageUsers = isLoggedIn && isAdmin;
```

مثال 4: عملگرهای تخصیص

```javascript
var subtotal = 800;
var discount = 120;
var finalAmount = subtotal - discount;
```

---

## چه زمانی نباید استفاده کنیم

این مثال اشتباه است، چون مقایسه‌ی ضعیف و غیر واضح انجام شده است:

```javascript
var numberValue = 10;
var stringValue = "10";
var result = numberValue == stringValue;
```

در این حالت، JavaScript مقدار را به صورت ضعیف مقایسه می‌کند و ممکن است نتیجه‌ای ایجاد شود که با منطق برنامه‌نویس همخوانی نداشته باشد. بهتر است از `===` استفاده کنیم.

همچنین اگر از عملگرهای منطقی بدون درک درست استفاده کنیم، نتیجه‌ی برنامه اشتباه می‌شود:

```javascript
var isLoggedIn = true;
var hasPermission = false;
var accessGranted = isLoggedIn || hasPermission;
```

اگر منظور ما دسترسی دقیق‌تر است، باید شرایط را به‌خوبی مشخص کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد | مثال |
|---|---|---|
| عملگر حسابی | انجام محاسبه | `a + b` |
| عملگر مقایسه | بررسی رابطه بین دو مقدار | `a === b` |
| عملگر منطقی | ترکیب چند شرط | `a && b` |
| عملگر تخصیص | ذخیره نتیجه در متغیر | `a = b` |
| عملگر افزایشی | افزایش مقدار | `a++` |
| عملگر کاهشی | کاهش مقدار | `a--` |

---

## بهترین روش‌های استفاده

- از `===` به جای `==` استفاده کن تا مقایسه دقیق‌تر باشد.
- برای شرایط پیچیده، هر شرط را واضح بنویس.
- از نام‌های معنی‌دار برای متغیرهای شرطی استفاده کن.
- از عملگرها برای منطق کسب‌وکار، نه فقط برای محاسبه ساده.
- هنگام استفاده از `&&` و `||`، اولویت را در نظر بگیر.

---

## اشتباهات رایج

1. استفاده از `==` در مقایسه‌های مهم

```javascript
if (age == 18) {
  console.log("Adult");
}
```

2. فراموش کردن پرانتز در عبارات پیچیده

```javascript
var total = price + tax * discount;
```

3. استفاده از عملگرهای منطقی بدون بررسی شرایط

```javascript
var canAccess = isLoggedIn && isAdmin;
```

4. استفاده از `++` یا `--` در جاهایی که خوانایی کاهش می‌یابد

```javascript
var count = count + 1;
```

## نکات بازار کار

در پروژه‌های Front-End و Node.js، این مفاهیم در هر بخش از منطق برنامه دیده می‌شوند. در فرم‌ها، سبد خرید، احراز هویت، پنل مدیریتی و API‌ها، همواره با مقایسه و محاسبه سروکار داریم.

در مصاحبه‌ها، معمولاً از شما انتظار می‌رود که بتوانید:

- تفاوت `==` و `===` را توضیح بدهید
- با عملگرهای منطقی کار کنید
- یک شرط پیچیده را به‌صورت خوانا بنویسید
- در code review، مشکلات مربوط به ترتیب اجرا و خوانایی را تشخیص بدهید
