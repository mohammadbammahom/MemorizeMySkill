# ClosuresAndCallbacks

---

## این مبحث چیست؟

در JavaScript، callbackها توابعی هستند که به عنوان ورودی به تابع دیگری داده می‌شوند. بسته‌ها یا closures نیز به ما این امکان را می‌دهند که داده‌ها و متغیرها را در محیطی حفظ کنیم که بعداً دوباره به آن دسترسی داشته باشیم.

---

## چرا از آن استفاده می‌کنیم؟

این مفاهیم برای ساخت کدهای انعطاف‌پذیر، قابل استفاده مجدد و مدرن بسیار مهم‌اند. در برنامه‌های واقعی از callbackها برای رویدادها، پردازش داده‌ها و عملیات غیرهمزمان استفاده می‌شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- روی هر آیتم یک عملیات خاص انجام دهیم
- یک تابع را به تابع دیگری پاس بدهیم
- داده‌ها را در یک تابع داخلی حفظ کنیم

مثال:

```javascript
function processItems(items, callback) {
  var result = [];
  for (var i = 0; i < items.length; i++) {
    result.push(callback(items[i]));
  }
  return result;
}
```

---

## چه زمانی نباید استفاده کنیم

اگر منطق callback خیلی پیچیده شود، کد خوانایی خود را از دست می‌دهد. در این حالت بهتر است توابع را واضح‌تر و به‌صورت ساختارمندتر بنویسیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| callback | اجرای یک تابع در زمان خاص |
| closure | حفظ متغیرها در محیط تابع |
| تابع عادی | اجرای مستقیم و مستقل |
| event handler | واکنش به رویداد |

---

## بهترین روش‌های استفاده

- callbackها را ساده و واضح بنویس.
- از closure برای حفظ داده‌های مرتبط استفاده کن.
- از توابع کوچک برای جلوگیری از پیچیدگی استفاده کن.

---

## اشتباهات رایج

1. استفاده از callback در جای نامناسب
2. فراموش کردن محیط حفظ‌شده در closure
3. نوشتن توابع خیلی بزرگ و پیچیده

---

## نکات بازار کار

در شرکت‌ها و پروژه‌های واقعی، callbackها و closureها در رویدادهای DOM، APIها، مدل‌های داده و کدنویسی غیرهمزمان بسیار پرکاربردند.
