# StringsAndStringMethods

---

## این مبحث چیست؟

رشته‌ها یکی از مهم‌ترین انواع داده در JavaScript هستند. در برنامه‌های واقعی، ما همیشه با متن کار می‌کنیم؛ برای مثال نام کاربر، ایمیل، پیغام، عنوان محصول یا متن پیام‌های سیستم.

---

## چرا از آن استفاده می‌کنیم؟

متدهای رشته به ما کمک می‌کنند متن را بخوانیم، اصلاح کنیم، بررسی کنیم و به بخش‌های مختلف تبدیل کنیم. این کار برای اعتبارسنجی فرم، نمایش داده‌های کاربر و ساخت پیام‌های پویا ضروری است.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم با متن کار کنیم، از رشته‌ها و متدهای آن استفاده می‌کنیم.

مثال 1: ایجاد رشته

```javascript
var fullName = "Muhammad ibn Abdullah";
```

مثال 2: تشخیص طول رشته

```javascript
console.log(fullName.length);
```

مثال 3: تبدیل به حروف بزرگ یا کوچک

```javascript
console.log(fullName.toUpperCase());
console.log(fullName.toLowerCase());
```

مثال 4: جداسازی متن

```javascript
var words = message.split(" ");
```

---

## چه زمانی نباید استفاده کنیم

اگر متن خیلی پیچیده باشد و نیاز به پردازش پیشرفته‌تر داشته باشد، روش‌های ساده رشته ممکن است کافی نباشند. در چنین مواردی شاید بهتر باشد داده‌ها در قالب ساختار مناسب‌تر ذخیره شوند.

```javascript
var text = "hello world";
```

اگر قرار باشد متن به‌صورت مداوم پردازش شود، بهتر است با اصول قابل‌نگهداری و خوانا کار کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| رشته | نگه‌داری متن |
| آرایه | نگه‌داری چند آیتم |
| عدد | نگه‌داری داده عددی |
| بولین | نگه‌داری درست/غلط |

---

## بهترین روش‌های استفاده

- متن‌ها را با دقت بررسی کن.
- برای کار با ورودی کاربر، حتماً فضای اضافی را کنترل کن.
- از متدهای مناسب برای جایگزینی، جستجو و تقسیم متن استفاده کن.

---

## اشتباهات رایج

1. استفاده از `indexOf` بدون بررسی نتیجه
2. فراموش کردن `trim` برای ورودی کاربر
3. استفاده از رشته به‌جای آرایه در موارد چندتایی

---

## نکات بازار کار

در فرم‌ها، ثبت‌نام، ورود، ارسال پیام و نمایش داده‌های کاربر، رشته‌ها دائماً استفاده می‌شوند. در مصاحبه‌ها نیز معمولاً از شما انتظار می‌رود که با متدهای متداول رشته کار کنید.
