# Functions

---

## این مبحث چیست؟

توابع در JavaScript به ما کمک می‌کنند منطق را به بلوک‌های قابل استفاده و قابل بازاستفاده تقسیم کنیم. این مفهوم برای ساخت برنامه‌های مدرن، کاهش کد تکراری و نگه‌داری بهتر کد بسیار مهم است.

---

## چرا از آن استفاده می‌کنیم؟

در پروژه‌های واقعی، ما بارها و بارها همین کارها را انجام می‌دهیم: ساخت خلاصه سفارش، محاسبه تخفیف، بررسی دسترسی، یا ساخت نمایه کاربر. توابع باعث می‌شوند این منطق فقط یک‌بار نوشته شود و بعد چندین بار استفاده شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- یک کار تکراری را در چند جا اجرا کنیم
- منطق را به بخش‌های واضح تقسیم کنیم
- خروجی‌های قابل استفاده تولید کنیم

مثال 1: تابع برای ساخت خلاصه سفارش

```javascript
function createOrderSummary(customerName, totalAmount, shippingFee) {
  var totalWithShipping = totalAmount + shippingFee;
  return "Order for " + customerName + " totals " + totalWithShipping + " dollars";
}
```

مثال 2: تابع برای محاسبه تخفیف

```javascript
function calculateDiscount(totalAmount, discountRate) {
  return totalAmount * discountRate;
}
```

---

## چه زمانی نباید استفاده کنیم

استفاده از تابع برای کارهای خیلی ساده، گاهی موجب پیچیده‌تر شدن کد می‌شود.

```javascript
function doNothing() {
  console.log("Nothing");
}
```

اگر کار خیلی ساده است و نیاز به بازاستفاده ندارد، بهتر است از تابع استفاده نکنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Function Declaration | تعریف تابع با نام |
| Function Expression | ذخیره تابع در یک متغیر |
| Parameter | ورودی تابع |
| Return Value | خروجی تابع |

---

## بهترین روش‌های استفاده

- توابع را کوتاه و متمرکز نگه دار.
- نام تابع را واضح انتخاب کن.
- از خروجی‌های واضح استفاده کن.
- برای منطق‌های پیچیده، تابع‌های جداگانه ایجاد کن.

---

## اشتباهات رایج

1. نام‌گذاری ضعیف تابع
2. نوشتن تابع‌های خیلی بزرگ
3. فراموش کردن `return`

---

## نکات بازار کار

توابع در همه‌ی پروژه‌های JavaScript استفاده می‌شوند؛ از فرم‌های ساده گرفته تا APIها و ماژول‌های بزرگ. در مصاحبه‌ها، معمولاً از شما انتظار می‌رود که بتوانید تابعی با ورودی و خروجی مشخص بنویسید و آن را برای کارهای واقعی به کار ببرید.
