# FunctionArgumentsAndDefaultValues

---

## این مبحث چیست؟

در JavaScript، توابع می‌توانند آرگومان دریافت کنند. گاهی ممکن است کاربر آرگومان خاصی را ارسال نکند، در این صورت باید برای تابع مقدار پیش‌فرض در نظر بگیریم تا برنامه دچار خطا نشود.

---

## چرا از آن استفاده می‌کنیم؟

استفاده از آرگومان‌ها و مقادیر پیش‌فرض باعث می‌شود توابع انعطاف‌پذیرتر شوند و در موقعیت‌های مختلف بدون نیاز به تغییر کد کار کنند.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- تابعی با ورودی‌های اختیاری بسازیم
- هنگام نبود ورودی، یک رفتار استاندارد داشته باشیم
- کد را خوانا‌تر و قابل استفاده‌تر کنیم

مثال:

```javascript
function createGreeting(userName, greetingType) {
  greetingType = greetingType || "welcome";
  return greetingType + ", " + userName;
}
```

---

## چه زمانی نباید استفاده کنیم

اگر مقدار پیش‌فرض خیلی پیچیده باشد، استفاده از آن می‌تواند خوانایی کد را کاهش دهد. بهتر است برای منطق‌های پیچیده، یک راه‌حل روشن‌تر انتخاب شود.

```javascript
function doSomething(value) {
  value = value || "fallback";
}
```

در این حالت، اگر منطق بیشتری داشته باشیم، بهتر است با رویکرد روشن‌تر و واضح‌تر پیش برویم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| آرگومان | داده‌ای که به تابع داده می‌شود |
| پارامتر | متغیر داخل تابع برای دریافت آرگومان |
| مقدار پیش‌فرض | مقدار جایگزین در صورت نبود ورودی |
| بازگشت | خروجی تابع |

---

## بهترین روش‌های استفاده

- آرگومان‌های ضروری و اختیاری را جدا کن.
- برای ورودی‌های گم‌شده، مقدار پیش‌فرض مشخص کن.
- کد را ساده و قابل فهم نگه دار.

---

## اشتباهات رایج

1. فراموش کردن مقدار پیش‌فرض
2. استفاده از `||` برای مقادیر عددی یا بولی بدون دقت
3. نادیده گرفتن ورودی‌های خالی
