# ConditionalStatements

---

## این مبحث چیست؟

در JavaScript، شرط‌ها به برنامه کمک می‌کنند بر اساس داده‌های مختلف تصمیم بگیرد. این مفاهیم برای تایید ورود کاربر، بررسی وضعیت سفارش، نمایش تخفیف و کنترل دسترسی به بخش‌های مختلف برنامه بسیار مهم هستند.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، همیشه لازم است شرایط مختلف را بررسی کنیم. برای مثال، اگر کاربر وارد سیستم شده باشد، صفحه داشبورد را نشان می‌دهیم؛ اگر سفارش بیش از حد مشخصی باشد، ارسال رایگان اعمال می‌شود؛ اگر پرداخت انجام نشده باشد، سفارش ادامه نمی‌یابد.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم بر اساس داده‌ها تصمیم بگیریم، از شرط‌ها استفاده می‌کنیم.

مثال 1: بررسی وضعیت ورود

```javascript
if (userStatus === "active") {
  console.log("User can access the dashboard.");
}
```

مثال 2: بررسی چند شرط

```javascript
if (accountType === "premium" || accountType === "admin") {
  console.log("Advanced features are available.");
}
```

مثال 3: تصمیم‌گیری برای سفارش

```javascript
if (orderAmount >= 300) {
  console.log("Free shipping is available.");
}
```

---

## چه زمانی نباید استفاده کنیم

اگر شرط‌ها را بدون تفکیک مناسب بنویسیم، کد گیج‌کننده می‌شود.

```javascript
if (userStatus === "active")
  console.log("Access granted");
```

این مثال ساده است، اما در پروژه‌های بزرگ بهتر است با بلوک‌های واضح و ساختارمند کار کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد | مثال |
|---|---|---|
| if | بررسی یک شرط | `if (isMember) {}` |
| else | اجرای حالت مخالف | `else {}` |
| else if | بررسی چند شرط متوالی | `else if (status === "pending") {}` |
| switch | انتخاب از بین چند گزینه | `switch (paymentMethod) {}` |

---

## بهترین روش‌های استفاده

- شرط‌ها را واضح و خوانا بنویس.
- از نام‌های معنی‌دار برای متغیرهای شرطی استفاده کن.
- برای چند شرط پیچیده، از `else if` استفاده کن.
- از `===` برای مقایسه‌های دقیق استفاده کن.

---

## اشتباهات رایج

1. استفاده از `=` به جای `===`
2. فراموش کردن بلوک‌های شرطی
3. ترکیب بیش از حد چند شرط بدون خوانایی

---

## نکات بازار کار

در پروژه‌های Front-End و Node.js، شرط‌ها در احراز هویت، اعتبارسنجی فرم‌ها، کنترل دسترسی، منطق سفارش، و نمایش اطلاعات پویا اهمیت زیادی دارند. در مصاحبه‌ها، معمولاً از شما انتظار می‌رود که بتوانید شرایط ساده و چندمرحله‌ای را درست تحلیل کنید.
