# JSONAndParsing

---

## این مبحث چیست؟

JSON یک فرمت استاندارد برای ذخیره و انتقال داده است. در برنامه‌های واقعی، داده‌ها معمولاً از API‌ها، فایل‌ها یا پایگاه داده‌ها به شکل JSON دریافت و ارسال می‌شوند. آشنایی با JSON و تبدیل آن به آبجکت یا برعکس برای توسعه‌ی Front-End و Node.js ضروری است.

---

## چرا از آن استفاده می‌کنیم؟

JSON به دلیل خوانایی و سادگی، برای تبادل داده بسیار محبوب است. این فرمت در برنامه‌های وب، APIها و پیکربندی‌های نرم‌افزار بسیار رایج است.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم داده را میان برنامه‌ها یا میان سرور و کلاینت منتقل کنیم، از JSON استفاده می‌کنیم.

مثال 1: تبدیل آبجکت به JSON

```javascript
var jsonString = JSON.stringify(userData);
```

مثال 2: تبدیل JSON به آبجکت

```javascript
var parsedData = JSON.parse(jsonString);
```

مثال 3: کار با داده‌های API

```javascript
var productPayload = '{"name":"Book","price":25}';
var product = JSON.parse(productPayload);
```

---

## چه زمانی نباید استفاده کنیم

اگر داده‌ی JSON خراب یا نامعتبر باشد، `JSON.parse` خطا می‌دهد.

```javascript
JSON.parse('{"name": "Ali"');
```

در چنین مواردی باید از `try` و `catch` برای مدیریت خطا استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| JSON | فرمت داده | 
| Object | ساختار داده در JavaScript |
| String | متن خام |
| Array | لیست داده‌ها |

---

## بهترین روش‌های استفاده

- داده‌ها را به صورت استاندارد JSON ارسال و دریافت کن.
- هنگام پردازش JSON، خطاها را مدیریت کن.
- از JSON برای انتقال داده‌های ساختارمند استفاده کن.

---

## اشتباهات رایج

1. استفاده از JSON به‌صورت نادرست
2. فراموش کردن `try/catch` برای پارس خطا
3. استفاده از متن خام به جای JSON
