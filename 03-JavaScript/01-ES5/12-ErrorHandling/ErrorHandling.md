# ErrorHandling

---

## این مبحث چیست؟

مدیریت خطا یکی از مهم‌ترین مهارت‌های برنامه‌نویسی است. در برنامه‌های واقعی، مواردی مثل ورودی اشتباه، داده‌های ناقص، یا خطاهای شبکه ممکن است رخ دهد. با استفاده از `try`, `catch` و `throw` می‌توانیم برنامه را کنترل‌شده‌تر و قابل‌اعتمادتر کنیم.

---

## چرا از آن استفاده می‌کنیم؟

بدون مدیریت خطا، برنامه ممکن است متوقف شود یا رفتار غیرمنتظره‌ای داشته باشد. مدیریت خطا باعث می‌شود کد بهتر عمل کند، مشکلات سریع‌تر پیدا شوند و تجربه‌ی کاربر بهتر شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم از وقوع خطا جلوگیری کنیم یا خطا را کنترل کنیم، از مدیریت خطا استفاده می‌کنیم.

مثال 1: مدیریت خطا در پردازش پرداخت

```javascript
try {
  console.log(processPayment(250, "card"));
} catch (error) {
  console.log(error.message);
}
```

مثال 2: پرتاب خطا برای داده‌های نامعتبر

```javascript
if (amount <= 0) {
  throw new Error("Amount must be greater than zero.");
}
```

---

## چه زمانی نباید استفاده کنیم

اگر از `try` و `catch` برای همه‌ی چیزها استفاده کنیم، کد پیچیده و سخت‌خوان می‌شود.

```javascript
try {
  console.log("Everything");
} catch (error) {
  console.log(error);
}
```

در این حالت، بهتر است خطاها را در جای مناسب کنترل کنیم و از پوشش‌دهی بیش از حد پرهیز کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| try | تلاش برای اجرای کد |
| catch | گرفتن و مدیریت خطا |
| throw | پرتاب خطای سفارشی |
| Error | شیء خطا در JavaScript |

---

## بهترین روش‌های استفاده

- خطاها را با پیام واضح گزارش کن.
- برای داده‌های نامعتبر، خطاهای سفارشی ایجاد کن.
- از `catch` برای نمایش یا ثبت خطا استفاده کن.
- کد را خراب نکن و از fallback مناسب استفاده کن.

---

## اشتباهات رایج

1. نادیده گرفتن خطاها
2. پرتاب خطا بدون پیام واضح
3. استفاده‌ی بیش از حد از `try` در بخش‌های ساده
