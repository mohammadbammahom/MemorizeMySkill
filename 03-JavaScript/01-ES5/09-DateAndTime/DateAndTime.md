# DateAndTime

---

## این مبحث چیست؟

کار با تاریخ و زمان در برنامه‌ها بسیار مهم است. از نمایش تاریخ امروز در یک پنل کاربری گرفته تا مدیریت رویدادها، زمان‌بندی و گزارش‌ها، همه به این مفهوم نیاز دارند.

---

## چرا از آن استفاده می‌کنیم؟

برای ثبت وقایع، نمایش زمان، محاسبه تفاوت زمانی و برنامه‌ریزی کارها، باید با تاریخ و زمان کار کنیم. این مفهوم در برنامه‌های آموزشی، فروشگاهی، بانکی و اداری بسیار کاربردی است.

---

## چه زمانی استفاده می‌کنیم

زمانی که بخواهیم زمان جاری را بخوانیم یا تاریخ مشخصی را بسازیم، از `Date` استفاده می‌کنیم.

مثال 1: گرفتن تاریخ فعلی

```javascript
var currentDate = new Date();
```

مثال 2: گرفتن بخش‌های مختلف تاریخ

```javascript
console.log(currentDate.getFullYear());
console.log(currentDate.getMonth() + 1);
console.log(currentDate.getDate());
```

مثال 3: ساخت تاریخ مشخص

```javascript
var eventDate = new Date(2026, 7, 15, 10, 30, 0);
```

---

## چه زمانی نباید استفاده کنیم

اگر فقط یک رشته ساده برای نمایش تاریخ نیاز داریم، ساختارهای ساده‌تر شاید کافی باشند. اما برای محاسبه و مدیریت واقعی زمان، `Date` بهترین گزینه است.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Date | مدیریت تاریخ و زمان |
| String | نگه‌داری متن |
| Number | نگه‌داری عدد |
| Array | نگه‌داری لیست داده‌ها |

---

## بهترین روش‌های استفاده

- از `Date` برای زمان واقعی برنامه استفاده کن.
- ماه‌ها را با `getMonth() + 1` در نظر بگیر، چون ماه‌ها از صفر شروع می‌شوند.
- برای نمایش تاریخ، format واضح و قابل خواندن انتخاب کن.

---

## اشتباهات رایج

1. فراموش کردن اینکه ماه از صفر شروع می‌شود
2. مقایسه‌ی اشتباه دو تاریخ
3. استفاده از رشته به‌جای شیء تاریخ برای عملیات زمانی

---

در برنامه‌های مدیریتی، فروشگاهی، آموزشی و حسابداری، کار با تاریخ و زمان بسیار شایع است. در مصاحبه‌ها هم معمولاً از شما انتظار می‌رود که بتوانید با تاریخ، مقایسه و نمایش آن کار کنید.
