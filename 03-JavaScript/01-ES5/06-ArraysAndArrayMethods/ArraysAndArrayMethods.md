# ArraysAndArrayMethods

---

## این مبحث چیست؟

آرایه‌ها یکی از مهم‌ترین ساختارهای داده در JavaScript هستند. در برنامه‌های واقعی، ما اغلب با لیست‌هایی از کاربر، سفارش، محصول، دانشجو یا رویداد کار می‌کنیم. آشنایی با آرایه و متدهای آن برای کار با داده‌های مرتبط ضروری است.

---

## چرا از آن استفاده می‌کنیم؟

وقتی چند آیتم مرتبط را در کنار هم نگه داریم، آرایه بهترین انتخاب است. برای مثال، لیست سفارشات، لیست کاربران، لیست درس‌ها یا لیست محصولات را می‌توانیم در یک آرایه نگه داریم و با عملیات مختلف آن‌ها را مدیریت کنیم.

---

## چه زمانی استفاده می‌کنیم

زمانی که بخواهیم یک مجموعه داده را ذخیره، اضافه، حذف یا جستجو کنیم، از آرایه استفاده می‌کنیم.

مثال 1: ساخت آرایه از دانشجویان

```javascript
var students = [
  { name: "Muhammad", score: 92 },
  { name: "Aisha", score: 81 }
];
```

مثال 2: اضافه کردن آیتم جدید

```javascript
students.push({ name: "Ali", score: 88 });
```

مثال 3: حذف آخرین آیتم

```javascript
students.pop();
```

مثال 4: پیمایش آرایه

```javascript
for (var i = 0; i < students.length; i++) {
  console.log(students[i].name);
}
```

---

## چه زمانی نباید استفاده کنیم

اگر داده‌ها ساختار پیچیده‌تری داشته باشند و نیاز به جستجو و دسترسی دقیق‌تر داشته باشیم، استفاده از آرایه به‌تنهایی همیشه بهترین راه نیست.

```javascript
var users = ["Muhammad", "Aisha", "Ali"];
```

در چنین موقعیتی، اگر بخواهیم اطلاعات بیشتر از هر کاربر ذخیره کنیم، آبجکت یا ساختار داده مناسب‌تر خواهد بود.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| آرایه | نگه‌داری لیست داده‌ها |
| آبجکت | نگه‌داری داده‌های مرتبط با کلید |
| آرایه‌ی تو در تو | لیست‌های پیچیده‌تر |
| متدهای آرایه | مدیریت و پردازش داده‌ها |

---

## بهترین روش‌های استفاده

- آرایه را برای داده‌های مشابه استفاده کن.
- نام آرایه را واضح انتخاب کن.
- هنگام اضافه یا حذف آیتم، وضعیت طول آرایه را کنترل کن.
- برای کارهای پیچیده‌تر، از حلقه‌ها یا متدهای مناسب استفاده کن.

---

## اشتباهات رایج

1. دسترسی به اندیس اشتباه
2. حذف یا اضافه کردن بدون بررسی طول آرایه
3. استفاده از آرایه برای داده‌های ساختارمند پیچیده

## نکات بازار کار

در Front-End، Node.js و برنامه‌های واقعی، آرایه‌ها در مدیریت لیست سفارشات، خدمات، محصولات، کاربران و ارسال داده به API‌ها زیاد استفاده می‌شوند. در مصاحبه‌ها نیز انتظار می‌رود با پیمایش و تغییر آرایه‌ها آشنا باشید.
