# ScopesAndClosures

---

## این مبحث چیست؟

اسکوپ یا محدوده‌ی متغیرها مشخص می‌کند که یک متغیر در کجای برنامه قابل دسترس است. closures یعنی تابعی که به متغیرهای محیط بیرونی خود دسترسی دارد، حتی بعد از اینکه آن محیط اجرا شده و پایان یافته است. این مفاهیم برای ساخت کد تمیز، امن و قابل استفاده در برنامه‌های واقعی بسیار مهم‌اند.

---

## چرا از آن استفاده می‌کنیم؟

در پروژه‌های واقعی، ما نیاز داریم بعضی داده‌ها فقط در یک بخش خاص در دسترس باشند و از دسترسی‌های غیرضروری جلوگیری کنیم. با اسکوپ مناسب و closure می‌توانیم داده‌های داخلی را پنهان کنیم و منطق را بهتر سازمان‌دهی کنیم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- متغیرهای داخلی را از بیرون مخفی کنیم
- توابعی بسازیم که به داده‌های محیط خود دسترسی داشته باشند
- کد را به‌صورت ماژولارتر و قابل نگهداری‌تر سازمان‌دهی کنیم

مثال 1: ساخت closure

```javascript
function createOrderProcessor() {
  var taxRate = 0.08;

  function calculateTotal(amount) {
    return amount + (amount * taxRate);
  }

  return calculateTotal;
}
```

مثال 2: استفاده از متغیرهای محلی

```javascript
function buildProfile() {
  var profileName = "Muhammad";
  console.log(profileName);
}
```

---

## چه زمانی نباید استفاده کنیم

اگر از closureها به‌صورت بی‌دلیل استفاده کنیم، کد ممکن است سخت‌تر خوانده شود و مدیریت آن دشوارتر شود.

```javascript
function createBadExample() {
  var secretValue = 10;
  return function () {
    return secretValue;
  };
}
```

این مثال کار می‌کند، اما اگر برای کارهای ساده استفاده شود، ممکن است خوانایی را کاهش دهد.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Global Scope | دسترسی در کل برنامه |
| Function Scope | دسترسی فقط داخل تابع |
| Closure | دسترسی به محیط بیرونی حتی بعد از پایان تابع |
| Module Pattern | سازمان‌دهی منطق و پنهان‌سازی داده |

---

## بهترین روش‌های استفاده

- متغیرها را در نزدیک‌ترین محدوده‌ی ممکن تعریف کن.
- برای داده‌های حساس، از closure یا بسته‌بودن داده استفاده کن.
- کد را ساده و قابل فهم نگه دار.
- از استفاده‌ی بیش از حد از توابع داخلی پرهیز کن.
