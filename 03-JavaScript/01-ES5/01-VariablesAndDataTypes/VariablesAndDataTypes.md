# VariablesAndDataTypes

---

## این مبحث چیست؟

متغیرها و انواع داده، پایه‌ی هر برنامه JavaScript هستند. بدون فهم درست این مفاهیم، خواندن کدهای واقعی و نوشتن برنامه‌های قابل‌اعتماد سخت می‌شود. در این درس یاد می‌گیریم که داده را در کجا ذخیره کنیم، چه نوع داده‌ای داریم و چگونه از آن‌ها در برنامه‌های واقعی استفاده کنیم.

---

## چرا از آن استفاده می‌کنیم؟

در هر برنامه‌ای، داده‌ها مهم‌ترین بخش هستند. برای مثال، نام کاربر، سن، مقدار سفارش، وضعیت پرداخت و تنظیمات برنامه همه داده‌اند. با استفاده از متغیرها می‌توانیم این داده‌ها را ذخیره، جابه‌جا کنیم و در منطق برنامه استفاده کنیم.

بدون متغیر و نوع داده درست، برنامه‌ها پر از خطا و گیج‌کننده می‌شوند. این مفاهیم در Front-End، React، Node.js و حتی در مصاحبه‌های شغلی خیلی مهم هستند.

---

## چه زمانی استفاده می‌کنیم

زمانی که بخواهیم اطلاعاتی مثل نام کاربر، قیمت، وضعیت ورود یا تنظیمات برنامه را نگه داریم، از متغیرها استفاده می‌کنیم.

مثال 1: ذخیره اطلاعات کاربر

```javascript
var userName = "Ali";
var age = 28;
var isActive = true;
```

مثال 2: ذخیره یک مجموعه داده مرتبط

```javascript
var userProfile = {
  name: "Ali",
  age: 28,
  isActive: true
};
```

مثال 3: ذخیره چند مقدار در یکجا

```javascript
var favoriteLanguages = ["JavaScript", "Python", "C#"];
```

مثال 4: استفاده از داده‌ها در منطق برنامه

```javascript
var price = 120;
var quantity = 3;
var totalPrice = price * quantity;

console.log(totalPrice);
```

---

## چه زمانی نباید استفاده کنیم

این یک مثال اشتباه است، چون از متغیرهای نامناسب و بی‌معنا استفاده شده است:

```javascript
var a = "Ali";
var b = 20;
var c = true;
```

این کد کار می‌کند، اما در پروژه‌های واقعی خوانایی و نگه‌داری آن پایین است. بهتر است از نام‌هایی مثل `userName`، `age` و `isActive` استفاده کنیم.

همچنین اگر نوع داده را درست انتخاب نکنیم، نتیجه برنامه اشتباه می‌شود:

```javascript
var total = "100" + 50;
console.log(total); // "10050"
```

در این حالت، رشته و عدد با هم ادغام می‌شوند و ممکن است نتیجه‌ای متفاوت از چیزی باشد که انتظار داریم.

---

## تفاوت با موارد مشابه

| مفهوم | کاربرد | مثال |
|---|---|---|
| متغیر | نگه‌داری داده | `var userName = "Ali";` |
| رشته | متن | `var message = "Hello";` |
| عدد | داده عددی | `var price = 150;` |
| بولین | درست/غلط | `var isLoggedIn = true;` |
| آرایه | لیست داده‌ها | `var items = [1, 2, 3];` |
| آبجکت | داده‌های مرتبط | `var user = { name: "Ali" };` |
| `null` | داده خالی و واضح | `var selectedUser = null;` |
| `undefined` | مقدار هنوز تعریف نشده | `var value;` |

---

## بهترین روش‌های استفاده

- از نام‌های معنی‌دار استفاده کن.
- برای داده‌های ثابت، از `var` با نام واضح استفاده کن.
- نوع داده را قبل از استفاده بررسی کن.
- برای داده‌های مرتبط، از آبجکت استفاده کن.
- برای لیست‌ها، آرایه مناسب‌تر است.
- در کدهای واقعی، همیشه سعی کن خوانایی و نگه‌داری را در اولویت قرار بدهی.

---

## اشتباهات رایج

1. استفاده از نام‌های خیلی کوتاه و مبهم

```javascript
var x = "Ali";
```

2. اشتباه در نوع داده

```javascript
var total = "10" * 2;
```

3. نادیده گرفتن `undefined`

```javascript
var user;
console.log(user.name);
```

4. استفاده از `null` بدون هدف مشخص

```javascript
var profile = null;
```

## نکات بازار کار

در پروژه‌های واقعی، این مفاهیم در همه جا دیده می‌شوند. در کار با فرم‌ها، API‌ها، پایگاه داده، مدیریت سفارش و UI، همیشه با داده‌ها سروکار داریم.

در مصاحبه‌ها، انتظار می‌رود بتوانی:

- یک متغیر با نام مناسب تعریف کنی
- نوع داده‌ی یک مقدار را تشخیص بدهی
- با آرایه و آبجکت کار کنی
- تفاوت `null` و `undefined` را توضیح بدهی
- دلایل استفاده از متغیرهای معنی‌دار را بیان کنی

در code review هم معمولاً این نکات مطرح می‌شود:

- نام متغیرها باید واضح باشد
- کد باید خوانا باشد
- داده‌ها نباید بدون بررسی استفاده شوند
