# ModulesAndNamespaces

---

## این مبحث چیست؟

ماژول‌ها و namespaceها به ما کمک می‌کنند کد را به بخش‌های منظم و قابل مدیریت تقسیم کنیم. در برنامه‌های بزرگ، داشتن یک ساختار منظم برای توابع و داده‌ها بسیار مهم است، چون جلوگیری می‌کند بخش‌های مختلف برنامه با هم تداخل کنند.

---

## چرا از آن استفاده می‌کنیم؟

وقتی برنامه رشد می‌کند، کدهای زیاد و مرتبط باید در دسته‌های منطقی نگه داشته شوند. namespaceها به ما کمک می‌کنند این منطق را در یک فضای مشخص قرار دهیم و از تداخل نام‌ها جلوگیری کنیم.

---

## چه زمانی استفاده می‌کنیم

وقتی برنامه چند بخش دارد یا می‌خواهیم منطق‌های مرتبط را جدا کنیم، از ماژول یا namespace استفاده می‌کنیم.

مثال 1: ساخت namespace

```javascript
var OrderApp = OrderApp || {};
```

مثال 2: افزودن تابع به namespace

```javascript
OrderApp.calculateTax = function (amount, taxRate) {
  return amount * taxRate;
};
```

---

## چه زمانی نباید استفاده کنیم

اگر برنامه خیلی کوچک است، استفاده از namespace ممکن است زیاد مفید نباشد و فقط کد را پیچیده‌تر کند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| Namespace | گروه‌بندی منطق مرتبط |
| Function | اجرای یک کار مشخص |
| Object | نگه‌داری داده و رفتار |
| Module | جدا کردن منطق به بخش‌های مستقل |

---

## بهترین روش‌های استفاده

- منطق‌های مرتبط را در یک namespace نگه دار.
- از نام‌های واضح و منحصربه‌فرد استفاده کن.
- برای پروژه‌های بزرگ، ساختار منظم‌تر داشته باش.
