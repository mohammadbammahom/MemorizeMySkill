# PrototypeBasics

---

## این مبحث چیست؟

در JavaScript، prototype یک مکان مشترک برای به اشتراک گذاشتن رفتار میان اشیاء است. این مفهوم در ES5 بسیار مهم است و به ما کمک می‌کند کد را بدون تکرار و به‌صورت ساختارمندتر بنویسیم.

---

## چرا از آن استفاده می‌کنیم؟

با استفاده از prototype می‌توانیم متدها را یک بار تعریف کنیم و برای همه‌ی نمونه‌های یک شیء به اشتراک بگذاریم. این کار باعث صرفه‌جویی در حافظه و بهبود سازمان‌دهی کد می‌شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- چند شیء مشابه داشته باشیم
- یک متد را برای همه‌ی نمونه‌ها مشترک کنیم
- رفتار یک شیء را بدون کپی‌کردن تکراری定义 کنیم

مثال:

```javascript
function Student(name, grade) {
  this.name = name;
  this.grade = grade;
}

Student.prototype.getSummary = function () {
  return this.name + " has grade " + this.grade;
};
```

---

## چه زمانی نباید استفاده کنیم

اگر از prototype برای کارهای خیلی ساده استفاده کنیم، ممکن است کد را پیچیده‌تر کنیم. در این حالت بهتر است از شیءهای ساده‌تر یا متدهای مستقیم استفاده کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| constructor | ساختن شیء |
| prototype | اشتراک رفتار میان نمونه‌ها |
| instance | نمونه‌ی ساخته‌شده از constructor |
| method | رفتار یا کار انجام‌شده توسط شیء |

---

## بهترین روش‌های استفاده

- متدهای مشترک را در prototype قرار بده.
- برای داده‌های اختصاصی، ویژگی‌ها را در constructor تعریف کن.
- کد را ساده و قابل فهم نگه دار.

---

## اشتباهات رایج

1. قرار دادن متد در داخل constructor
2. اشتباه در درک this
3. استفاده‌ی نادرست از نمونه‌های مختلف

در کدنویسی حرفه‌ای و ساخت کلاس‌های مبتنی بر ES5، درک prototype برای فهم Object-Oriented Programming بسیار مهم است.
