# MathAndNumberOperations

---

## این مبحث چیست؟

عملیات ریاضی و عددی در JavaScript برای محاسبه، تحلیل داده، مدیریت مالی و ساخت منطق برنامه‌ای بسیار مهم‌اند. از جمع و تفریق ساده تا تولید عدد تصادفی و گرد کردن مقدار، همه در این مبحث قرار می‌گیرند.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، ما مدام با اعداد کار می‌کنیم. برای مثال، محاسبه قیمت نهایی، تخفیف، مالیات، امتیاز، درصد و خروجی‌های آماری همه به عملیات عددی نیاز دارند.

---

## چه زمانی استفاده می‌کنیم

زمانی که بخواهیم عددی را پردازش کنیم، از عملیات عددی و Math استفاده می‌کنیم.

مثال 1: عملیات پایه

```javascript
console.log(15 + 7);
console.log(20 - 8);
```

مثال 2: متدهای Math

```javascript
console.log(Math.round(4.7));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
```

مثال 3: عدد تصادفی

```javascript
var randomNumber = Math.random();
```

---

## چه زمانی نباید استفاده کنیم

اگر داده‌ها نوع رشته باشند، عملیات ریاضی مستقیم ممکن است نتیجه‌ی غیرمنتظره بدهد.

```javascript
var value = "10";
console.log(value + 5);
```

در چنین شرایطی باید قبل از محاسبه، داده‌ها به عدد تبدیل شوند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| عدد | نگه‌داری داده عددی |
| Math | عملیات ریاضی پیشرفته |
| String | نگه‌داری متن |
| Boolean | نگه‌داری درست/غلط |

---

## بهترین روش‌های استفاده

- برای اعداد مالی، از دقت مناسب استفاده کن.
- برای بازه‌های عددی، از `Math.random()` همراه با تبدیل مناسب استفاده کن.
- برای نمایش داده، از `toFixed` استفاده کن.
