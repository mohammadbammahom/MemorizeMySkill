# ArrayIterationAndMapping

---

## این مبحث چیست؟

پیمایش و نگاشت آرایه‌ها یکی از مهارت‌های مهم در JavaScript است. وقتی با داده‌های زیادی کار می‌کنیم، نیاز داریم روی هر آیتم یک کار انجام دهیم، آن‌ها را بررسی کنیم یا به شکل جدیدی تبدیل کنیم. این کار در برنامه‌های واقعی برای کار با لیست کاربران، سفارش‌ها، محصولات و دانشجوها بسیار رایج است.

---

## چرا از آن استفاده می‌کنیم؟

این تکنیک‌ها به ما کمک می‌کنند داده‌ها را خواناتر، قابل تحلیل‌تر و آماده‌تر برای استفاده در UI، API یا منطق برنامه تبدیل کنیم. بدون پیمایش، مدیریت داده‌های تکراری و بزرگ خیلی سخت می‌شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- روی همه‌ی آیتم‌های آرایه پیمایش کنیم
- یک آرایه‌ی جدید بر اساس داده‌های موجود بسازیم
- آیتم‌های خاص را جدا کنیم
- اطلاعات را به یک فرم ساده‌تر یا قابل استفاده‌تر تبدیل کنیم

مثال 1: پیمایش آرایه

```javascript
for (var i = 0; i < students.length; i++) {
  console.log(students[i].name);
}
```

مثال 2: ساخت آرایه‌ی جدید

```javascript
var names = [];
for (var j = 0; j < students.length; j++) {
  names.push(students[j].name);
}
```

---

## چه زمانی نباید استفاده کنیم

اگر منطق خیلی پیچیده شود، استفاده‌ی بی‌رویه از حلقه‌های زیاد و ساخت آرایه‌های مکرر می‌تواند خوانایی کد را کم کند.

```javascript
for (var i = 0; i < items.length; i++) {
  for (var j = 0; j < items.length; j++) {
    console.log(items[i], items[j]);
  }
}
```

در چنین مواردی بهتر است ساختار کد را ساده‌تر و منظم‌تر کنیم.
