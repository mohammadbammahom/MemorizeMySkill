# ArraySortingAndReducing

---

## این مبحث چیست؟

مرتب‌سازی و کاهش داده‌ها از مهم‌ترین عملیات روی آرایه‌ها در JavaScript است. این مفاهیم به ما کمک می‌کنند داده‌ها را برای نمایش بهتر، تحلیل سریع‌تر و تصمیم‌گیری درست‌تر آماده کنیم.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، ما اغلب باید سفارش‌ها، محصولات یا کاربران را بر اساس امتیاز، قیمت یا زمان مرتب کنیم. همچنین گاهی به یک نتیجه‌ی کلی مانند مجموع درآمد یا بیشترین مقدار نیاز داریم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- آرایه را بر اساس یک معیار مرتب کنیم
- مجموع یا نتیجه‌ی نهایی را حساب کنیم
- بیشترین یا کمترین آیتم را پیدا کنیم

مثال 1: مرتب‌سازی بر اساس قیمت

```javascript
sortedOrders.sort(function (a, b) {
  return a.total - b.total;
});
```

مثال 2: جمع‌آوری نتیجه‌ی نهایی

```javascript
var totalRevenue = 0;
for (var i = 0; i < orders.length; i++) {
  totalRevenue = totalRevenue + orders[i].total;
}
```

---

## چه زمانی نباید استفاده کنیم

اگر منطق زیادی برای مرتب‌سازی یا کاهش وجود دارد، بهتر است آن را به توابع واضح‌تر و قابل نگهداری‌تر تقسیم کنیم.

```javascript
var result = 0;
for (var i = 0; i < data.length; i++) {
  result = result + data[i].value;
}
```

در چنین مواردی اگر کد دوباره و پیچیده شود، خوانایی کاهش می‌یابد.

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| مرتب‌سازی | ترتیب دادن داده‌ها |
| کاهش | جمع‌آوری یک نتیجه‌ی نهایی |
| فیلتر | جدا کردن آیتم‌های خاص |
| پیمایش | بازدید از همه‌ی آیتم‌ها |

- داده‌ها را برای تحلیل، به‌صورت منظم و قابل خواندن تنظیم کن.
- برای نتیجه‌ی کلی، متغیرهای معنی‌دار استفاده کن.
