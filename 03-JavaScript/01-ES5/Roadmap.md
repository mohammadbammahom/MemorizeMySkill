# ES5 Roadmap

## What changed in ES5?

ES5 introduced a more reliable foundation for JavaScript. It standardized important patterns, improved object behavior, and made browser code more consistent.

## Why it matters

- It created a stable baseline for modern JavaScript.
- It improved array handling and object support.
- It helped developers write more maintainable code.

## Key topics

- Strict mode
- Array methods
- Object methods
- JSON support
- Function binding

## Difficulty

Beginner to intermediate.

## Recommended order

1. Strict mode
2. Array iteration methods
3. Object helpers
4. JSON
5. Function binding

## Interview topics

- What is strict mode?
- Why use `Object.create`?
- How do `forEach`, `map`, and `filter` differ?
