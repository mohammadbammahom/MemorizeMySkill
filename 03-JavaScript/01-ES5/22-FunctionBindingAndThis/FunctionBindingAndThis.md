# FunctionBindingAndThis

---

## این مبحث چیست؟

در JavaScript، مقدار this بسته به نحوه‌ی فراخوانی تابع تغییر می‌کند. این موضوع در ES5 یکی از پرچالش‌ترین بخش‌هاست. با استفاده از bind می‌توانیم این مقدار را ثابت کنیم و رفتار تابع را قابل پیش‌بینی‌تر کنیم.

---

## چرا از آن استفاده می‌کنیم؟

زمانی که یک تابع به عنوان callback یا به شیء دیگری منتقل می‌شود، this ممکن است گم شود. bind این مشکل را حل می‌کند و باعث می‌شود تابع در همان زمینه‌ی دلخواه اجرا شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- this را در callbackها ثابت نگه داریم
- یک تابع را به شیء دیگری منتقل کنیم
- رفتار تابع را در موقعیت‌های مختلف کنترل کنیم

مثال:

```javascript
var boundGreet = user.greet.bind(user);
```

---

## چه زمانی نباید استفاده کنیم

اگر از bind بدون درک درست از this استفاده کنیم، کد ممکن است گیج‌کننده شود. همیشه بهتر است منظور خود از this را روشن کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| this | اشاره به Context فعلی |
| bind | ثابت کردن this |
| call | اجرای تابع با this مشخص |
| apply | اجرای تابع با آرگومان‌های آرایه‌ای |

---

## بهترین روش‌های استفاده

- در callbackها از bind استفاده کن.
- برای خوانایی بهتر، context را واضح مشخص کن.
- از call و apply فقط در موارد مناسب استفاده کن.

---

## اشتباهات رایج

1. گم‌شدن this در callback
2. استفاده‌ی اشتباه از bind
3. درک نادرست از context اجرا
