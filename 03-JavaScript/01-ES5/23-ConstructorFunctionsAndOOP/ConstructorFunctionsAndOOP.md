# ConstructorFunctionsAndOOP

---

## این مبحث چیست؟

در ES5، توابع سازنده یکی از روش‌های اصلی ساخت اشیاء و پیاده‌سازی اصول OOP هستند. با این روش می‌توانیم ساختار مشخصی برای چند شیء مشابه ایجاد کنیم و رفتار مشترک را در یک جا نگه داریم.

---

## چرا از آن استفاده می‌کنیم؟

این روش به ما کمک می‌کند اشیاء را بدون تکرار ساختار کدنویسی کنیم و از الگوی شیء‌گرایانه برای مدل‌سازی داده‌ها استفاده کنیم.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- چند شیء با ویژگی‌های مشابه داشته باشیم
- رفتار مشترک میان نمونه‌ها را تعریف کنیم
- ساختار منظم‌تری برای برنامه داشته باشیم

مثال:

```javascript
function Account(owner, balance) {
  this.owner = owner;
  this.balance = balance;
}
```

---

## چه زمانی نباید استفاده کنیم

اگر برنامه خیلی ساده است، استفاده از constructorها ممکن است بیش از نیاز باشد و کدنویسی را پیچیده کند.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| constructor | ساختن شیء |
| instance | نمونه‌ی ساخته‌شده |
| prototype | اشتراک متدها |
| OOP | مدل‌سازی شیء‌گرا |

---

## بهترین روش‌های استفاده

- ویژگی‌های خاص هر شیء را در constructor قرار بده.
- متدهای مشترک را در prototype اضافه کن.
- از نام‌های واضح برای ویژگی‌ها و متدها استفاده کن.

---

## اشتباهات رایج

1. قرار دادن متدها داخل constructor
2. نادیده گرفتن prototype
3. استفاده از this بدون درک صحیح

---

در پروژه‌های واقعی، درک constructorها و OOP در ES5 برای فهم کدهای قدیمی، کتابخانه‌ها و الگوهای ساختارمند بسیار مهم است.
