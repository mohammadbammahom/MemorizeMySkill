# FunctionScopeAndHoisting

---

## این مبحث چیست؟

محدوده تابع و هاستینگ در JavaScript مفاهیمی پایه‌ای هستند که رفتار متغیرها و توابع را در زمان اجرا توضیح می‌دهند. فهم این مفاهیم برای نوشتن کد درست و بدون خطا ضروری است.

---

## چرا از آن استفاده می‌کنیم؟

این مفاهیم کمک می‌کنند بفهمیم متغیرها در کدام قسمت از کد قابل دسترس‌اند و چرا برخی توابع یا متغیرها قبل از تعریف نیز قابل استفاده‌اند.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- رفتار متغیرها را درون تابع‌ها بفهمیم
- توابع داخلی و محلی را بسازیم
- از قانون هاستینگ آگاه باشیم

مثال:

```javascript
function greet(name) {
  return "Hello, " + name;
}
```

و همچنین:

```javascript
console.log(message);
var message = "Learning JavaScript";
```

---

## چه زمانی نباید استفاده کنیم

اگر از هاستینگ به‌صورت نادرست استفاده کنیم، کد ممکن است گیج‌کننده و پر از خطا شود. بهتر است متغیرها را قبل از استفاده تعریف کنیم.

```javascript
console.log(name);
var name = "Ali";
```

در این حالت، درک رفتار کد کمی دشوار می‌شود.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| محدوده محلی | دسترسی فقط در داخل تابع |
| محدوده سراسری | دسترسی در کل برنامه |
| هاستینگ | حرکت تعاریف به بالای حوزه |
| بسته | نگه داشتن دسترسی به متغیرها در توابع داخلی |

---

## بهترین روش‌های استفاده

- متغیرها را نزدیک به محل استفاده تعریف کن.
- برای جلوگیری از گیجی، از `var` با دقت استفاده کن.
- برای ساخت کد قابل پیش‌بینی، رفتار تابع‌ها را روشن نگه دار.

---

## اشتباهات رایج

1. پیش‌فرض گرفتن از هاستینگ بدون درک آن
2. استفاده از متغیرهای سراسری بدون نیاز
3. نادیده گرفتن محدوده‌ی تابع

---

## نکات بازار کار

در کدنویسی حرفه‌ای، درک محدوده و هاستینگ برای جلوگیری از باگ‌های سخت‌رفع و نوشتن کد قابل نگهداری ضروری است.
