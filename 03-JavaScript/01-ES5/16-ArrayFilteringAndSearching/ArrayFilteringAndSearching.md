# ArrayFilteringAndSearching

---

## این مبحث چیست؟

فیلتر کردن و جست‌وجوی آرایه‌ها یکی از کاربردی‌ترین مهارت‌ها در JavaScript است. در برنامه‌های واقعی، ما اغلب باید از میان داده‌های زیادی، آیتم‌های مرتبط را پیدا کنیم؛ برای مثال محصولات موجود، سفارش‌های پرداخت‌شده یا کاربران با شرایط خاص.

---

## چرا از آن استفاده می‌کنیم؟

این تکنیک‌ها به ما کمک می‌کنند داده‌های بی‌استفاده را کنار بگذاریم و فقط موارد مربوط را در اختیار برنامه قرار دهیم. این کار برای UI، جست‌وجو، داشبوردها و منطق کسب‌وکار بسیار مهم است.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم:

- آیتم‌های خاصی را از آرایه جدا کنیم
- بر اساس معیار مشخصی، داده‌ها را پیدا کنیم
- یک مورد خاص را با نام، شناسه یا ویژگی پیدا کنیم

مثال 1: پیدا کردن محصولات موجود

```javascript
for (var i = 0; i < products.length; i++) {
  if (products[i].inStock) {
    availableProducts.push(products[i].name);
  }
}
```

مثال 2: جست‌وجوی یک محصول خاص

```javascript
for (var k = 0; k < products.length; k++) {
  if (products[k].name === searchName) {
    matchedProduct = products[k];
    break;
  }
}
```

---

## چه زمانی نباید استفاده کنیم

اگر شرط‌ها خیلی پیچیده شوند، کد سخت‌تر می‌شود و احتمال خطا بیشتر می‌شود.

```javascript
if (product.category === "Education" && product.price < 20 && product.inStock) {
  console.log(product.name);
}
```

در این حالت بهتر است منطق را به‌صورت واضح‌تر و قابل خواناتر بازنویسی کنیم.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| فیلتر | جدا کردن آیتم‌های مناسب |
| جست‌وجو | پیدا کردن یک آیتم خاص |
| پیمایش | دیدن همه‌ی آیتم‌ها |
| نگاشت | ساخت آرایه‌ی جدید از داده‌ها |

---

## بهترین روش‌های استفاده

- شرط‌ها را ساده و واضح بنویس.
- برای مقایسه‌های دقیق از `===` استفاده کن.
- نام متغیرهای نتیجه را واضح انتخاب کن.
- در داده‌های بزرگ، شرط‌های مناسب را به‌صورت قابل خوانا پیاده کن.

---

## اشتباهات رایج

1. استفاده از مقایسه‌ی ضعیف
2. فراموش کردن `break` در جست‌وجو
3. نادیده گرفتن حالت‌های خالی

## نکات بازار کار

در برنامه‌های واقعی، این مهارت برای جست‌وجو در فروشگاه‌ها، پنل‌های مدیریتی، فیلتر کردن داده‌ها و نمایش اطلاعات مرتبط بسیار مهم است. در مصاحبه‌ها نیز معمولاً از شما انتظار می‌رود که بتوانید با شرط‌های ساده، داده‌ها را پیدا کنید.
