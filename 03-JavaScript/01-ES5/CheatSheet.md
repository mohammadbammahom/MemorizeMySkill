# ES5 Cheat Sheet

## Syntax

```js
'use strict';

var value = 10;
```

## Common features

- `Array.prototype.forEach`
- `Array.prototype.map`
- `Array.prototype.filter`
- `Object.keys`
- `JSON.parse`
- `JSON.stringify`
- `Function.prototype.bind`

## Quick reference

| Feature | Example |
| --- | --- |
| Strict mode | `'use strict';` |
| Array iteration | `items.forEach(...)` |
| Object keys | `Object.keys(obj)` |
| JSON parsing | `JSON.parse(text)` |
| Function binding | `fn.bind(this)` |
