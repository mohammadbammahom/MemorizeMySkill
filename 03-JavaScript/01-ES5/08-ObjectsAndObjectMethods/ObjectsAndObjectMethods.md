# ObjectsAndObjectMethods

---

## این مبحث چیست؟

آبجکت‌ها یکی از مهم‌ترین ساختارهای داده در JavaScript هستند. با آبجکت‌ها می‌توانیم داده‌های مرتبط را در یک واحد منظم نگه داریم؛ برای مثال اطلاعات یک کاربر، محصول، سفارش یا حساب.

---

## چرا از آن استفاده می‌کنیم؟

در برنامه‌های واقعی، داده‌ها اغلب به صورت ساختارمند و مرتبط هستند. به جای ذخیره کردن هر فیلد به‌صورت جداگانه، بهتر است آن‌ها را در یک آبجکت نگه داریم تا کد خواناتر و قابل نگهداری‌تر شود.

---

## چه زمانی استفاده می‌کنیم

وقتی بخواهیم داده‌های مرتبط را در یکجا نگه داریم، از آبجکت استفاده می‌کنیم.

مثال 1: ساخت آبجکت کاربر

```javascript
var userProfile = {
  firstName: "Muhammad",
  age: 30,
  city: "Riyadh"
};
```

مثال 2: افزودن ویژگی جدید

```javascript
userProfile.email = "muhammad@example.com";
```

مثال 3: پیمایش روی ویژگی‌ها

```javascript
for (var key in userProfile) {
  console.log(key, userProfile[key]);
}
```

---

## چه زمانی نباید استفاده کنیم

اگر داده‌ها خیلی ساده و بدون ساختار مرتبط باشند، استفاده از آبجکت ممکن است بی‌نیاز باشد.

```javascript
var firstName = "Muhammad";
var age = 30;
var city = "Riyadh";
```

در این حالت، اگر فقط چند مقدار ساده داریم، استفاده از متغیرها ساده‌تر است.

---

## تفاوت با مفاهیم مشابه

| مفهوم | کاربرد |
|---|---|
| آبجکت | داده‌های مرتبط با کلید |
| آرایه | لیست داده‌ها |
| متغیر | نگه‌داری یک مقدار ساده |
| تابع | اجرای منطق |

---

## بهترین روش‌های استفاده

- برای داده‌های مرتبط از آبجکت استفاده کن.
- نام ویژگی‌ها را واضح انتخاب کن.
- از آبجکت برای مدل‌سازی داده‌های واقعی استفاده کن.
- در صورت نیاز، آبجکت را با آرایه ترکیب کن.

---

## نکات بازار کار

آبجکت‌ها در همه‌ی پروژه‌های JavaScript؛ از فرم‌ها و پنل‌های کاربری تا APIها و ماژول‌های هسته‌ای برنامه، بسیار پرکاربرد هستند. در مصاحبه‌ها هم معمولاً از شما خواسته می‌شود که با ساخت آبجکت و دسترسی به ویژگی‌های آن کار کنید.
