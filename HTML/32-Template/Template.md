# Template

## این مبحث چیست؟

عنصر `<template>` برای نگه‌داری ساختار HTML است که بعداً با JavaScript در صفحه استفاده می‌شود. این عنصر کمک می‌کند قالب‌های قابل استفاده مجدد بدون رندر اولیه ایجاد شوند.

## چرا از آن استفاده می‌کنیم؟

- ساخت الگوهای قابل استفاده مجدد
- کاهش تکرار کد
- کمک به JavaScript برای ساخت عناصر پویا

## چه زمانی استفاده می‌کنیم؟

- ساخت کارت‌های پویا
- رندر کردن چند آیتم از داده‌ها
- ایجاد الگوی UI بدون نمایش اولیه

## چه زمانی نباید استفاده کنیم؟

- برای محتوای ساده و ثابت
- وقتی نیازی به ساخت پویا نیست
- وقتی HTML را مستقیم در صفحه می‌نویسیم

## تفاوت با عناصر مشابه

- `<template>` برای ساختارهای پنهان و قابل‌استفاده است
- `<script type="text/template">` روش قدیمی‌تر است
- `<div>` برای ساختار مستقیم و همیشه دیده‌شده است

## بهترین روش‌های استفاده

- از template برای ساختارهای تکرارشونده استفاده کنید
- با JavaScript آن را clone کنید
- ساختار را از منطق جدا نگه دارید

## اشتباهات رایج

- استفاده‌ی بی‌دلیل از template برای چیزهای ساده
- فراموش کردن clone کردن محتوا
- قرار دادن منطق زیاد در قالب

## نکات بازار کار

در اپلیکیشن‌های مدرن، template در کنار JavaScript برای ساخت UI‌های پویا، کارت‌ها و لیست‌ها بسیار کاربردی است.

## چک‌لیست یادگیری

- [ ] مفهوم `template` را می‌فهمم
- [ ] رابطه‌ی آن با JavaScript را می‌دانم
- [ ] از آن برای ساختارهای قابل استفاده مجدد استفاده می‌کنم
- [ ] از template برای کد تمیزتر استفاده می‌کنم
