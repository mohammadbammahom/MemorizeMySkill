# فرمت‌کردن متن

---

## این مبحث چیست؟

تگ‌های formatting معنایی:

- `<strong>` - متن مهم (بولد معنایی)
- `<em>` - تاکید (italic معنایی)
- `<mark>` - برجسته‌کردن
- `<del>` - حذف شده
- `<ins>` - اضافه شده
- `<code>` - کد برنامه‌نویسی
- `<sub>`, `<sup>` - subscript/superscript

---

## چرا وجود دارند؟

- **معنایی**: صفحه‌خوان‌ها می‌فهمند کدام متن مهم است
- **SEO**: Google متن مهم را با وزن بیشتر rank می‌کند
- **Styling**: CSS می‌تواند این تگ‌ها را style کند
- **Semantic meaning**: `<strong>` و `<b>` مختلف‌اند!

---

## چه زمانی استفاده کنیم

**`<strong>`**: متن خیلی مهم (توجه نیاز دارد)

**`<em>`**: متن تاکید‌شده (معنای متفاوت)

**`<mark>`**: برجسته‌کردن (رنگ زرد)

**`<del>`**: قیمت قدیم، نسخه قدیم

**`<ins>`**: قیمت جدید، نسخه جدید

**`<code>`**: نام کلاس، متغیر، کد کوتاه

---

## چه زمانی نباید استفاده کنیم

❌ `<strong>` برای styling (نه معنایی):
```html
<strong>فقط برای رنگ</strong> <!-- CSS استفاده کن -->
```

❌ `<em>` برای italic (نه تاکید):
```html
<em>فقط رنگ‌شده</em> <!-- بد معنایی -->
```

❌ `<code>` برای متن طولانی:
```html
<code>تمام یک پاراگراف</code> <!-- استفاده از <pre> کن -->
```

---

## تفاوت با عناصر مشابه

| تگ | معنی | صفحه‌خوان | CSS |
|----|--------|-----------|-----|
| `<strong>` | مهم | "بیان شده" | bold |
| `<b>` | فقط bold | عادی | bold |
| `<em>` | تاکید | "تاکید" | italic |
| `<i>` | فقط italic | عادی | italic |

---

## بهترین روش‌ها

✅ `<strong>` برای متن مهم (warnings، prices)

✅ `<em>` برای متن تاکید‌شده (معنای متفاوت)

✅ `<mark>` + `<strong>` برای برجسته‌ی خیلی مهم

✅ `<del>` + `<ins>` برای tracking changes

✅ `<code>` فقط برای کد کوتاه (< ۱ خط)

---

## اشتباهات رایج

❌ `<strong>` بدون معنی:
```html
<strong>این فقط برای رنگ است</strong> <!-- بد accessibility -->
```

❌ `<em>` برای italic خالص:
```html
<em>نام کتاب</em> <!-- `<i>` بهتر، یا `<cite>` -->
```

❌ `<code>` برای پاراگراف کامل:
```html
<code>function add() {
    ...
}</code> <!-- از <pre><code> استفاده کن -->
```

## تمرین

اکنون فایل `TextFormatting.Exercises.html` را خودت ایجاد کن و تمرین‌های زیر را انجام بده.

1. مقاله‌ی خبری: تاکید و strong متن‌ها.

7. فرمول‌ها: `<sup>` برای exponentials.

9. داکومنتیشن API: `<code>` برای parameters.
10. صفحه‌ی کامل: تمام tags + semantic صحیح.
