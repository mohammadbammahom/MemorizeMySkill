# Output

## این مبحث چیست؟

عنصر `<output>` برای نمایش نتیجه‌ی محاسبه یا مقدار تولیدشده توسط فرم استفاده می‌شود. این عنصر معمولاً با JavaScript همراه می‌شود و به جای نمایش متن ساده، نتیجه را در قالبی قابل فهم برای کاربر ارائه می‌کند.

## چرا از آن استفاده می‌کنیم؟

- نمایش نتیجه‌ی محاسبه در فرم
- بهبود تجربه‌ی کاربر در ابزارهای سفارش، حساب‌گر و فیلترها
- جدا کردن منطق نمایش از منطق داده

## چه زمانی استفاده می‌کنیم؟

- فرم‌های سفارش و‌ قیمت‌گذاری
- ماشین‌حساب و تبدیل واحد
- فرم‌های چندمرحله‌ای که نتیجه‌ی لحظه‌ای نیاز دارند

## چه زمانی نباید استفاده کنیم؟

- وقتی نتیجه فقط برای نمایش است و نیازی به ارتباط با فرم ندارد
- وقتی از `<div>` یا `<span>` برای نمایش ساده‌تر مناسب‌تر باشند
- وقتی عنصر باید با JavaScript به‌صورت پیچیده‌تر کنترل شود

## تفاوت با عناصر مشابه

- `<output>` برای نتیجه‌ی فرم مناسب است
- `<div>` برای ساختار کلی استفاده می‌شود
- `<span>` برای متن درون خط مناسب است

## بهترین روش‌های استفاده

- از `for` برای اتصال به ورودی‌های مرتبط استفاده کنید
- نتیجه را واضح و قابل خواندن نمایش دهید
- برای نمایش عدد و متن از JavaScript استفاده کنید

## اشتباهات رایج

- استفاده‌ی بی‌دلیل از `<output>` برای متن ثابت
- فراموش کردن اتصال با `for`
- نمایش نتیجه بدون به‌روزرسانی لحظه‌ای

## نکات بازار کار

در پروژه‌های فرم‌محور، این عنصر برای UI‌های حرفه‌ای و تعامل‌پذیر بسیار کاربردی است. مخصوصاً در داشبوردها و فروشگاه‌های آنلاین دیده می‌شود.

## چک‌لیست یادگیری

- [ ] مفهوم `<output>` را می‌فهمم
- [ ] رابطه‌ی آن با فرم و JavaScript را می‌دانم
- [ ] از آن در مثال‌های محاسباتی استفاده می‌کنم
- [ ] در فرم‌های حرفه‌ای از آن استفاده می‌کنم

## تمرین

اکنون یک فایل جدید با نام

Output.Exercises.html

بساز و تمرین‌های زیر را انجام بده.

1. فرم محاسبه‌ی هزینه‌ی سرویس با `<output>` بساز.
2. خروجی جمع چند ورودی را به‌صورت لحظه‌ای نمایش بده.
3. یک فرم تخفیف و مبلغ نهایی ایجاد کن.
4. در یک فرم رزرو، مجموع مبلغ را با `<output>` نمایش بده.
5. یک صفحه‌ی ساده‌ی ماشین‌حساب با چند ورودی بساز.
6. خروجی را با رنگ و سبک متفاوت نمایش بده.
7. یک فرم ارزیابی امتیاز و نتیجه‌ی نهایی بساز.
8. در فرم چند فیلد، مجموع را با `toLocaleString` نمایش بده.
9. یک فرم نظرسنجی با نتیجه‌ی عددی ایجاد کن.
10. یک نسخه‌ی حرفه‌ای از فرم محاسبه‌ی سفارش بساز.
