# Project Landing Page

## این مبحث چیست؟

این پروژه نمونه‌ای از یک landing page حرفه‌ای است که در آن ساختار HTML برای بخش‌های اصلی یک صفحه‌ی فروش و معرفی طراحی می‌شود.

## چرا از آن استفاده می‌کنیم؟

- نمایش ارزش محصول یا خدمات
- ساختاردهی واضح برای معرفی برند
- تمرین semantic و navigation واقعی

## چه زمانی استفاده می‌کنیم؟

- برای معرفی خدمات یا نرم‌افزار
- برای کمپین‌های تبلیغاتی و برندینگ
- برای صفحات جذب مشتری

## چه زمانی نباید استفاده کنیم؟

- وقتی صفحه نیاز به محتوای زیاد و چندصفحه‌ای دارد
- وقتی تمرکز اصلی روی وبلاگ یا فروشگاه است

## تفاوت با عناصر مشابه

- landing page نسبت به blog بیشتر روی CTA و ارزش پیشنهادی تمرکز دارد
- در project comparison، این صفحه از `cta` و `pricing` بیشتری استفاده می‌کند

## بهترین روش‌های استفاده

- hero section واضح
- pricing و FAQ شفاف
- فرم تماس ساده و semantic

## اشتباهات رایج

- نادیده گرفتن ارتباط بخش‌ها
- ساختار ناهماهنگ برای nav و footer
- استفاده از content نامتوازن

## نکات بازار کار

landing page در شرکت‌ها و استارتاپ‌ها یکی از پروژه‌های اصلی برای front-end engineer است. این نمونه برای تمرین HTML واقعی عالی است.

## چک‌لیست یادگیری

- [ ] ساختار landing page را می‌شناسم
- [ ] hero و CTA را درست طراحی می‌کنم
- [ ] pricing و FAQ را semantic می‌نویسم
- [ ] footer و فرم تماس را کامل می‌کنم

## تمرین

اکنون فایل LandingPage.Exercises.html را ایجاد کن و تمرین‌های زیر را انجام بده.

1. یک landing page برای اپلیکیشن موبایل بساز.
2. یک landing page برای مشاوره‌ی برند طراحی کن.
3. یک hero با CTA و ویژگی‌ها بساز.
4. یک pricing section حرفه‌ای اضافه کن.
5. یک FAQ با `details` طراحی کن.
6. یک فرم تماس مناسب برای landing page بساز.
7. یک footer برای لینک‌های اصلی طراحی کن.
8. یک نمونه‌ی landing page با features و benefits بساز.
9. یک landing page با بخش testimonials اضافه کن.
10. یک نسخه‌ی کامل و واقعی از landing page بساز.

## درس بعدی

در درس بعدی پروژه‌ی وبلاگ با header، sidebar و recent posts پیاده‌سازی می‌شود.
